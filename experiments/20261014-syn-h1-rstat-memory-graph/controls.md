## Второй Poisson-контроль (регулярные структуры) — **НЕ УСТАНОВЛЕН**
| Структура | Доля вырожденных зазоров | Результат |
|---|---|---|
| Решётка 20×20 (открытая) | 0.510 | исключена правилом (>5 %); фильтр из внешнего отчёта даёт 0.4006 |
| Тор 20×20 | 0.855 | исключён; фильтр из отчёта даёт 0.5905 |
| Случайный 6-регулярный (30 графов) | — | 0.5309 ≈ GOE, не Poisson |

Вывод: утверждение внешней модели «решётка 20×20 даёт r=0.4006 при связном графе» **воспроизводится численно (0.40058), но это артефакт фильтрации**: фильтр вырезает вырожденные зазоры из последовательности и склеивает несоседние уровни, а по корректному определению r для 51 % зазоров не определено. Решётка не является валидным вторым Poisson-контролем; случайные регулярные графы — GOE. **Следствие для S3:** единственный подтверждённый механизм Poisson-подобной базы в этой семье графов — несвязность (суперпозиция независимых блоков). Если реальные чистые графы окажутся Poisson-подобными, проверяется число компонент.

## Слабая связность (отчётный SBM p_in=0.15, p_out=0.001)
⟨r̃⟩ = 0.5316 ± 0.0150, компонент 1 → «Poisson-арм» отчёта не Poisson (≈60 межблочных рёбер возвращают отталкивание уровней).

## Псевдорепликация
Mann–Whitney по r_i одного графа против другого (нулевая гипотеза верна): ложноположительных 10.7 % при номинальных 5 % (300 пар; ≈4.5 SE выше 5 %), среднее lag-1 автокорреляции r_i = 0.24. Граф-уровневый permutation-тест (10 против 10 графов): 0/30. Решение: все выводы S3/S4 строятся на уровне графов; MWU по r_i не используется.

## Отклонение от pre-registration (minor)
TOL вырожденных зазоров = 1e-9 вместо 1e-12 из claim.md. Эффект проверен: доли вырожденных зазоров решётки идентичны при обоих порогах (0.5097 / 0.5097; 0.8552 / 0.8552) → практического влияния нет. Фиксируется как deviation (тривиальное).
