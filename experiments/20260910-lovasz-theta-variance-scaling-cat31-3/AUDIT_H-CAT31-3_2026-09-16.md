## F. Methodology failures (cross-cutting, most important section for future work)

1. **Novelty check skipped, self-caught (Pt.29)**: Points 26-28's λ_k derivation framed as new math; a Source Trace later found it classical (Filmus 2016). Result stands as independent re-derivation; only the novelty claim was invalid.
2. **Tautology mislabeled as discovery (Pt.34→36)**: a "cross-layer identity" was trivial linearity of the same fixed operator; the verification check that "confirmed" it was itself guaranteed to pass regardless of truth.
3. **Headline result invalidated by its own negative control (Pt.44→45)**: "single most informative result" was a small-grid artifact, caught only by testing on synthetic (non-Lovász) spectra of the same size.
4. **[MOST IMPORTANT] Skeptic review itself gave a false CONFIRMED-REAL verdict (Pt.47→48)**: cross-method solver agreement and small residuals were NOT sufficient evidence of LP primal feasibility — only a verified dual certificate was. This is not "an agent's first draft was wrong" (the recurring pattern in Points 65-68) — this is the ADVERSARIAL REVIEW LAYER ITSELF passing a materially false claim. Calibration implication: a `CONFIRMED-REAL` skeptic verdict in this project's numerical-LP domain specifically should not be treated as final without an independent dual-certificate-style check when the claim rests on solver/feasibility behavior.
5. **Symbol collision, caught before entering committed code (`T_q`)**: points 15b-20's swap-Dirichlet-energy vs. a later external proposal's LP-remainder — renamed before commit, old meaning undisturbed.
6. **Self-referential/circular sanity-check pattern, avoided by design (Point 66)**: δ_i computed via two independent LP solves, specifically to avoid reconstructing it from x_i·w_i — a positive methodology finding.
7. **Wrong reference distribution for a slope-significance test, occurring independently TWICE (Points 65, 66/68)**: conflating within-n sample count with the number of independent n-levels for degrees-of-freedom purposes.
8. **Aggregator-vs-construction confound never separated in test design (Point 67)**: three "independent" hypotheses all varied the graph, none varied the aggregator — found only on a SECOND skeptic pass.
9. **Overclaiming measurement precision from an uncontrolled instrument (Point 68)**: "1e-10" turned out to be pure solver noise (proven via 30+/40 mathematically-impossible `min>max` results); resolved specifically by adding a positive control (Gate 3 discipline) — a demonstrated, not merely stated, lesson.
10. **Four-for-four pattern**: every "SURVIVES/PASS"-flavored headline drafted in Points 65,66,68 before full adversarial review was substantially walked back on review. This is now an established base rate for this specific kind of claim in this project, not an anomaly.
