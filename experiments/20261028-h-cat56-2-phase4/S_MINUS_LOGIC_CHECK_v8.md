## 2. Утверждения и кванторы

**Теорема N (конечный полный POVM, матрица/след).** ∃ c > 0, s₁ > 0 ∀ конечный полный POVM {E_k} ∀ h ∈ S¹_ℝ (единичная сфера в ℝ^S) ∀ θ = sh с |s| ≤ s₁: tr(F^Q(θ) − F_E(θ)) ≥ c.
- c, s₁ зависят от: модели (A_a, Q, S); разделителя R* (γ > 0); констант Łojasiewicz (C₀, θ₀) при θ = 0; L = sup_{|h|=1,|s|≤t₀,|v|=1} ‖∂_sN_v(sh)‖; t₀.
- **Не зависят** от POVM (используются только Σ_k tr E_k = 22, Σ_k tr(R̂E_k) = tr R*, Σ_k tr(P_yE_k) = 20, rank E_k ≤ 22) и от h (sup по сфере в L).
- Проверено: лемма 6 — субаддитивность (x+y)^{θ₀} ≤ x^{θ₀} + y^{θ₀}, Гёльдер по k, Σ_j e_{kj}^{1−θ₀} ≤ 22^{θ₀}(tr E_k)^{1−θ₀}. CONFIRMED (аудиты ae2a07af, a19acd8d).

**Следствие N₁ (борелевский).** Для борелевского POVM M и |s| ≤ s₁: tr F^C_M(sh) ≤ tr F^Q(sh) − c. Переход: каждое конечное разбиение P даёт полный конечный POVM → trF_P ≤ trF^Q − c → след монотонного предела сети ≤ trF^Q − c. **Порядок пределов не используется**: оценка при фиксированной точке θ_s, предел по s — только для любой предельной точки. CONFIRMED.

**Направленный D2 (конечный POVM).** Если существует lim_{s→0} F_E(sh) (он существует для конечных POVM, см. D2_CONE_TRANSFER_v3), то tr lim ≤ tr F^Q(0) − c по Теореме N (предельный переход в следе). Значит матрица lim не равна F^Q(0). CONFIRMED.

**Предложение 7.** μ := tr M: P_θ ≪ μ, P_θ(B) ≤ μ(B) (так как ‖ρ_θ‖ ≤ 1, исправлено с «=»), m_θ = tr(ρ_θW), ∂m ограничено по ‖∂ρ‖, ∂m = 0 на {m=0}, sup_P F_P = I_int матрично. Обоснование: ℓ_x ∈ L²(P_θ), E[·|σ(P)] — ортогональная проекция, объединение конечных подалгебр плотно в L². Счётная порождённость не используется. CONFIRMED (аудит ae2a07af, пункт А).

**Łojasiewicz.** f_0(v) = λ₂(N_v(0)) — полуалгебраическая на сфере C²² (полиномиальная матрица от (Re v, Im v)); нули = 𝒱₀ ∩ S, 𝒱₀ = C²×𝒴, 𝒴 замкнут (условие rank ≤ 1 — обнуление 2×2-миноров). Утверждение dist(v,Z) ≤ C f^{θ₀} на компакте — из теоремы Łojasiewicz, раздел §2.6 Bochnak–Coste–Roy «Continuous semi-algebraic functions. Łojasiewicz's inequality» (уровень раздела подтверждён оглавлением, основная книга по номерам следствий не сверена). Номер Corollary 2.6.7 в статье **не используется**.

## 5. Открытое (явно)

1. **Обобщение на C¹-семьи** (аудит adc79edf завершён): Теорема N переносится при условиях 1–3 (THEOREM_NATURAL_D2_NOGO_v8 §0), с модулем непрерывности ω вместо L; условие непрерывности ∂ρ в нуле обязательно (контрпример), а блок supp×supp при θ = 0 должен быть нулевым. Предельная форма N₁ и Предложение 8 ложны для общих C¹-семей с условиями 1–3 (контрпример toy_rank_jump, C^∞, ранг 2 → 5); при постоянном ранге 2 предельная форма N₁ верна (аргумент: проектор поддержки и L непрерывны). Численные проверки — синтетика на игрушке 5×3, не на C²². Условие нулевого блока относится к ∂ρ₀ (эквивалентно L(0)_ss = 0), а не к ρ₀ (ss-блок ρ₀ = Q).
2. **Эквивалентность (D-Б) с интегральной формой при θ-зависимой мере**: не рассматривается (неприменимо, см. Предложение 7 для θ-независимой μ).
3. **Явные константы** (c, s₁, C₂, θ₀): существуют (Łojasiewicz), не вычислены.
4. **Внешнее рецензирование**: не проводилось.
5. **Литературная проверка**: номера теорем Łojasiewicz (кроме раздела §2.6), Hayashi–Ouyang (только метаданные) — не подтверждены.
