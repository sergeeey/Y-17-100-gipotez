Заменяет v5 после аудита агента (a19acd8d…): CONFIRMED по всем пунктам; внесены исправления записи. Математика v5 не менялась.

## 0. Предпосылки (явно)

- Модель S− (`S_MINUS_FINAL_v2.md` §1): ρ_θ = U_θρ₀U_θᴴ, ρ₀ = Q ⊕ 0 (Q = diag(1/3,2/3)), U_θ = exp(Σ_aθ_aX_a), X_a = [[0,−G_aᴴ],[G_a,0]], G_a = A_a/2 (блоки инстанса A_a = −2iB_a^{inst}, конвенция C2). Индексы S = {4..15} (0-based).
- Направление h ∈ R^S, |h| = 1; для s ∈ [−t₀, t₀] точка θ_s := s·h. Ниже везде |s| ≤ t₀, а «t» обозначает то же s.
- **SLD (явная формула).** Пусть ∂_aU_θ = U_θΩ_a(θ), Ω_a(θ) = ∫₀¹ e^{−σΘ}X_a e^{σΘ}dσ (Θ = Σθ_bX_b; целая по θ). Тогда ∂_aρ_θ = U_θ[Ω_a, ρ₀]U_θᴴ, и L_a(θ) = U_θ Φ(Ω_a)U_θᴴ, где Φ(Ω)_{ij} = 2(λ_j−λ_i)/(λ_i+λ_j)·Ω_{ij} при λ_i+λ_j > 0 (λ — собственные значения ρ₀: (1/3, 2/3, 0,…,0)); блок ker×ker произволен (например, 0) и в N_v не входит. Отсюда L_a(θ) аналитичен по θ. (Проверка уравнения SLD численно ≤ 10⁻⁸; аудит.)
- N_v(θ) := (Re(vᴴL_a(θ)ρ_θL_b(θ)v))_{a,b∈S} ∈ S^{12}, v ∈ C²². Через ρ входят только блоки L на supp ρ_θ (supp×supp и supp×ker), определённые однозначно ⇒ N_v(θ) аналитичен и не зависит от выбора ker×ker-блока.
- Для PSD E ∈ Herm₊(22) с спектральным разложением E = Σ_j e_jv_jv_jᴴ: N_E(θ) := Σ_je_jN_{v_j}(θ) (линейно по E).
- F^Q(θ) := (Re tr(ρ_θL_aL_b))_{a,b}; классическая FI конечного POVM {E_k}: F_E(θ) := Σ_{k: p_k(θ)>0} ∇p_k∇p_kᵀ/p_k, p_k = tr(ρ_θE_k), ∂_ap_k = Re tr(E_kL_a(θ)ρ_θ).

## 1. Элементарные леммы (любая точка θ)

**Лемма 1.** F_k(θ) ⪯ N_{E_k}(θ) и rank F_k(θ) ≤ 1 (F_k := 0 при p_k = 0).
*Доказательство.* Коши–Шварц: (Re tr(E L_xρ))² ≤ tr(ρE)·tr(ρL_xEL_x) ⇒ (∂_xp)²/p ≤ xᵀNx. При p = 0 градиент равен 0 (минимум неотрицательной гладкой функции), F = 0. ∎

**Лемма 2.** δ_k(θ) := N_{E_k}(θ) − F_k(θ) ⪰ 0; Σ_kδ_k(θ) = F^Q(θ) − F_E(θ) =: Δ(θ); λ₂(N_{E_k}(θ)) ≤ tr δ_k(θ).
*Доказательство.* Полнота: Σ_kN_{E_k} = F^Q. Вейль: λ₂(F+δ) ≤ λ₂(F)+λ₁(δ) ≤ tr δ (rank F ≤ 1). ∎

## 2. Функция f_s и Łojasiewicz при s = 0

f_s(v) := λ₂(N_v(θ_s)), |v| = 1, v = (x;y) ∈ C²⊕C²⁰.

**Лемма 3.** N_v(0)_{ab} = Re(yᴴA_aQA_bᴴy) не зависит от x; 𝒱₀ := {v : rank N_v(0) ≤ 1} = C² × 𝒴_S, где 𝒴_S := ∪_{x≠0}Y_S(x) ∪ {0} — замкнутый конус (условие rank ≤ 1 замкнуто). Множество нулей Z := f_0⁻¹(0) ∩ S = 𝒱₀ ∩ S непусто (v = (x;0)). f_0 — непрерывная полуалгебраическая функция на компактной сфере. По неравенству Łojasiewicz существуют C₀, θ₀ ∈ (0,1] с dist(v,𝒱₀) ≤ C₀f_0(v)^{θ₀} для |v| = 1.
*Статус:* PROVED (стандарт). Точный номер теоремы в Bochnak–Coste–Roy **не сверен** (UNVERIFIED-CITATION).

**Лемма 4 (Липшиц по s).** |f_s(v) − f_0(v)| ≤ L|s| для |v| = 1, |s| ≤ t₀, L := sup‖∂_sN_v‖ < ∞ (аналитичность на компакте; |λ₂(A)−λ₂(B)| ≤ ‖A−B‖).

## 3. Разделитель и оценка

R* ∈ Herm(20), s* := sup{yᴴR*y : y ∈ 𝒴¹_S}, γ := tr R* − 20 s* > 0 (O3: γ ≥ 0.0304). R̂ := diag(0,R*) ∈ Herm(22), P_y — проектор на C²⁰; для v = (x;y): vᴴR̂v = yᴴR*y.

**Лемма 5.** Для |v| = 1, y := P_yv: vᴴR̂v − s*|y|² ≤ C₁·dist(v,𝒱₀), C₁ := 4‖R*‖ + 2|s*|.
*Доказательство.* Пусть w = (x_w; y_w) ∈ 𝒱₀ — ближайшая точка, |v−w| = dist(v,𝒱₀). Так как 𝒱₀ = C²×𝒴_S, а 𝒴_S — конус, ближайшая точка в y-части — проекция y на замкнутый конус 𝒴_S: ỹ := P_yw ∈ 𝒴_S с |ỹ| ≤ |y| ≤ 1 (для проекции на замкнутый конус |ỹ|² = Re⟨y,ỹ⟩ ≤ |y||ỹ|). Однородность: ỹᴴR*ỹ ≤ s*|ỹ|² (ỹ/|ỹ| ∈ 𝒴¹, если ỹ ≠ 0). Далее yᴴR*y − ỹᴴR*ỹ ≤ 2‖R*‖·|y−ỹ|·(|y|+|ỹ|)/2·2 ≤ 4‖R*‖|v−w|, и |y|² − |ỹ|² ≤ 2|v−w|. Отсюда yᴴR*y − s*|y|² ≤ 4‖R*‖|v−w| + 2|s*||v−w|. ∎

**Лемма 6.** Для любого конечного POVM {E_k} и |s| ≤ t₀:
tr R* − 20 s* ≤ C₂·[(tr Δ(θ_s))^{θ₀} + |s|^{θ₀}], C₂ := 22·C₁C₀·max(1, L^{θ₀}).
*Доказательство.* Для каждого k: E_k = Σ_je_{kj}v_{kj}v_{kj}ᴴ (≤ 22 слагаемых, |v_{kj}| = 1). Тогда tr(R̂E_k) − s*tr(P_yE_k) = Σ_je_{kj}(v_{kj}ᴴR̂v_{kj} − s*|P_yv_{kj}|²).
По лемме 5, лемме 3 (dist ≤ C₀f_0^{θ₀}) и лемме 4 (f_0 ≤ f_s + L|s|), субаддитивности (x+y)^{θ₀} ≤ x^{θ₀}+y^{θ₀}:
v ᴴR̂v − s*|P_yv|² ≤ C₁C₀[f_s(v)^{θ₀} + (L|s|)^{θ₀}].
По лемме 2: e_{kj}·f_s(v_{kj}) ≤ λ₂(N_{E_k}(θ_s)) ≤ tr δ_k, т.е. f_s(v_{kj})^{θ₀} ≤ (tr δ_k/e_{kj})^{θ₀}.
Складываем с весами e_{kj}: tr(R̂E_k) − s*tr(P_yE_k) ≤ C₁C₀[(tr δ_k)^{θ₀}Σ_je_{kj}^{1−θ₀} + (L|s|)^{θ₀}tr E_k].
Σ_je_{kj}^{1−θ₀} ≤ 22^{θ₀}(tr E_k)^{1−θ₀}. Суммируем по k: Σ_k tr(R̂E_k) = tr R*, Σ_k tr(P_yE_k) = 20, Σ_k tr E_k = 22; Гёльдер Σ_k(tr δ_k)^{θ₀}(tr E_k)^{1−θ₀} ≤ (Σ tr δ_k)^{θ₀}(Σ tr E_k)^{1−θ₀}. Итог: tr R* − 20 s* ≤ C₁C₀[22(tr Δ)^{θ₀} + 22(L|s|)^{θ₀}]. ∎

## 4. Теорема N и следствие

**Теорема N.** Существуют c > 0, s₁ > 0 такие, что для любого конечного POVM и |s| ≤ s₁: tr(F^Q(θ_s) − F_E(θ_s)) ≥ c.
*Доказательство.* Если C₂|s|^{θ₀} ≤ γ/2, то из леммы 6: C₂(trΔ)^{θ₀} ≥ γ/2 ⇒ trΔ ≥ (γ/(2C₂))^{1/θ₀} =: c. ∎

**Следствие N₁ (борелевский).** Для борелевского POVM M положим F^C_M(θ) := lim (монотонная сеть) sup-по-разбиениям F_P(θ) при фиксированном θ; монотонность по измельчению верна (огрубление уменьшает классическую FI при каждом θ, и исходы с p = 0 дают 0). Для каждого конечного разбиения P (конечный POVM) tr F_P(θ_s) ≤ tr F^Q(θ_s) − c, и след переходит к пределу сети. Значит tr F^C_M(θ_s) ≤ tr F^Q(θ_s) − c для |s| ≤ s₁. Поскольку F^Q непрерывна, любая предельная точка lim_{s→0} tr F^C_M(θ_s) не превосходит tr F^Q(0) − c. Порядок пределов по s и по разбиениям не участвует. **Следовательно, естественный борелевский D2 не равен F^Q даже по следу, и тем более не равен матрично.**

## 5. Что доказано и что нет

- Доказано (PROVED-hand): Теорема N для любого конечного POVM; Следствие N₁ для любого борелевского POVM (в смысле предела монотонной сети разбиений).
- Не требуется: равномерный по s Łojasiewicz; обмен пределов; интегральная форма CFIM.
- **Открыто (явно):** (а) эквивалентность определения F^C = lim-сеть sup по разбиениям с интегральной формой ∫∇m∇mᵀ/m dμ (аргумент лемм 1–6 переносится на плотность дословно, если заменить суммы интегралами; это не проверено); (б) точная ссылка на теорему Łojasiewicz (BCR); (в) константы C₀, θ₀, L — экзистенциальны; (г) семья F_U (для общей C¹-семьи требуется проверка аналитичности/ранга); (д) численный контроль (минимизация tr Δ по POVM) не выполнен.
