**Условия для обобщения на C¹-семьи (добавлено 2026-10-31 по аудиту adc79edf; для F_U выполнены автоматически):**

2. Отображение θ ↦ ∂ρ_θ непрерывно в θ = 0. Без этого условия общее утверждение Теоремы N ложно (контрпример ниже); доказательство использует его через ω(r) → 0 (PROOF_RECONSTRUCTION_THEOREM_N_2026-10-31.md, шаг 5). Минимальность условия 2 не установлена.

Эквивалентно (L_a(0))_{ss} = 0, так как (∂ρ)_{ss} = (QL_{ss} + L_{ss}Q)/2 и уравнение Сильвестра с Q > 0 однозначно разрешимо (собственные значения q_i + q_j > 0). Для F_U условие выполнено: ∂_aρ₀ = [X_a, ρ₀] с X_a внедиагональным, его ss-блок равен X_{ss}Q − QX_{ss} = 0; явно ∂_aρ(0) = ½[[0, QA_aᴴ],[A_aQ, 0]]. Роль в доказательстве: при L_{ss}(0) = 0 имеем K_a v = Q^{1/2}L_{sk}(a)y, то есть N_v(0) зависит только от кернельной компоненты y, и 𝒱₀ = ℂ² × 𝒴 (продуктовая структура, на которой держится оценка разделения через P_y). Ненулевой ss-блок вводит x-зависимость в N_v(0), и продуктовая структура не доказана. Условие 3 не проверено как необходимое.
   *Замечание о константах:* для общей C¹-семьи 𝒴 и C₁ зависят от ∂_aρ₀ (блок sk), а не только от (A, Q); для F_U это (A, Q).
   *Замечание о Łojasiewicz:* f_0(v) = λ₂(N_v(0)), где N_v(0) — квадратичная форма по v с вещественными постоянными коэффициентами из L(0). Значит f_0 полуалгебраична для любых фиксированных L(0), аналитичность семьи не нужна.

**Контрпример к условию 2 (аудит, FALSIFIED без неё).** θ_k → 0, r_k = |θ_k|², φ(θ) = −Σ_k(θ−θ_k)·η(|θ−θ_k|/r_k) с гладкой срезкой η ≡ 1 около нуля, ρ_θ := ρ^{F_U}_{θ+φ(θ)}. **Постоянный ранг 2.** Для самой Теоремы N не нужен (аудит: SLD существует в каждой точке для любой дифференцируемой PSD-семьи; ∇p_k = 0 при p_k = 0). Нужен для N₁ (переход s → 0) и для Предложения 8: см. §3 и §4.

**Модуль вместо L (исправлено после аудита Codex, 2026-10-31).** Прежняя формула ω(r) = sup‖N_v(θ) − N_v(0)‖ **ложна** при скачке ранга: N_v(θ) не сходится к N_v(0), иначе F^Q = Σ_j N_{e_j}(θ) была бы непрерывна, что противоречит toy_rank_jump. Оценка f_θ ≥ f₀ − ω(|θ|) использует только M_v (PROOF_RECONSTRUCTION шаг 5). Для C¹-семьи L может не существовать, поэтому s₁ неявен.

**Односторонняя оценка f_s ≥ f_0 − ω(s).** Проектор Рисса P(θ) на два больших собственных значения непрерывен (спектральная щель сохраняется); N_v(θ) ⪰ Re⟨PK_av, PK_bv⟩, P K_a непрерывен в нуле. Без постоянного ранга — не нужен. Численно (игрушка 5×3, синтетика, не C²²): min_v(f_s − f_0) = −1.6, −0.32, −0.084, −0.020 при s = 0.1, 0.03, 0.01, 0.003 (линейно по s).

## 1. Определения (явно)

- **Матричная классическая информация** конечного POVM: F_E(θ) := Σ_{k:p_k>0} ∇p_k∇p_kᵀ/p_k, p_k = tr(ρ_θE_k).
- **Квантовая:** F^Q(θ)_{ab} = Re tr(ρ_θL_aL_b), L_a(θ) — SLD.
- **D2 вдоль луча (матричный):** для конечного POVM F_D2(h) := Σ_k lim_{t→0} F_k(th), F_k(th) := 0 при p_k(th) = 0.
- **Борелевский естественный (матричный, след):** F^C_M(θ) := предел монотонной направленной сети конечных разбиений P ↦ F_P(θ) по Лёвнеру (существует, см. предложение 7); для борелевского M её след — tr F^C_M(θ) = sup_P tr F_P(θ).

## 2. Утверждения

**Лемма 1–5** — без изменений (v7 §1; аудит: CONFIRMED).

**Лемма 6 и Теорема N** — без изменений в содержании. Квантор: ∃ c, s₁ > 0 ∀ конечный полный POVM ∀ h ∈ S¹_ℝ ∀ |θ| ≤ s₁ (не только вдоль лучей): tr(F^Q(θ) − F_E(θ)) ≥ c, с c := (γ/(2C₂))^{1/θ₀} и s₁ > 0 таким, что s₁ ≤ t₀ и ω(s₁)^{θ₀} ≤ γ/(2C₂) (неявно; существует при ω → 0). Для F_U, где ω(r) ≤ L·r, можно взять s₁ := min(t₀, (γ/(2C₂L^{θ₀}))^{1/θ₀}). Прежняя явная формула s₁ = min(t₀, (γ/(2C₂))^{1/θ₀}) без множителя L была неверной (она молча предполагала ω(r) ≤ r). Константы c, s₁ не зависят от POVM и от h.

**Следствие N₁ (борелевский, матричный и следовой).** Для борелевского POVM M и |θ| ≤ s₁: tr F^C_M(θ) ≤ tr F^Q(θ) − c. Для F_U (ранг постоянен) любая предельная точка tr F^C_M(θ_s), s → 0, не превосходит tr F^Q(0) − c; значит F^C_M(θ_s) не стремится к F^Q(0) ни в следе, ни в матрице. **Предельная форма N₁ для общей C¹-семьи с условиями 1–3 ложна.** Контрпример toy_rank_jump (C^∞, условия 1–3 выполнены, ранг 2 в нуле и 5 при θ ≠ 0): tr F^Q(s) → 65.51 при tr F^Q(0) = 61.51, то есть F^Q разрывна в нуле. Поэтому любая предельная точка tr F^C_M(sh) ограничена величиной lim tr F^Q(sh) − c, а не tr F^Q(0) − c. Достаточное условие для предельной формы — постоянный ранг 2 (тогда проектор поддержки непрерывен и tr F^Q непрерывна в нуле). Неравенство в каждой точке tr F^C_M(θ) ≤ tr F^Q(θ) − c не опровергнуто (контрольный POVM на том же примере: tr F_E ≈ 38.8 при tr F^Q(s) ≈ 65.5). Аналитически (первый порядок, PROOF_RECONSTRUCTION шаг 10 и приложение): lim_{s→0} F^Q(sh) = F^Q(0) + 4(trτ)hhᵀ, так что lim tr F^Q(sh) − tr F^Q(0) = 4 trτ = 4.0; численно 3.9976 при s = 0.003 (toy_rank_jump/rank_jump_check.out).

**Предложение 7 (сеть разбиений = интегральная CFIM, при θ-независимой мере).** Пусть μ := tr M (конечная мера, не зависит от θ). Для любого θ: P_θ(B) := tr(ρ_θM(B)) ≤ ‖ρ_θ‖·μ(B) ≤ μ(B) (так как ‖ρ_θ‖ ≤ 1), значит P_θ ≪ μ, и плотность m_θ = dP_θ/dμ = tr(ρ_θW(x)) (M(dx) = W(x)μ(dx), W ⪰ 0, tr W = 1 μ-п.в.). Утверждения:
(а) |∂_am_θ(x)| ≤ ‖∂_aρ_θ‖ (поэтому дифференцирование под знаком интеграла законно);
(б) на {m_θ = 0} градиент ∂m_θ = 0 (по неравенству Коши–Шварца |∂_am|² ≤ m·tr(W L_aρL_a)-оценки, см. лемму 1);
(в) для x ∈ ℝ^S: xᵀF_P(θ)x = ‖E_θ[ℓ_x | σ(P)]‖²_{L²(P_θ)}, ℓ_x := x·∇m_θ/m_θ, и xᵀI_int(θ)x = ‖ℓ_x‖²_{L²(P_θ)} (I_int := ∫_{m>0}∇m∇mᵀ/m dμ). Поскольку ℓ_x ∈ L²(P_θ) (так как xᵀI_intx ≤ xᵀF^Q x < ∞), а условное ожидание E[·|σ(P)] — ортогональная проекция на L²(σ(P)), а объединение конечных подалгебр σ(P) по направленной сети плотно в L² (простые функции плотны в L²(P_θ) для борелевского пространства), получаем sup_P xᵀF_Px = xᵀI_int x. Поскольку сеть монотонна по Лёвнеру, sup существует как предел сети и равен I_int матрично.
Итог: F^C_M(θ) = I_int(θ) матрично для θ-независимой меры μ = tr M.
*Замечание к обоснованию (исправлено):* прежняя ссылка на мартингальную сходимость относилась к последовательности σ-алгебр, которая может не порождать σ(ℓ); в версии v8 используется плотность простых функций и ортогональная проекция, счётная порождённость пространства исходов не нужна.
*Статус:* PROVED-hand.

**Сеть разбиений монотонна (лемма 1′).** Для огрубления G ⊂ G' (конечные σ-алгебры) F_G ⪯ F_{G'}: неравенство Титу (Σg_i)ᵀ(Σg_i)/Σp_i ≤ Σ g_ig_iᵀ/p_i для каждого x; нулевые исходы дают g = 0. Статус: PROVED-hand.

## 3. Область действия (явно — главная поправка)

Запрет относится к **матричной** (или следовой) классической информации Фишера вдоль луча θ_s = sh и к её пределу. Это **не** запрет для всех определений «информации». В частности:

**Контрпример для квадратичной формы по направлению (Proposition 8).** Пусть E_0 := I₂⊕0 и E_k := 0⊕e_ke_kᴴ (k = 1..20) — полный конечный POVM на ℂ²². Тогда для каждого фиксированного h ∈ S¹_ℝ: lim_{t→0} hᵀF_E(th)h = hᵀF^Q(0)h. Причина: N_{E_k} = (Re(e_kᴴA_aQA_bᴴe_k)), ΣN_k = F^Q, а для регулярного нулевого-по-предельному исхода вклад в hᵀ·h равен (hᵀN_kh)²/(hᵀN_kh) = hᵀN_kh, сумма по k даёт hᵀF^Qh; E_0 даёт вклад O(t²). Численно это подтверждено (аудит ae2a07af: расхождение убывает как t²). Тождество Шура для ядерного блока здесь использует постоянный ранг 2: на игрушке со скачком ранга hᵀF_E(sh)h → 16.40 против hᵀF^Q(0)h = 12.40 (аудит adc79edf), то есть без постоянного ранга утверждение Предложения 8 не воспроизводится. Для F_U ранг постоянен, и утверждение верно. Однако матрица lim_t F_E(th) при этом НЕ равна F^Q (следовый дефицит ≥ c по теореме N). Значит:
- если «CFIM» определять как квадратичную форму hᵀF^C h для каждого h отдельно (например через расстояние Хеллингера, 8H²(P_0,P_{th})/t² → hᵀFh), то насыщение достижимо;
- запрет v7/v8 относится к матричной классической информации (с её следом), то есть к стандартной CFIM-матрице в многопараметрической QCRB.

Эта различие должно быть явно указано в статье как часть определения.
