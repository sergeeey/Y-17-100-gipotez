# LEMMA_CELL_AUDIT — лемма ячейки и покрытие S³ для отрицательного сертификата S− (стадия C)

Дата: 2026-10-29. Объект: `code/c3d_cell_certificate_adapted.py` (прогоны `c3d_S-_f090_v2`, `c3d_S-_f090_margin1e-4_v2`, `c3g_S-_f090_dump`), интервальная проверка `metrics/interval_top1000.json`.

Метки: **[PROVED-hand]** вывод на бумаге, проверен мной по шагам (не инструментом); **[VERIFIED-sampling]** выборочная проверка численно (может опровергнуть, не доказать); **[VERIFIED-interval]** строгая арифметика шаров на отдельных ячейках; **[OPEN]** не закрыто.

## 0. Что утверждается

Для каждого единичного x ∈ C² и каждого единичного y ∈ Y_{S−}(x) выполнено y†Ry ≤ B_ℓ, где ℓ — принятый лист, покрывающий x. Тогда sup ≤ max_ℓ B_ℓ ≤ s_target. Если tr R − 20·s > 0, то I₂₀ ∉ cone{yy† : y ∈ 𝒴_{S−}} (критерий фазы 3).

## 1. Обозначения и R-линейность Φ  [PROVED-hand]

u = (Re x₀, Im x₀, Re x₁, Im x₁) ∈ S³ ⊂ R⁴. Строки `phi_rows` (`s8_admissible_span.py`, строки 46–58) суть Re/Im линейных и антилинейных по x функций; Re/Im от C-линейного или C-антилинейного отображения по x R-линейны по (Re x, Im x). Значит Φ(u) = Σ_j u_j Φ_j точно, Φ_j = phi_rows на базисных векторах. Численная проверка: lin_dev = 5.7·10⁻¹⁴ [VERIFIED-float].

## 2. Ядро Φ(u) совпадает с Y_S(x)  [PROVED-hand]

Пусть a_c = conj(A_i[:,c]) (строка c столбца), тогда (A_i†y)_c = a_c·y. Ограничения: g₁ = x₀a₁ − x₁a₀ даёт комплексное условие g₁·y = 0 (2 вещественных строки на i); g₃ = conj(x₀)a₀ + conj(x₁)a₁ даёт Im(g₃·y) = 0 (1 строка на i). Итого 3·12 = 36 строк.
- Если y ∈ Y_S(x): a_c·y = λx_c, λ ∈ R ⇒ g₁·y = 0, и conj(x₀)(a₀·y)+conj(x₁)(a₁·y) = λ|x|² вещественно.
- Обратно, если g₁·y = 0 и Im(g₃·y) = 0 при x₀ ≠ 0: λ := (a₀·y)/x₀ даёт a₁·y = λx₁ (из g₁·y = 0), а Im(g₃·y)=0 ⇒ λ|x|² вещественно ⇒ λ вещественно. ∎
- Вещественная форма: y†Ry = vᵀMv, M = [[Re R, −Im R],[Im R, Re R]] (R эрмитова) [PROVED-hand], численно симметрична.
- dim ker = 40 − 36 = 4 ⇔ σ₃₆(Φ(u)) > 0.

**Фазы.** Y_S(e^{iα}x) = e^{iα}·Y_S(x) при домножении y на фазу; y†Ry инвариантен. Поэтому достаточно x₀ ≥ 0 вещественное, т.е. параметризация Блоха x = (cos θ/2, sin θ/2 e^{iφ}), θ∈[0,π], φ∈[0,2π) покрывает все x. [PROVED-hand]

## 3. Лемма ячейки

Центр u₀ = u(θ_c, φ_c), полуширины h_θ, h_φ, du = ½h_θ + sin(θ_hi/2)·h_φ + 10⁻¹².
Φ₀ = Φ(u₀), A_j = Φ₀⁺Φ_j (40×40), κ = du·(Σ‖A_j‖²)^{1/2}, κ_K = du·(Σ‖A_jZ‖²)^{1/2}, Z = ортобазис K = ker Φ₀, ρ = κ_K/(1−κ), B = max(λ_K,0) + 2‖MZ‖ρ + ‖M‖ρ², λ_K = λ_max(ZᵀMZ).

**L1 (радиус).** Вдоль пути от центра сначала по θ, потом по φ: |∂_θu| = ½ (проверено), |∂_φu| = sin(θ/2) (проверено). Значит sup_{ячейка}|u − u₀| ≤ ½h_θ + sin(θ_hi/2)h_φ, так как sin(θ/2) возрастает на [0,π]. Шов 10⁻¹² покрывает погрешности float. [PROVED-hand]; рабочая ошибка 2× (фаза «du-bug», аннулирована) — **исправлена** в c3d строка 107.

**L2 (шар на сфере).** Лемма формулируется для ЛЮБОГО единичного u с |u − u₀| ≤ du, не только для u из прямоугольника. Доказательство: Δ = u − u₀, Φ(u)y = 0 ⇒ Φ₀y = −Φ(Δ)y.

**L3 (разложение).** y = z + w, z ∈ K, w ∈ row(Φ₀). Φ₀w = −Φ(Δ)y, и Φ₀⁺Φ₀ = проектор на row(Φ₀) ⇒ w = −Φ₀⁺Φ(Δ)(z+w). Оценка операторной нормы: ‖Φ₀⁺Φ(Δ)v‖ ≤ Σ|Δ_j|‖A_jv‖ ≤ du·(Σ‖A_j‖²)^{1/2}‖v‖ = κ‖v‖ при |Δ| ≤ du; для v = Zc даёт κ_K|c|. Отсюда |w| ≤ κ_K|z| + κ|w| ⇒ |w| ≤ ρ|z| при κ < 1. [PROVED-hand]

**L4 (квадратичная форма).** y = z + w, |z|² + |w|² = 1, z = Zc. yᵀMy = zᵀMz + 2zᵀMw + wᵀMw. zᵀMz ≤ max(λ_K,0)|c|² ≤ max(λ_K,0) (|c| ≤ 1). |zᵀMw| = |cᵀ(ZᵀM)w| ≤ ‖MZ‖·|w| ≤ ‖MZ‖ρ. wᵀMw ≤ ‖M‖ρ². Итог yᵀMy ≤ B. [PROVED-hand]

**Константы.** В c3d L_Φ **не используется** (он нужен только историческому `c3_cell_certificate.py`). Используются κ, κ_K, ‖M‖, ‖MZ‖, λ_K. L_Φ = 506.16449 и ‖M‖ = 0.2897488185 проверены mpmath на 40 знаках [VERIFIED-mp].

**Условия σ₃₆.** Нужны σ₃₆(Φ₀) > 0 (ранг 36, Φ₀⁺ определён, dim K = 4) и κ < 1. Оба выполнены во всех принятых листьях: min σ₃₆ = 0.010075 (запас 10⁻⁴), κ ≤ 0.25 на листьях из топ-1000 [VERIFIED-float]. Численные значения σ₃₆ на 6 центрах совпали с mpmath до 4·10⁻¹⁴ [VERIFIED-mp].

**Вывод по лемме:** на бумаге рассуждение корректно, ошибок не найдено. Ошибка в радиусе (фаза du-bug) была единственной найденной ошибкой и исправлена. Выборочная проверка (раздел 5) не опровергла лемму.

## 4. Покрытие S³  [PROVED-hand, с оговорками]

1. Листы — это бисекции прямоугольника [0,π]×[0,2π] по float-срединам. Дочерние листы используют те же float-значения границ, поэтому разбиение точное в вещественной арифметике: нет щелей между листами. [PROVED-hand]
2. Щели из-за float: float π < π на 1.2·10⁻¹⁶, float 2π < 2π на 2.4·10⁻¹⁶. Точки θ = π и φ = 2π не входят в прямоугольник. Но по L2 лемма применяется к любому единичному u с |u−u₀| ≤ du. Расстояние до точки (π, φ) от центра ближайшего листа не больше du + 1.2·10⁻¹⁶ ≤ du + 10⁻¹². Значит точки щелей покрыты тем же листом. [PROVED-hand]. Численно: на 20 000 полярных листов (θ_hi = float π) и 20 000 шовных листов (φ_hi = 2π) максимум |u(точка щели) − u₀|/du = 1 − 9·10⁻⁹ < 1 (`code/sliver_check.py`, журнал `logs/sliver_check.log`, seed 20261029). Аудит `lemma_audit.py` эти листы не выбирал, поэтому щели проверены отдельно.
3. **Вырожденные точки** (σ₃₆(x) = 0, ядро прыгает с 4 на 6): отдельной обработки не требуется. L2 использует только центр u₀ листа и не требует σ₃₆ в самой точке x: для любого единичного y ∈ ker Φ(u) с |u−u₀| ≤ du имеем yᵀMy ≤ B. Размерность ядра в точке u не используется. [PROVED-hand]; выборочно проверено на 40 листах × 6000 точек сферы (раздел 5).
4. Площадь принятых листов = 2π² с относительной ошибкой 2·10⁻¹⁶ [VERIFIED-float]. Это проверка согласованности, не доказательство покрытия; доказательство — пп. 1–3.

**Что остаётся [OPEN] в покрытии:** формальная запись пп. 1–2 через интервалы на границах (чисто текстовая, не вычислительная). Пп. 1–3 не зависят от вычислений.

## 6. Что это значит для вердикта

- Лемма ячейки и покрытие доказаны на бумаге (разделы 2–4) с одной оговоркой: float-арифметика (раздел 7).
- Сертификат S− как **строгое** доказательство требует: (a) строгой арифметики для всех листьев или доказанной оценки ошибки float; (b) независимой проверки разложения (раздел 3, L3) формальным инструментом, а не вручную. Пункт (b) частично закрыт выборочно.
- Для порога b = 0.0145 условие тем же: tr R − 20·b = 0.01405 > 0 (см. C_NOTES 6e).
