## A. От «λ_i не тождественно нулевые» к допустимому разложению

### Лемма A (разложение с одновременно ненулевыми λ)

**Обозначения.** Для направления x_j ∈ ℂ²∖{0} пусть Y_j ⊂ ℂ²⁰ — вещественная линейная оболочка базисных векторов B_{j,1..m_j}, где каждый B_{j,a} ∈ Y_{S₊}(x_j) = {y : A_i†y ∈ ℝx_j для всех i ∈ S₊}. Для y ∈ Y_j определим λ_{j,i}(y) ∈ ℝ из A_i†y = λ_{j,i}(y)·x_j.

**Предпосылки.**
- P1. Каждый B_{j,a} принадлежит Y_{S₊}(x_j). `[VERIFIED-exact]` двумя путями (§D).
- P2. Для всех j и i ∈ S₊ вектор ℓ_{j,i} := (λ_{j,i}(B_{j,a}))_{a=1..m_j} ∈ ℝ^{m_j} ненулевой. `[VERIFIED-exact]` двумя путями (§D).
- P3. Главный подблок M_j⁰⁰ (индексы a, b ≤ m_j) точной моментной матрицы M_j* положительно определён. Следует из «все 280 блоков M_j* положительно определены» (прогоны A и B сертификата, `S_PLUS_CERTIFICATE_FINAL_v2.md` §3). Мной не перепроверено.
- P4. Σ_j Σ_{a,b ≤ m_j} M_j⁰⁰[a,b] B_{j,a}B_{j,b}† = I₂₀. Это ядерный блок 484 точных равенств A·M* = b (подмножество из 400 вещественных координат Herm(20); там же). Мной не перепроверено.
- P5. Индексы a = 1..m_j матрицы M_j* соответствуют базисным векторам B_{j,a} из `exact_bases2.pkl` в том же порядке и с тем же m_j, а индекс N_j — вектору (x_j; 0). Так устроен сертификат (`S_PLUS_CERTIFICATE_FINAL_v2.md` §1, §5); отдельно не перепроверено.

**Утверждение.** Существует конечное семейство векторов y_{jk} ∈ Y_j такое, что Σ_{j,k} y_{jk}y_{jk}† = I₂₀ и λ_{j,i}(y_{jk}) ≠ 0 для всех j, k, i ∈ S₊. Каждый E_{jk,00} := y_{jk}y_{jk}† удовлетворяет буквальному (10) с c^{jk}_{lm} = λ_{j,l}(y_{jk})/λ_{j,m}(y_{jk}) для всех упорядоченных пар (l, m) ∈ S₊², включая l = m.

**Доказательство.** `[PROVED-paper]`
1. *Линейность.* Y_{S₊}(x_j) задаётся вещественно-линейными условиями, поэтому Y_j ⊂ Y_{S₊}(x_j) — вещественное подпространство. Отображение y ↦ λ_{j,i}(y) = Re(x_j†A_i†y)/|x_j|² вещественно-линейно на Y_j, и для y = Σ_a d_a B_{j,a} с d ∈ ℝ^{m_j} имеем λ_{j,i}(y) = ℓ_{j,i}·d.
2. *Выбор векторов.* По P3 (и P5 для соответствия индексов) M_j⁰⁰ = LLᵀ с обратимой L (Холецкий). Для любой ортогональной Q положим d_k = LQe_k, k = 1..m_j. Тогда Σ_k d_k d_kᵀ = LQQᵀLᵀ = M_j⁰⁰ точно. Далее λ_{j,i}(y_k) = ℓ_{j,i}·d_k = w_i·(Qe_k), где w_i = Lᵀℓ_{j,i} ≠ 0 (L обратима, P2). Для Q, распределённой по мере Хаара на O(m_j), каждый столбец Qe_k равномерен на сфере S^{m_j−1}, и P(w_i·Qe_k = 0) = 0. Пар (i, k) конечное число, поэтому почти всякая Q даёт все λ_{j,i}(y_k) ≠ 0.
3. *Сохранение структуры.* y_k = Σ_a d_k[a] B_{j,a} — вещественная комбинация, значит y_k ∈ Y_j ⊂ Y_{S₊}(x_j).
4. *Совместимость с моментами.* Используется только положительная определённость подблока (P3). Последняя координата (направление (x_j; 0)) в ядерный блок не входит.
5. *Точное воспроизведение.* Σ_k y_k y_k† = Σ_{a,b} (Σ_k d_k[a]d_k[b]) B_{j,a}B_{j,b}† = Σ_{a,b} M_j⁰⁰[a,b] B_{j,a}B_{j,b}†, так как d_k вещественны. Сумма по j равна I₂₀ по P4.
6. *Нормировка и фазы.* λ вещественны по P1. Фаза x_j фиксирована, λ определены относительно неё. Масштаб y не влияет на ненулевость.
7. *Кванторы (10).* Для любого семейства постоянного ранга с этими данными первого порядка в θ₀ имеем L_{l,+0} = 2∂_lV†Y = A_l†, откуда Y†∂_lV = A_l/2. Так как Y†V = 0, Y†∂_lṼ = (Y†∂_lV)U† = ½A_lU†. Поэтому (10) равносильно E_k(A_l − c^k_{lm}A_m)U† = 0, то есть E_k(A_l − c^k_{lm}A_m) = 0. Для E = yy† это A_l†y = c·A_m†y, то есть λ_l = c·λ_m (x_j ≠ 0). При всех λ ≠ 0 подходит c = λ_l/λ_m, вещественное. Квантор «для всех l, m» выполнен; «существует POVM {E_k,00} на ℋ₀ с ΣE_k,00 = I₂₀» выполнен (конечный); «вещественные c^k_{lm}» выполнены. ∎

**Что лемма не даёт.**
- Существование подходящих векторов не означает существования POVM, насыщающего границу при D1. Это отдельный вопрос (§B, §C).
- Остальную часть 2′ (вещественные диагональные D_l и унитарная U_θ, решающая систему ДУЧП в окрестности θ₀; интегрируемость) лемма не затрагивает `[OPEN]`. В самой точке θ₀ U выпадает из (10).

**Минимальный контрпример при нарушении P2.** Мутация A₃ := 0 делает ℓ_{j,3} = 0 на каждом направлении. Тогда любой y ∈ Y_j имеет λ₃ = 0 при ненулевых других λ, и буквальная (10) нарушена для пары (l, 3) во всём Y_j. Детектор находит это в обоих путях (§D).

### Сторона S₋: буквальная 2′ не выполняется в θ₀

`[PROVED-paper]`, условно на сепаратор V5.1. Пусть {E_k,00} — POVM на ℋ₀ с (10). E_kX = 0 ⇔ v†X = 0 для всех v ∈ range(E_k). Значит, каждый v ∈ range(E_k) удовлетворяет A_l†v = c^k_{lm}A_m†v для всех l, m. Если A_m†v = 0 для какого-то m, то и A_l†v = 0 для всех l. Иначе все A_l†v вещественно пропорциональны одному вектору w ≠ 0, то есть v ∈ Y_{S₋}(w). В обоих случаях v ∈ 𝒴_{S₋}. Разложив E_k по range, получаем I₂₀ = Σ vv† с v ∈ 𝒴_{S₋}, и Tr H = Σ v†Hv ≥ 0. Это противоречит Tr H < 0 для сепаратора V5.1. Ранг E_k произвольный.

## B. D1 и разделённые POVM

**Тезис.** Для ρ₀ = Q ⊕ 0 (Q > 0) и ∂_iρ₀ = ½{ρ₀, L_i}, L_i = [[0, A_i†],[A_i, 0]], любой POVM из блочно-диагональных эффектов E = E₊₊ ⊕ E₀₀ имеет F_C,D1(θ₀) = 0.

**Вывод.** `[PROVED-paper]` ρ₀L_i = [[0, QA_i†],[0, 0]], L_iρ₀ = [[0, 0],[A_iQ, 0]], значит ∂_iρ₀ = ½[[0, QA_i†],[A_iQ, 0]] — только внедиагональные блоки. Для блочно-диагонального E ∂_ip = Tr(∂_iρ₀E) = 0. Регулярный исход (p > 0) даёт ∂p∂pᵀ/p = 0, нулевой исход при D1 даёт 0. Итог F_C,D1 = 0. Так как F^Q_ii = Re tr(QA_i†A_i) > 0 при A_i ≠ 0, такой POVM границу не насыщает. Тезис верен в более широкой форме: достаточно блочной диагональности каждого эффекта, а не поддержки только на носителе или только на ядре.

**Поправки к формулировкам отчёта от 10.11.**
1. «Регулярная часть одна (проектор на носитель)». Это верно только для конструкции Нурдина (Π — общие спектральные проекторы L₊₊ = 0, значит Π = I). У произвольного разделённого POVM регулярных эффектов может быть много, и все они дают 0.
2. «Насыщающий POVM S₊ обязан быть неразделённым (каждый элемент u = (x; y) с x ≠ 0)». Слишком широко. Верно:
   - хотя бы один эффект должен иметь ненулевой внедиагональный блок (из тезиса);
   - каждый вектор из range насыщающего регулярного эффекта имеет вид (x; y) с y ∈ Y_S(x) (A1, шаги 3–5); нулевые эффекты должны лежать на чистых векторах (A_i†y = 0 для всех i), а их нет (вещественная размерность чистого подпространства 0 для S₊, S₋ и всех 16, `[VERIFIED-exact]`, §D). Поэтому у каждого ненулевого эффекта ненулевая часть на носителе.
   - **Контрпример к широкой версии** («каждый эффект имеет ненулевой перекрёстный блок»), `[PROVED-paper]`: M_j* положительно определена, значит M_j* − εe_Ne_Nᵀ ≻ 0 при малом ε > 0 (e_N — координата (x_j; 0)). Эффект ε(x_j; 0)(x_j; 0)† блочно-диагонален, у него N_E = 0 и F_C,E = 0. Остаток раскладывается в насыщающие эффекты ранга один общим разложением, у которого каждый кусок имеет ненулевую последнюю координату (как в лемме A, шаг 2). Сумма F_C = Σ N_E = F^Q. Получается насыщающий D1 POVM с блочно-диагональным эффектом.
3. **Класс POVM в поправке.** В arXiv v5 (раздел 6) построение разделённое: регулярные V Π V† на ℋ₊ и нулевые на ℋ₀ `[DOCS]`. Вывод «ΣE_k,00 = I_{r0} необходимо» там получен из того, что регулярные оптимальные эффекты имеют вид V Π V†. Резюме опубликованной поправки IEEE (запись в Vault от 2026-11-01 через OpenAlex) говорит, что именно это допущение неверно для общих POVM `[WEAK]`: сам текст не прочитан. **Обновление 2026-11-10:** аннотация восстановлена из OpenAlex и прочитана `[DOCS]`; она также отрицает необходимость условия 1. Это возможное расхождение с теоремой 3 v5 (v5 подана 7 июня 2024, эррата позже в 2024); класс POVM в обоих текстах не сверялся. См. `../q0_followup_2026-11-10/Q0_FOLLOWUP.md` §1.
4. **Определение насыщения у Нурдина** опирается на информацию нулевых исходов в смысле предела (конвенция YPZJ), а не на точечную D1. При D1 его достаточная конструкция даёт F_C = 0.
5. **Откуда информация в конвенции предела.** Для семейства постоянного ранга ρ_θ = V_θρ₊₊(θ)V_θ† и нулевого эффекта E = ww†, w = (0; y): V_{θ₀}†w = 0, ∂_iV†w = ½L_{i,+0}(Y†w) = ½A_i†y, откуда p(θ) = ¼θᵀN_Eθ + O(|θ|³), где N_E,ij = Re(a_i†Qa_j), a_i = A_i†y. Вдоль θ = th при hᵀN_Eh > 0 предел CFIM равен (N_Eh)(N_Eh)ᵀ/(hᵀN_Eh) ≤ N_E с равенством тогда и только тогда, когда rank N_E = 1. `[PROVED-paper]`
6. **Почему при D1 нужны перекрёстные блоки.** Для регулярного эффекта ранга один с u = (x; y) имеем ∂_ip = Re(x†Q·A_i†y). Это выражение ненулевое только при x ≠ 0 и y ≠ 0.

**Ответы на проверки дополнения.**
- *Кванторы по направлениям.* Для ∀h и многомерного предела вопрос закрыт через общее h. Для «∃h произвольная» (h может лежать в ker N_E нулевого эффекта) **первый недоказанный переход**: оценка вклада нулевого эффекта вдоль h ∈ ker N_E (≤ N_E или = 0). Вдоль такого луча p = O(t³), и предел не выводится из данных первого порядка `[OPEN]`. В `CONVENTION_RESOLUTION.md` для F_U это значение проверено только численно (9·10⁻⁹).
- *Зависимость POVM от направления.* Насыщающий класс реализуется одним POVM, не зависящим от направления (iv).
- *Один общий POVM для всех параметров.* Да, равенство матричное.
- *Направленная информация против матричной CFIM.* Не равносильны, контрпример ниже.
- *Нулевые исходы.* Допустимы в (ii); при D1 дают 0; в нашей модели насыщающему POVM они не нужны (чистых векторов нет).
- *Конечность.* Предполагается; бесконечные и борелевские POVM не покрыты.
- *Разделённое → неразделённое.* Ядерная часть 2′ (в любой форме, включая буквальную) влечёт (iii) по рассуждению §A для S₋, а (iii) ⇒ (iv). Обратно, (iii) даёт ядерную часть 2′ в ослабленной форме (нули λ разрешены). Буквальная форма требует дополнительно разложения без смешанных направлений: для S₊ это выполнено (§A). Модель, где (iii) верно, а буквальная 2′ нет, не построена `[OPEN]`.
- *Точное сохранение F_C = F_Q.* В (iii) ⇒ (iv) каждое равенство точное.

**Контрпример: каждое направление насыщаемо, матрица нет** (внутри предпосылок). Чистый кубит ρ₀ = |0⟩⟨0| (r₊ = r₀ = 1), L₁ = σ_x, L₂ = σ_y, то есть A₁ = 1, A₂ = i. F^Q = Re⟨0|σ_iσ_j|0⟩ = δ_ij. Условие y ∈ Y_S(x): y ∈ ℝx и −iy ∈ ℝx, откуда y = 0, а чистых ненулевых y нет. Значит, I₁ ∉ cone и матричная граница не насыщается ни в одной из конвенций T4. Для каждого направления u подмножество из одного параметра L_u насыщаемо: Y(x) ≠ {0}. В нашей модели тот же эффект даёт S₋: все направления насыщаемы (T5 в `CONVENTION_RESOLUTION.md`), все 11-подмножества насыщаемы, а 12-подмножество нет (условно на V5.1).

**Вне предпосылок.** Для семейств с растущим рангом (F_R в `CONVENTION_RESOLUTION.md`, T3) вклад нулевого эффекта может превышать N_E (численно: след 2,57 против 0,83). Тогда шаг с равенством ломается, и T4 не утверждается.

**Сравнение с `CONVENTION_RESOLUTION.md` T4.** Содержание совпадает. Независимый вывод добавляет: (1) варианты ∀h и многомерного предела равносильны (iii), так что риск §7.2 о кванторе закрыт везде, кроме «∃h произвольная»; (2) квадратичный коэффициент ¼N_E выведен для любого семейства постоянного ранга, а не только для F_U. Расхождений не найдено, зависящие утверждения пересматривать не нужно.
