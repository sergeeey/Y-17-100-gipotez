Статус: аналитическая редукция с предположениями (H-SLD), (H-lim), (H-fin) ниже. Версия 2 исправляет ошибки, найденные независимым аудитом (агент skeptic, без истории работы): индексы S, шаг §6b, пустой гэп G2. Evidence: [DERIVED-hand] — вывод на бумаге, не аудирован внешним человеком; [VERIFIED-float] — численная проверка малой семьи или A0; [TEXT] — из первоисточника.

Индексы. Всё в этом документе с 0-based индексами, как в CONVENTION_RESOLUTION (строка 3: S+ = {0..11}, S− = {4..15}) и в `code/c3d_cell_certificate_adapted.py` (`range(4,16)`). Версия 1 писала «{4..15} 1-based», это было ошибкой.

## 0. Что нужно доказать

Для конечного POVM {E_k} на C²² с F^C_D2(h) = F^Q_S (S = S− = {4..15}, 0-based) вывести
  I₂₀ ∈ 𝒞_S := cone{yy† : y ∈ 𝒴_S}, 𝒴_S = ⋃_x Y_S(x), Y_S(x) = {y : A_i†y = λ_i x, λ_i ∈ ℝ, i ∈ S}.
Тогда отрицательный сертификат (I₂₀ ∉ 𝒞_{S−}, R + O3 v2) исключает и D2-насыщение.

Предположения:
- (H-SLD) L_i — SLD семьи ρ_θ при θ0. Без этого F^Q = Σ N_E неверно, и сама постановка не согласована. Следствие: в §6a W(u) = A_u/2.
- (H-lim) для каждого исхода и каждого куска предел F_t(h) = lim_{t→0} F_t существует вдоль выбранного h. Это часть определения D2.
- (H-fin) POVM конечен. Для борелевского POVM нужна перестановка предела и интеграла, см. G5.
- (C) семья C¹ по θ, постоянного ранга 2 вблизи θ0 (A1).

## 1. Насыщение и покусочная равность [DERIVED-hand]

Пусть E_k — элемент POVM, E_k = Σ_j e_j, e_j = y_j y_j† (спектральное разложение, ≤ 22 кусков). Для любого θ_t = θ0 + th с p_E(θ_t) > 0 по Коши–Шварцу
  F_t(E) := (Σ_j ∂p_j)(Σ_j ∂p_j)ᵀ / Σ_j p_j ≤ Σ_j ∂p_j ∂p_jᵀ / p_j =: Σ_j F_t(e_j),
причём куски с p_j(θ_t) = 0 имеют ∂p_j(θ_t) = 0 (положительность) и выпадают. Это точное неравенство для каждого t, не только в пределе.

Предел: F_lim(E) ≤ Σ_j F_lim(e_j) (конечная сумма, пределы существуют по (H-lim)).

Квантовая сторона линейна: N_E = Σ_j N_j, N_j := N_{e_j}(θ0).

## 2. Ограничение на куски: F_lim(e_j) ≤ N_j [DERIVED-hand]

Для кусков с p_j(θ_t) > 0 (t ≠ 0) классическая квантово-классическая граница на отдельном исходе (YPZJ Eq. 9, [TEXT]) даёт F_t(e_j) ≤ N_j(θ_t), где N_j(θ) использует SLD в точке θ. Для кусков с p_j(θ_t) = 0 имеем F_t(e_j) = 0 ≤ N_j(θ_t) (PSD). Для постоянного ранга семья SLD непрерывна (ненулевые собственные значения ρ_θ непрерывны), значит N_j(θ_t) → N_j(θ0). Переходя к пределу: F_lim(e_j) ≤ N_j.

Важно: этот шаг не требует, чтобы h был невырожденным (hᵀN_jh > 0). Версия 1 пыталась обосновать ту же оценку через «s_j > 0», и это было неверным шагом (аудит, пункт (f)).

## 3. Равенство и покусочное насыщение [DERIVED-hand]

Насыщение F_lim(E_k) = N_k для всех k (сумма по k даёт F^Q = Σ N_k, см. T-сумма в CONVENTION_RESOLUTION). Тогда цепочка
  N_E = F_lim(E) ≤ Σ_j F_lim(e_j) ≤ Σ_j N_j = N_E
даёт равенства: F_lim(e_j) = N_j для всех j. F_lim(e_j) — предел матриц ранга ≤ 1, значит rank N_j ≤ 1 для каждого куска.

## 4. Регулярные куски ⇒ y ∈ 𝒴_S [DERIVED-hand, аудит (b) подтверждён]

Регулярный кусок e = vvᴴ, v = (a, b), a ∈ ℂ², b ∈ ℂ²⁰, p = a†R0 a > 0. Насыщение F = N означает (по YPZJ thm:reg, [TEXT], и выкладкой через Gram-матрицу): g_a := A_aᴴ b, и разность N − F есть Gram-матрица проекций g_a на вещественное ортодополнение к a. Она равна нулю ⇔ A_aᴴ b = λ_a a, λ_a ∈ ℝ. Значит b ∈ Y_S(a) ⊂ 𝒴_S.

## 5. Нулевые куски ⇒ y ∈ 𝒴_S [DERIVED-hand, аудит (c) подтверждён]

Нулевой кусок: E00 = yyᴴ, в блоке ℂ²⁰ с p = 0 при θ0. Квантовая сторона N_ab = Re⟨g_a, g_b⟩_{R0}, g_a = A_aᴴ y.
Для вещественных x: xᵀ(Re G)x = ‖Σ_a x_a g_a‖²_{R0}. Значит rank N = dim_ℝ span_ℝ{g_a}. По §3 rank N_j ≤ 1 ⇒ все g_a вещественно пропорциональны одному вектору z: g_a = λ_a z, λ_a ∈ ℝ. Отсюда y ∈ Y_S(z) ⊂ 𝒴_S. Если N_j = 0, то g_a = 0 и y ∈ Y_S(0).

## 6. Смешанные исходы (G2 закрыт) [DERIVED-hand]

Регулярный элемент E (p_E(θ0) > 0) может содержать нулевые куски. Для них ∂p_j(θ0) = 0 (ρ_θ0 y = 0 и ∂ρ на ℂ²⁰-блоке при θ0 равно 0, аудит (a)). Значит, в регулярном вкладе F(E) = ∂p∂pᵀ/p нулевые куски не участвуют, а N_j ≥ 0 входит в N_E. **[ОПРОВЕРГНУТО, версия 3, G2 открыт].** Прежний вывод «насыщение требует N_j = 0 для нулевых кусков» не доказан. Контрпример E = I (A0, sa.load_A, `g2_decomposition.py`): разложение I₂₂ на рангово-один куски даёт нулевые куски с p_j(θ0) = 0 и ∇p_j(θ0) = 0 точно, но Σ_j tr N_j = tr F^Q = 60152 > 0. То есть ∇p_j = 0 не влечёт N_j = 0. Причина структурная: для любого E ≥ 0 классическая часть (p, ∂p) зависит от E11 и E12 (блоки ∂ρ нулевые на C²⁰×C²⁰), а квантовая N_E — только от E22. Поэтому поэлементный переход от F(E) = N_E к N_j = 0 не следует из ∂p = 0. Нужен блочный разбор регулярных E; это следующий шаг.

## 7. Сборка [DERIVED-hand, аудит (d): для конечного POVM подтверждён]

I₂₀ = Σ_k (блок 20×20 элемента E_k) — блок 20×20 тождества POVM (конечная сумма). По §4 и §5 каждый слагаемый, то есть блок каждого куска, лежит в 𝒞_S; 𝒞_S — конус, замкнут относительно сложения. Значит I₂₀ ∈ 𝒞_S.

Направление переноса: D2-насыщение (при (H-SLD), (H-lim), (H-fin), (C)) ⇒ I₂₀ ∈ 𝒞_S ⇒ противоречие с сертификатом R (I₂₀ ∉ 𝒞_{S−}). Обратное не нужно для отрицательного результата.

## 8. Что переходит без изменений

- Множество 𝒴_S и конус 𝒞_S те же, что в D1. Разделитель R и сертификат O3 v2 (3 955 841 лист, 0 отказов) не меняются.

## 9. Разрывы

- **G1 — закрыт аналитически, проверен численно для линейной семьи** (§9a). Формула F(h) = (N_E h)(N_E h)ᵀ/(hᵀN_E h) выведена для hᵀNh > 0 и не нужна в §§2–5 (там используется только F_lim ≤ N).
- **G3 — закрыт** (§2, §3): выбор h не нужен; требуется только существование предела по (H-lim) для h, при котором насыщение выполнено.
- **G5 (открыт) — борелевский POVM.** Перестановка предела D2 с интегралом по исходам не обоснована; нужна мажорируемая сходимость или явный довод. Поэтому утверждение ограничено конечными POVM (H-fin). Версия 1 говорила о борелевском случае без обоснования.
- **G6 (открыт) — тождество 4N = N_E (W-форма §9a ↔ определение CONVENTION_RESOLUTION §2).** На A0 проверено численно (§9b), но проверка частично тавтологична (см. §9b). Независимый вывод для C¹-семьи — только аналитический (§9a).

## 9a. G1: предел D2 для нулевого куска (линейная семья)

Для семьи ρ_θ = V M V†, V = [[I₂],[tW + O(t²)]], W(u) = A_u/2 (H-SLD). Для нулевого E = [[0,0],[0,E00]]:
- p(θ0+th) = t²·N(h,h) + O(t³), N(u,v) := Re tr(W(u) M W(v)† E00);
- ∂_u p = 2t·N(h,u) + O(t²);
- F_t → 4N(h,u)N(h,v)/N(h,h) при N(h,h) > 0.
Здесь N(u,v) = Re tr(W(u) M W(v)† E00) — форма с W = A/2, то есть N = N_E/4, где N_E,ab = Re tr(E00 A_a Q A_bᴴ) — форма из CONVENTION_RESOLUTION §2 (`[TEXT]` для определения, `[VERIFIED-float]` для ¼: p/(t²·hN_Eh/4) = 1.000000 при sa.load_A, `n_identity_a0_sa.py`). Итог: p = t²·hᵀN_Eh/4 и F = (N_E h)(N_E h)ᵀ/(hᵀN_E h) ≤ N_E. Множитель 4 в «4N» происходит из W = A/2 (H-SLD, аудит (e)), а не из Коши–Шварца: Коши–Шварц даёт F ≤ N_E без множителя. Обозначения: N_Q в этом документе не используется; вместо него N_E.

Численно (`g1_check.py` в scratchpad, линейная семья, ранг 2, E00 ранга 20): max|F_t − формула| ≤ 10⁻¹³ при t = 10⁻²…10⁻⁴ (`g1_check.py`); uᵀFu ≤ uᵀN_E u выполнено (N_E = 4N).

Для hᵀNh = 0 формула не даёт предел (аудит (h): контрпример с членом t⁴ даёт F_lim = 4rrᵀ/‖f₂‖² ≠ 0, хотя T2 ставит 0). Но §§2–3 не используют эту формулу, поэтому контрпример не ломает вывод: там нужна только оценка F_lim ≤ N, а не её значение.

## 9b. G6: тождество 4N = N_E на A0 [VERIFIED-float + DERIVED-hand]

Скрипт `code/n_identity_a0.py`, лог `metrics/n_identity_a0.log` (версия 2 — S = range(4,16), 0-based):
- L_i из блоков A0 (16 блоков 20×2) по определению L = [[0,Aᴴ],[A,0]]. Семья V = [[I₂],[Σθ_iA_i/2]], Q = diag(1/3, 2/3). Проверка ∂_iρ = (L_iρ + ρL_i)/2 с ошибкой 2.5·10⁻¹⁵ — это проверка (H-SLD) семьи, которая строится так, что выполняется тождественно; поэтому она **не независима** и подтверждает только согласованность построения.
- N_E,ab = Re tr(E L_a ρ L_b) совпадает с Re tr(E00 A_a Q A_bᴴ) с ошибкой 7·10⁻¹². Это алгебраическое тождество (L_aρL_b = [[0,0],[0,A_aQA_bᴴ]] при любых A), то есть проверка подтверждает алгебру, а не нормировку.
- Предел D2 вдоль h для линейной семьи совпадает с (N_E h)(N_E h)ᵀ/(hᵀN_E h) с относительной ошибкой 10⁻¹⁰ (только для линейной семьи, см. 9a).

Итог: нормировка 4N = N_E подтверждена алгебраически и согласована с (H-SLD). Независимой численной проверки, которая могла бы опровергнуть тождество, не проводилось.
