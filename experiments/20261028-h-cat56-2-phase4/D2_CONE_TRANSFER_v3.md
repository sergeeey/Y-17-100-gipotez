## 0. Постановка и соглашения

- Канонические матрицы: `A = sa.load_A(instance)` (сертификатная конвенция, `A_a = −2i·(re + i·im)`). `a ∈ S`, `S = {4,…,15}` (0-based), `x ∈ ℝ^S`, `M_x = Σ_{a∈S} x_a A_a` (20×2).
- `ρ_0 = diag(Q, 0)` на `ℂ² ⊕ ℂ²⁰`, `Q = diag(1/3, 2/3)`. `L_a = [[0, A_aᴴ],[A_a, 0]]`, `∂_aρ = ½{ρ, L_a}`.
- Квантовая доля исхода: `N_E,ab = Re tr(E L_a ρ L_b)`. Для блочного E = [[P,B],[Bᴴ,D]]: `L_aρL_b` лежит в блоке ℂ²⁰, поэтому **N_E зависит только от D = E₂₂**:
  `N_E,ab = Re tr(D A_a Q A_bᴴ)`.
- Классическая доля регулярного исхода (p_E(θ0) > 0): `F_E = ∂p ∂pᵀ / p`, `p = tr(QP)`, `∂_a p = Re tr(B A_a Q)`. Зависит от P и B.
- `Σ_E N_E = F^Q` (полнота POVM; вещественные части следов равны).
- **D2, направление h.** Для конечного POVM `F_D2(h) = lim_{t→0} F^C(θ0 + th)`, где нулевые исходы входят со своими пределами. Насыщение «по направлению h»: `F_D2(h) = F^Q` как матрицы. Результат ниже использует одно направление h; из этого следует случай «все направления».
- **Семья F_U** (контролируемая): `ρ_θ = U_θ ρ U_θᴴ`, `U_θ = exp(Σθ_i X_i)`, `X_i = [[0, −B_iᴴ],[B_i, 0]]`, `B_i = A_i/2`. Первый порядок совпадает с L_i (CONVENTION_RESOLUTION §1).

## 1. Блочная формула дефицита (Лемма 1)

**Утверждение.** Пусть `E = [[P,B],[Bᴴ,D]] ⪰ 0`, `P ∈ ℂ^{2×2}`, `B ∈ ℂ^{2×20}`, `D ∈ ℂ^{20×20}`, `p := tr(QP) > 0`. Положим `R := D − BᴴP⁺B`, `M := M_x`, `c := BMQ`. Тогда для всех `x ∈ ℝ^S`:

`xᵀ(N_E − F_E)x = Re tr(R M Q Mᴴ) + [ T₁ − T₂ ]`,
`T₁ := Re tr(W Q⁻¹ Wᴴ)`, `W := ZMQ`, `Z := P^{+1/2}B`,
`T₂ := (Re tr c)² / p`.

Кроме того: (a) `T₁ − T₂ ≥ 0`; (b) `T₁ − T₂ = 0` ⇔ `Im tr c = 0` и равенство в неравенстве Коши–Шварца, т.е. `ZM = μ P^{1/2}` для некоторого **μ ∈ ℝ** (знак μ не ограничен); (c) `R ⪰ 0`.

**Доказательство.**

*Шаг 1 (положительность и область значений).* `E ⪰ 0` ⇔ `P ⪰ 0`, `ran B ⊆ ran P`, `D − BᴴP⁺B ⪰ 0` (обобщённое дополнение Шура). Отсюда `R ⪰ 0` — это (c).

*Шаг 2 (представление B).* Положим `Z := P^{+1/2}B`. Тогда `P^{1/2}Z = ΠB = B` (Π = PP⁺ — проектор на ran P, и `ran B ⊆ ran P`), и `ZᴴZ = BᴴP⁺B`.

*Шаг 3 (классическая часть).* `c = BMQ = P^{1/2} Z M Q = P^{1/2} W`. Далее `tr c = tr(P^{1/2}W)`.

*Шаг 4 (квантовая часть).* `xᵀNx = Re tr(D MQMᴴ)`. Подставляем `D = ZᴴZ + R`. По циклическости следа `tr(ZᴴZ·MQMᴴ) = tr(Z·MQMᴴ·Zᴴ)`. Поскольку `W = ZMQ`, имеем `W Q⁻¹ Wᴴ = ZMQ·Q⁻¹·QMᴴZᴴ = ZMQMᴴZᴴ`. Значит `Re tr(ZᴴZ·MQMᴴ) = Re tr(WQ⁻¹Wᴴ) = T₁`, и `xᵀNx = T₁ + Re tr(RMQMᴴ)`.

*Шаг 5 (сборка).* `xᵀ(N_E − F_E)x = T₁ + Re tr(RMQMᴴ) − (Re tr c)²/p = Re tr(RMQMᴴ) + (T₁ − T₂)`. Это тождество, проверено численно (лог C1, ошибка 5·10⁻¹⁶).

*Шаг 6 (неотрицательность T₁ − T₂).* Факторизуем след: `tr c = tr(P^{1/2}W) = tr(W P^{1/2}) = tr(Y·K)`, где `Y := WQ^{−1/2}`, `K := Q^{1/2}P^{1/2}`. Тогда `‖Y‖_F² = tr(YᴴY) = tr(Q^{−1/2}WᴴWQ^{−1/2}) = tr(WQ⁻¹Wᴴ) = T₁` (по циклическости), и `‖K‖_F² = tr(KᴴK) = tr(P^{1/2}QP^{1/2}) = tr(QP) = p`.
Неравенство Коши–Шварца `|tr(YK)| = |⟨Yᴴ, K⟩_{HS}| ≤ ‖Y‖_F‖K‖_F` даёт `|tr c|² ≤ p·T₁`. Отсюда `(Re tr c)² ≤ |tr c|² ≤ p·T₁`, т.е. `T₁ − T₂ ≥ 0`. Факторизация использует только `P^{1/2}` и `Q^{±1/2}`, поэтому справедлива и для rank(P) = 1 (a) доказано.

*Шаг 7 (равенство).* `T₁ − T₂ = 0` требует (i) `Im tr c = 0` (тогда `(Re tr c)² = |tr c|²`) и (ii) равенство в Коши–Шварце, т.е. `Y = κ K†` для некоторого `κ ∈ ℂ`. Из (ii): `WQ^{−1/2} = κ P^{1/2}Q^{1/2}`, т.е. `W = κ P^{1/2} Q`. Тогда `tr c = κ·tr(P^{1/2}P^{1/2}Q) = κ p`, и (i) ⇒ `κ ∈ ℝ`. Итог: `W = μ P^{1/2}Q` с **μ ∈ ℝ** (знак не фиксирован; версия v2 утверждала μ ≥ 0 — это ошибка, исправлена, см. §10). Из `ZMQ = μ P^{1/2}Q` (Q обратим) получаем `ZM = μ P^{1/2}`, значит `BM = P^{1/2}ZM = μ P`. (b) доказано.

*Численная проверка* (лог C2a, C2b): при μ ∈ {0.7, −0.7, −3.2} скобка `T₁ − T₂` равна 0 с точностью до 1.4·10⁻¹⁴ (достаточность). Необходимость: при c = μPQ + εG скобка/ε² постоянна и положительна (C2b). Знак μ не влияет на равенство. Прямая проверка необходимости по всему классу c — это аналитический шаг 7, он не покрыт численно полностью.

## 2. Регулярные исходы (Лемма 2)

**Утверждение.** Пусть `E ⪰ 0`, `tr(QP) > 0`, и `xᵀ(N_E − F_E)x = 0` для всех `x ∈ ℝ^S` (матричное насыщение по всем направлениям S). Тогда:
(i) `BA_a = μ_a P` для всех `a ∈ S`, `μ_a ∈ ℝ`;
(ii) `R A_a = 0` для всех `a ∈ S`;
(iii) `D ∈ cone{yyᴴ : y ∈ 𝒴_S}`, где `𝒴_S = ⋃_{x≠0} Y_S(x)`.

**Доказательство.**

(i) Из Леммы 1 при `x = e_a` (т.е. `M = A_a`): обе скобки равны нулю, значит `BA_a = μ_a P` с μ_a ∈ ℝ.

(ii) При насыщении `Re tr(R M_x Q M_xᴴ) = 0` для всех `x`, в частности `x = e_a`: `tr(A_aᴴ R A_a Q) = 0`. Матрица `A_aᴴRA_a ⪰ 0`, `Q ≻ 0`, значит `A_aᴴRA_a = 0`, и `RA_a = 0` (так как `R ⪰ 0`).

(iii) Разложим `BᴴP⁺B = ZᴴZ` по строкам Z. Пусть `z_r` — r-я строка Z (1×20), `w_r := z_rᴴ ∈ ℂ²⁰`. Тогда `ZᴴZ = Σ_{r=1,2} w_r w_rᴴ`.
Из `BA_a = μ_a P` и `Z = P^{+1/2}B`: `ZA_a = P^{+1/2}BA_a = μ_a P^{+1/2}P = μ_a P^{1/2}`. Строка r: `z_r A_a = μ_a (P^{1/2})_{r,:}`, сопряжённо: `A_aᴴ w_r = μ_a c_r`, `c_r := ((P^{1/2})_{r,:})ᴴ ∈ ℂ²`. Значит `w_r ∈ Y_S(c_r)` при `c_r ≠ 0`, и `w_r ∈ Y_S(0) ⊆ 𝒴_S` при `c_r = 0` (тогда λ_a = 0 допустимы при любом x ≠ 0).
Остаток `R ⪰ 0` с `RA_a = 0`: спектральное разложение `R = Σ_j y_j y_jᴴ` даёт `A_aᴴ y_j = 0`, т.е. `y_j ∈ Y_S(0)`. Итого `D = Σ_r w_r w_rᴴ + Σ_j y_j y_jᴴ ∈ cone{yyᴴ : y ∈ 𝒴_S}`. ∎

*Замечание о rank(P) = 1 и P > 0.* Формулы содержат только P^{1/2}, P⁺ и Z = P^{+1/2}B; случай rank 1 получается автоматически (тогда `Z` имеет rank ≤ 1 и одна из `w_r` равна нулю). Проверено численно: тождество (C1, ошибка 5·10⁻¹⁶, алгебраическое); эквивалентность «E ⪰ 0 ⇔ R ⪰ 0» на 200 случайных примерах с обоими знаками (C1b, 200/200). Прежняя формулировка «R ⪰ 0 на случайных примерах» была тавтологией: R задавалась равной положительному слагаемому, поэтому проверка не могла провалиться (замечание аудита З1).

## 3. Нулевые исходы в D2 (Лемма 3)

Нулевой исход: `p_E(θ0) = 0` ⇔ `E = [[0,0],[0,D]]` (PSD-блоки). Для него `F_E ≡ 0` (регулярной части нет).

**(3a) Точная нулевая норма.** Пусть `h ∈ ℝ^S`, `hᵀN_Eh = 0`. Для E = yyᴴ (после суммирования по разложению D) это даёт `Q^{1/2}B_h† y = 0`, где `B_h = Σh_a A_a/2`, т.е. `B_h†y = 0`. Тогда `X_h w = 0` (w = (0;y)), и `U_{th} w = w` **точно** для всех t. Значит `p_E(th) ≡ 0` и F_lim(E,h) = 0. Для суммы по разложению D: `hᵀN_Eh = Σ_j hᵀN_{y_j}h = 0` ⇒ каждое `hᵀN_{y_j}h = 0` ⇒ каждое `p_{y_j}(th) ≡ 0` ⇒ `p_E(th) ≡ 0`. Это доказывает утверждение v2 §9a для F_U точно, а не только численно (лог C3: |p| ≤ 3·10⁻¹⁷).

**Соглашение (обязательно, замечание аудита З4).** Вклад нулевого исхода в CFIM определяется как 0, когда p_E ≡ 0 на луче θ0 + th (выражение ∇p∇pᵀ/p имеет вид 0/0). Это часть определения D2, принятая в настоящем документе: F_lim(E,h) := 0 при p_E(θ0 + th) ≡ 0. Для D2 в другом соглашении (например, с тем же исходом, но иначе определённым пределом) результат не переносится автоматически.

**(3b) Ненулевая норма.** Пусть `hᵀN_Eh > 0`. Тогда `p_E(th) = ¼ t² hᵀN_Eh + O(t³)`, `∇p_E(th) = (t/2) N_E h + O(t²)`, и
`F_lim(E,h) = (N_E h)(N_E h)ᵀ / (hᵀN_E h) ⪯ N_E` (неравенство Коши–Шварца для PSD N_E).
Формула совпадает с CONVENTION_RESOLUTION §3 (T2) [DERIVED-hand]. Остаточный член в документе записан консервативно как O(t³). Аудит (З7) указал, что для F_U верхний блок `e^{−X}w` даёт `B_hᴴy + O(θ³)`, а поправка третьего порядка переходит в нижний блок, так что `p = ¼θᵀNθ + O(θ⁴)` — это наблюдение аудита [INFERRED], не проверенное отдельно. Численно предел подтверждён (лог C4: относительная ошибка 6.9·10⁻¹ → 9.5·10⁻³ → 9.5·10⁻⁵ при t = 10⁻²…10⁻⁴, то есть убывание порядка t²; на t = 10⁻² асимптотика ещё не установилась).

**(3c) Насыщение нулевого исхода.** Из `F_lim(E,h) = N_E` при hᵀN_Eh > 0 следует `N_E = (N_Eh)(N_Eh)ᵀ/(hᵀN_Eh)`, т.е. `rank N_E ≤ 1`. При hᵀN_Eh = 0 насыщение означает `N_E = 0`.

**(3d) Конусность нулевого исхода.** Лемма 4 (ранг-один): для `y ∈ ℂ²⁰`, `rank N_{yyᴴ} ≤ 1` ⇔ `∃ z ∈ ℂ²: A_aᴴy = λ_a Q^{−1/2}z`, λ_a ∈ ℝ, т.е. `y ∈ 𝒴_S`.
*Доказательство.* `N_{yyᴴ}` — действительная Грамова матрица векторов `g_a = Q^{1/2}A_aᴴy ∈ ℂ²`: `(N)_{ab} = Re⟨g_a, g_b⟩`. Её ранг равен `dim_ℝ span_ℝ{g_a}` (вещественная Грамова матрица комплексных векторов). Ранг ≤1 ⇔ все `g_a` лежат в одной вещественной прямой `ℝz` ⇔ `g_a = λ_a z`, λ_a ∈ ℝ. ∎
Для произвольного нулевого E: `N_E = Σ_j N_{y_jyⱼᴴ}` (спектральное разложение D); если `rank N_E ≤ 1`, то `N_{y_j} ⪯ N_E` и `rank N_{y_j} ≤ 1` ⇒ `y_j ∈ 𝒴_S`. Если `N_E = 0`, то все `N_{y_j} = 0` ⇒ `A_aᴴy_j = 0` ⇒ `y_j ∈ Y_S(0)`. Итого `D_E ∈ cone{yyᴴ : y ∈ 𝒴_S}`.

**Смешанные элементы.** В D2 мы не разлагаем регулярный исход на нулевые куски; регулярный исход рассматривается целиком в Лемме 2. Поэтому «G2» в его прежней формулировке (поэлементный переход `N_j = 0`) не используется. Опровергнутый шаг v2 §6 заменён Леммой 2 (блочной).

## 4. Аддитивность и поэлементное насыщение (конечные POVM)

Пусть `{E_k}` конечный POVM, для каждого k существует `F_lim(E_k,h)` (H-lim). Тогда:
(a) `F_D2(h) = Σ_k F_lim(E_k,h)` (конечная сумма пределов);
(b) для регулярных k: `F(E_k) ⪯ N_{E_k}` (Лемма 1, (a)); для нулевых k: `F_lim(E_k,h) ⪯ N_{E_k}` (Лемма 3, (3b)), или `=0 ⪯ N_{E_k}`;
(c) `Σ_k N_{E_k} = F^Q`.
Из `F_D2(h) = F^Q` и (a)–(c): `Σ_k (N_{E_k} − F_lim(E_k,h)) = 0`, каждое слагаемое ⪰ 0 ⇒ **каждое равно нулю**. Это поэлементное насыщение.

## 5. Теорема (конечные POVM)

**Теорема A.** Пусть `{E_k}` — конечный POVM на ℂ²², семья F_U (§0), `S = {4,…,15}`, и `F_D2(h) = F^Q` для некоторого `h ∈ ℝ^S`. Тогда `I₂₀ ∈ cone{yyᴴ : y ∈ 𝒴_S}`.

**Доказательство.** По §4 каждый исход насыщен. Регулярные исходы — по Лемме 2 (требуется матричное насыщение по всем x, которое даёт §4 для регулярных k, т.к. `F(E_k)` не зависит от h). Нулевые — по §3 (3c, 3d). Сумма блоков `E₂₂`: `Σ_k E_{k,22} = I₂₀` (блок тождества). Каждое `D_k ∈ cone`, cone замкнут относительно сложения ⇒ `I₂₀ ∈ cone`. ∎

**Примечание к hypothesis.** Теорема использует одно направление h. Если в определении насыщения требуется «для всех h», то условие сильнее и вывод тем более верен.

## 6. Счётные и борелевские POVM (G5) — **открыто**

Для счётного POVM `{E_k}` сумма `Σ_k F_lim(E_k,h)` ≤ `F^Q` (Fatou по частичным суммам), но равенство `lim_t Σ_k F_k(θ_t) = Σ_k lim_t F_k(θ_t)` не следует. Без него насыщение не даёт поэлементного равенства §4.

Достаточное условие (**тугость**): `lim_{K→∞} limsup_{t→0} ‖Σ_{k>K} F_k(θ_t)‖ = 0`. Тогда перестановка законна и Теорема A переносится на счётный POVM. Для борелевского POVM аналогичное условие на хвосты интеграла. **Барьер:** тугость не выводится из условий P-reg, F_U и конечности F^Q; нужен отдельный довод (мажорируемость `F_k(θ_t) ≤ N_k(θ_t)`, `Σ_k N_k(θ_t) → F^Q`) — это следующий шаг. Утверждение для счётных и борелевских POVM **не доказано**.

## 13. Обратная часть Леммы 4 и сверка с сертификатом

**Лемма 4 (полная, аналитически).** Для `y ∈ ℂ²⁰` при `Q ≻ 0`: `rank N^S(yyᴴ) ≤ 1 ⇔ y ∈ 𝒴_S`.
- (⇒) rank 1: `g_a = Q^{1/2}A_aᴴy` лежат в одной вещественной прямой, `g_a = λ_a z`, `λ_a ∈ ℝ`, значит `A_aᴴy = λ_a Q^{−1/2}z`, т.е. `y ∈ Y_S(Q^{−1/2}z)` при `z ≠ 0`.
- (⇒) rank 0: все `A_aᴴy = 0`; тогда `y ∈ Y_S(x)` для любого `x ≠ 0` с `λ_a = 0`. Поэтому `Y_S(0)` в тексте означает именно этот случай, а не `x = 0` (определение требует `x ≠ 0`).
- (⇐) `y ∈ Y_S(x)`: `g_a = λ_a Q^{1/2}x`, все лежат в вещественной прямой, rank ≤ 1.
Точное доказательство; численный поиск минимизатора `σ₂/σ₁` не нужен и не проводился (фоновая задача `bx4vwms5k` остановлена).

**Сверка с сертификатом** (`code/s14_ycone_colgen.py`, `s11_cone_saturation`):
- Загрузка матриц: `sa.load_A` — та же конвенция `−2i`, что в §0 и C-проверках.
- Индексы S: 0-based список (`spec` → `S = [int(t) …]`); для S− это `{4..15}`, как в §0.
- Определение 𝒴_S: `Y_S(x) = {y : A_iᴴy = λ_i x, λ_i ∈ ℝ, i ∈ S}`, `𝒴_S = ⋃_x Y_S(x)` — совпадает с §0.
