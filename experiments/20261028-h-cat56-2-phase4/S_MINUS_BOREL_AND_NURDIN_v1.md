# S−: произвольные (борелевские) POVM и предложение Nurdin о составной матрице c_lm (v1, 2026-10-31)

Продолжение `S_MINUS_FINAL_v1.md`. Здесь: (A) точная область доказанного для D2; (B) препятствие для борелевских POVM с точной формулировкой недостающей леммы; (C) проверка предложения Nurdin c_lm и новое ограничение для S−.

## A. Что доказано для D2 (точная область)

Теорема A (`S_MINUS_FINAL_v1.md` §2): для конечного или счётного POVM {E_k} в семье F_U и одного направления h: если F_D2(h) = F^Q_S, то I₂₀ ∈ 𝒞_S. Для S = S− = {4..15} I₂₀ ∉ 𝒞_S (сертифицировано, O3 v2). Значит такого POVM нет.

Максимальный класс, который закрыт аналитически: **конечные и счётные POVM**. Борелевский случай не закрыт (ниже).

## B. Борелевские POVM: представление, предельный переход, препятствие

**B1. Определение CFIM для несчётных исходов.** Для POVM M на борелевском пространстве исходов X с плотностью ρ_θ классическая информация Фишера обычно определяется двумя эквивалентными способами: (i) интегралом ∫ (∂f_θ)²/f_θ dμ по доминирующей мере μ (f — плотность p_θ(·) = tr(ρ_θ M(·)) относительно μ); (ii) супремумом F_P по конечным разбиениям P пространства X (для абсолютно непрерывного семейства совпадает с (i) — классическая теорема Дмитриева–Левита). Для D2 нужно семейство по θ, поэтому доминирующая мера должна быть одна на всей траектории θ_t: её нельзя взять как μ_0 = p_{θ_0}, потому что на нулевых по вероятности в θ_0 исходах p_{θ_t} не абсолютно непрерывна относительно μ_0 (это и есть «нулевые исходы в D2»). Поэтому определение (ii) с супремумом по разбиениям — естественный выбор.

**B2. Монотонность по разбиениям.** Для разбиений P ≤ P' (P' измельчает P) имеем F_P(θ) ⪯ F_{P'}(θ) при каждом θ с p>0 (обработка данных для классической информации Фишера, матричная версия). Поэтому для каждой траектории θ_t предел D2 по разбиению F_{P,D2}(h) := lim_t F_P(th) (существует для конечного P по теореме A-конечной части: регулярные элементы непрерывны, нулевые — по лемме 3b) монотонен по P. Для счётной вложенной последовательности разбиений P_n, порождающих борелевскую σ-алгебру (существует в стандартном борелевском пространстве), F_{P_n,D2}(h) возрастает в порядке Лёвнера и ограничена F^Q.

**B3. Что нужно доказать для борелевского случая.** Пусть F^C_D2(h) := sup_n F_{P_n,D2}(h). Если F^C_D2(h) = F^Q, то (в норме) для любого ε > 0 найдётся конечное разбиение P_ε с ‖F^Q − F_{P_ε,D2}(h)‖ ≤ ε. Тогда нужна **робастная версия Теоремы A** для конечного POVM P_ε:

> **(R) Робастная лемма.** Существуют абсолютные константы c, C > 0 такие, что для любого конечного POVM с ‖F^Q_S − F_{D2}(h)‖ ≤ ε выполнено tr R* − 20 s* ≤ C·√ε, где (R*, s*) — разделитель из P6 (tr R* − 20 s* = 0.0304).

Если (R) верна с C·√ε < 0.0304, то для ε малого получаем противоречие, и борелевский случай закрыт при определении (ii) D2.

**B4. Статус (R).** Набросок доказательства имеет ту же структуру, что точная теорема A, с заменой точных равенств на оценки:
- дефект на элементе δ_k := N_k − F_lim_k ⪰ 0, Σ_k δ_k = Δ := F^Q − F_D2 ⪰ 0, ‖Δ‖ ≤ ε (это следует из ‖F^Q − F_D2‖ ≤ ε и F_D2 ⪯ F^Q);
- тождество Леммы 1 даёт для регулярного элемента: xᵀδ_kx = Re tr(R_k M_x Q M_xᴴ) + (T₁−T₂)_k(x), обе части ≥ 0;
- отсюда (Коши–Шварц по элементам) Σ_k √(tr R_k · tr δ_k) и т.п. контролируют отклонение от конуса; суммирование по k закрыто неравенством Коши–Шварца Σ_k √(a_k b_k) ≤ √(Σa_k)√(Σb_k) с Σ_k tr R_k ≤ 20 и Σ_k tr δ_k ≤ 12ε, так что число элементов не входит в оценку;
- для нулевых элементов дефект δ_k = N_k − (Nh)(Nh)ᵀ/(hᵀNh) содержит направление h в ядре и требует отдельного квантового аналога леммы 4 (rank ≈ 1 ⇔ y ≈ 𝒴_S) с линейной по δ_k оценкой.

**Статус (R): OPEN.** Главные неизвестные: (а) явная константа в аппроксимации y ≈ 𝒴_S через дефект; (б) линейная (а не √) оценка для нулевых элементов; (в) проверка, что оценки не зависят от числа элементов. Без (а)–(в) борелевский случай не закрыт.

**B5. Точное препятствие.** Борелевский случай отличается от счётного именно тем, что (R) нельзя вывести из точной теоремы A ни предельным переходом (нет поэлементного разложения), ни монотонностью без робастной оценки. Ни одного контрпримера не найдено; статус **UNKNOWN для борелевских POVM под D2**. Утверждать невозможность для всех POVM сейчас нельзя.

**Минимальный эксперимент, способный изменить результат:** численная проверка (R) на случайных конечных POVM (с ε-дефектом, построенным минимизацией ‖F^Q − F_D2‖ по POVM в выпуклой оболочке элементов) — если найдётся POVM с ‖F^Q − F_D2‖ → 0 и tr R* − 20 s* > 0 удерживается, (R) ложна и борелевская невозможность под этим определением не может быть доказана робастным методом.

## C. Предложение Nurdin о составной матрице c_lm

**C1. Что сказано в первоисточнике** (`2402.11567` v5, раздел 6 «Corrigendum», формула (10) и Condition 2′ / Theorem 3). Для нулевого (ℋ₀-) элемента E_k POVM на ℋ₀ с вещественными c^k_lm:
E_k (L_{θ_l,0+}− c^k_lm L_{θ_m,0+}) = 0 для всех l,m (через блоки SLD L_{θ,0+} = A_θ). Это и есть «составная матрица попарных ограничений с коэффициентами c_lm».

**C2. Что доказано для полного набора из 16 блоков.** `TECHNICAL_NOTE_A0_EN_v1.2.md` §4 (Proposition 2): при (S) (Herm_0(20) порождается W_{lm,σ} = i(B_lσB_mᴴ − B_mσB_lᴴ) для пар l<m и σ ∈ {I,σx,σy,σz}) никакой ненулевой E ∈ M_20(C) не удовлетворяет E(α_lm B_l − β_lm B_m) = 0 для всех пар с (α,β) ∈ R²∖{0}. Доказательство (проверено по тексту): u†(α B_l − β B_m) = 0 ⇒ αa_l = βa_m (a_l := B_lᴴu); z := a_lᴴσa_m вещественно; u†W u = 0; f(X) = u†Xu обращается в ноль на Herm_0(20) по (S), а на X₀ = uuᴴ − (|u|²/20)I равно |u|⁴(1−1/20) ≠ 0. Отсюда: **любой POVM на ℋ₀ с Condition 2′ для всех исходов состоит из нулевых элементов, что противоречит Σ E_k = I₂₀.** Это доказательство для полного набора (16 блоков). Точная проверка (S) (ранг 399) — в `rank_test_A0_and_controls.json`.

**C3. Ограничение для S−: доказательство C2 не переносится.** Для S− = {4..15} (12 блоков) число вещественных образующих W_{lm,σ} равно C(12,2)·4 = **264 < 399 = dim_ℝ Herm_0(20)**. Значит предпосылка (S) ложна для S−, и Proposition 2 для S− не выводится. Это строгое арифметическое препятствие (верхняя граница ранга span ≤ 264 < 399). Вывод: **для S− метод через составную матрицу c_lm не даёт невозможности**. Невозможность для S− обеспечивает только D2-цепочка (Теорема A + I₂₀ ∉ 𝒞_S), а не Nurdin-null-условие.

**C4. Статус предложения Nurdin.** Формулировка корректна в v5 (с корригендумом); для полного набора из 16 параметров даёт невозможность kernel-POVM (C2, PROVED-hand + проверка ранга). Для S± наборов — не применима (C3). Вывод c_lm в переписке не найден (см. HANDOFF); мы его не восстанавливаем.
