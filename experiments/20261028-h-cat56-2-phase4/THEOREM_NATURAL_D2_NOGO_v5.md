# S−: запрет для естественного борелевского D2 через равномерность по t (v5, 2026-10-31)

Закрывает открытый барьер из `THEOREM_NOGO_S_MINUS_v4.md` (естественный борелевский D2 lim_t sup_P F_P(th)). Ключевая идея: не переставлять пределы. Оценка проводится в каждой точке θ_t отдельно, а единственный переход t → 0 делается по непрерывности величин. Равномерность по t получается без равномерного Łojasiewicz: из Липшицевости по t и Łojasiewicz при t = 0.

## 0. Предпосылки

- Модель S− (`S_MINUS_FINAL_v2.md` §1): ρ_θ = U_θ ρ_0 U_θᴴ, ρ_0 = Q ⊕ 0, Q = diag(1/3,2/3); генераторы U_θ = exp(Σθ_aX_a), X_a = [[0,−G_aᴴ],[G_a,0]], G_a = A_a/2; S = {4..15}; A_a = −2iB_a^{inst} (конвенция C2).
- Θ(t) := направление h ∈ R^S, θ_t := t·h; t ∈ [0, t₀].
- SLD L_a(θ) в точке θ: решение ∂_aρ_θ = (ρ_θL_a + L_aρ_θ)/2. Спектр ρ_θ постоянен (1/3, 2/3, 0,…), поэтому L_a(θ) и ρ_θ аналитичны по θ (решение уравнения Ляпунова с постоянным спектром).
- Для вектора v ∈ C²²: N_v(θ) := (Re(vᴴ L_a(θ) ρ_θ L_b(θ) v))_{a,b∈S} ∈ S^{12}; N_v(θ) ⪰ 0 (Коши–Шварц, как в `S_MINUS_FINAL_v2.md` §4(i)).
- Для PSD E ∈ Herm₊(22): N_E(θ) := Σ_j e_j N_{v_j}(θ) при спектральном разложении E = Σ_j e_j v_jv_jᴴ (линейно по E). Полнота: Σ_k N_{E_k}(θ) = F^Q(θ) := (Re tr(ρ_θ L_aL_b))_{a,b} при Σ_k E_k = I₂₂.
- Классическая FI конечного POVM {E_k} в точке θ: F_E(θ) := Σ_{k: p_k(θ)>0} ∇p_k∇p_kᵀ/p_k, p_k(θ) = tr(ρ_θE_k), ∇p_k = (∂_a p_k)_a, ∂_a p_k = Re tr(E_k L_a(θ)ρ_θ).

## 1. Элементарные леммы в точке θ (любой θ, без предела)

**Лемма 1 (CS).** Для каждого k: F_k(θ) ⪯ N_{E_k}(θ), и rank F_k(θ) ≤ 1 (F_k = ∇p∇pᵀ/p при p > 0; F_k = 0 при p = 0).
*Доказательство.* ∂_xp_k = Re tr(E_kL_xρ) (L_x := Σ_a x_aL_a), (Re tr(EL_xρ))² ≤ tr(ρE)·tr(ρL_xEL_x) (CS по HS-скалярному произведению), то есть (∂_xp)²/p ≤ xᵀN_E x. При p = 0: F = 0 ⪯ N (N ⪰ 0). ∎

**Лемма 2 (спектральный дефект).** δ_k(θ) := N_{E_k}(θ) − F_k(θ) ⪰ 0, Σ_k δ_k(θ) = F^Q(θ) − F_E(θ) =: Δ(θ), и λ₂(N_{E_k}(θ)) ≤ tr δ_k(θ).
*Доказательство.* Вейль: λ₂(F+δ) ≤ λ₂(F) + λ₁(δ) ≤ 0 + tr δ, так как rank F ≤ 1 и δ ⪰ 0. ∎

## 2. Функция f_t и её свойства

f_t(v) := λ₂(N_v(θ_t)) для v ∈ C²², |v| = 1.

**Лемма 3 (Łojasiewicz при t = 0).** Существуют C₀, θ₀ ∈ (0,1] такие, что dist(v, 𝒱₀) ≤ C₀ f_0(v)^{θ₀} для всех единичных v ∈ C²². Здесь 𝒱₀ := {v : rank N_v(0) ≤ 1} = {v : P_y v ∈ 𝒴_S ∪ {0}}, P_y — проектор на ℋ₀ = C²⁰ (rank N_v(0) зависит только от y = P_yv: N_v(0) = Re(yᴴA_aQA_bᴴy)).
*Доказательство.* f_0 — непрерывная полуалгебраическая функция на компактной сфере (λ₂ полиномиальной матрицы), Z = f_0⁻¹(0) = 𝒱₀ ∩ S, Z ≠ ∅. Łojasiewicz (Bochnak–Coste–Roy, гл. 2–3; точная нумерация теорем не сверена). ∎

**Лемма 4 (Липшиц по t).** |f_t(v) − f_0(v)| ≤ L|t| для |v| = 1, |t| ≤ t₀, где L := sup_{|t|≤t₀,|v|=1} ‖∂_t N_v(t)‖ < ∞.
*Доказательство.* N_v(θ_t) аналитичен по t на компакте; Вейль: |λ₂(A)−λ₂(B)| ≤ ‖A−B‖. ∎

## 3. Разделитель и оценка в точке θ_t

Пусть R* ∈ Herm(20) — разделитель S−: s* := sup{yᴴR*y : y ∈ 𝒴¹_S}, γ := tr R* − 20 s* > 0 (`O3_CLOSURE_2026-10-31.md`: γ ≥ 0.0304). Пусть R̂ := diag(0, R*) ∈ Herm(22), P_y — проектор на ℋ₀. Для v = (x;y): vᴴR̂v = yᴴR*y.

**Лемма 5 (разделение в v-уровне).** Для единичного v ∈ C²² с P_yv =: y: vᴴR̂v − s*|y|² ≤ C₁·dist(v, 𝒱₀), C₁ := 2‖R*‖·(1 + 1) (зависит только от R*).
*Доказательство.* Пусть w ∈ 𝒱₀ — ближайшая точка, ỹ := P_yw ∈ 𝒴_S ∪ {0} (конус). Тогда ỹᴴR*ỹ ≤ s*|ỹ|² (определение s* и однородность конуса). Разность yᴴR*y − ỹᴴR*ỹ ≤ 2‖R*‖(|y|+|ỹ|)|y−ỹ| ≤ 4‖R*‖·|v−w| (|y|,|ỹ| ≤ 1), и |y|² − |ỹ|² ≤ 2|v−w|. Итого vᴴR̂v − s*|y|² ≤ 4‖R*‖|v−w| + 2s*|v−w| ≤ C₁ dist(v,𝒱₀) с C₁ := 4‖R*‖ + 2s*. ∎

**Лемма 6 (оценка для одного POVM в точке θ_t).** Пусть {E_k} — конечный POVM, |t| ≤ t₀. Тогда
tr R* − 20 s* ≤ C₂·[(tr Δ(θ_t))^{θ₀} + |t|^{θ₀}],
где C₂ зависит только от (R*, C₀, L, Σ_k tr E_k = 22).
*Доказательство.* Для каждого k: E_k = Σ_j e_{kj} v_{kj}v_{kj}ᴴ (≤ 22 слагаемых). Тогда
tr(R̂E_k) − s* tr(P_yE_k) = Σ_j e_{kj}(v_{kj}ᴴR̂v_{kj} − s*|P_yv_{kj}|²).
Для каждого j: по лемме 5 и лемме 3 (dist ≤ C₀ f_0^{θ₀}) и лемме 4 (f_0 ≤ f_t + L|t|):
v ᴴR̂v − s*|P_yv|² ≤ C₁C₀(f_t(v_{kj}) + L|t|)^{θ₀} ≤ C₁C₀[f_t(v_{kj})^{θ₀} + (L|t|)^{θ₀}] (субаддитивность, θ₀ ≤ 1).
По лемме 2 (λ₂(N_{E_k}) = λ₂(Σ_j e_jN_{v_j}) ≤ tr δ_k и e_j N_{v_j} ⪯ N_{E_k}): e_{kj}·f_t(v_{kj}) ≤ λ₂(N_{E_k}(θ_t)) ≤ tr δ_k(θ_t). Следовательно f_t(v_{kj})^{θ₀} ≤ (tr δ_k/e_{kj})^{θ₀}.
Складываем с весами e_{kj}:
tr(R̂E_k) − s* tr(P_yE_k) ≤ C₁C₀[(tr δ_k)^{θ₀} Σ_j e_{kj}^{1−θ₀} + (L|t|)^{θ₀} tr E_k].
Σ_j e_{kj}^{1−θ₀} ≤ 22^{θ₀}(tr E_k)^{1−θ₀} (Гёльдер). Суммируем по k: Σ_k tr(R̂E_k) = tr R* (так как Σ E_k = I₂₂), Σ_k tr(P_yE_k) = 20. По Гёльдеру Σ_k (trδ_k)^{θ₀}(trE_k)^{1−θ₀} ≤ (Σ tr δ_k)^{θ₀}(Σ tr E_k)^{1−θ₀} = 22^{1−θ₀}(tr Δ)^{θ₀}. Итог:
tr R* − 20 s* ≤ C₁C₀[22·(tr Δ)^{θ₀} + 22(L|t|)^{θ₀}]. ∎

## 4. Главная теорема (естественный борелевский D2)

**Теорема N.** При предпосылках §0 существуют c > 0 и t₁ > 0 такие, что для любого конечного POVM и любого |t| ≤ t₁:
tr(F^Q(θ_t) − F_E(θ_t)) ≥ c.
*Доказательство.* Из леммы 6: (tr Δ)^{θ₀} ≥ (γ − C₂|t|^{θ₀})/C₂ ≥ γ/(2C₂) при C₂|t|^{θ₀} ≤ γ/2, то есть tr Δ ≥ (γ/(2C₂))^{1/θ₀} =: c. ∎

**Следствие N₁ (борелевский, естественный).** Для любого борелевского POVM M положим F^C_M(θ) := sup_P F_P(θ) (по конечным разбиениям P). Тогда tr(F^Q(θ_t) − F^C_M(θ_t)) ≥ c для всех |t| ≤ t₁, поскольку для каждого P (конечный POVM) tr F_P(θ_t) ≤ tr F^Q(θ_t) − c, и след монотонно переходит к sup по возрастающей последовательности разбиений.
Следовательно, для любого предела lim_{t→0} F^C_M(θ_t) (если существует, и для любой частичной предельной точки):
tr lim ≤ tr F^Q(0) − c < tr F^Q(0)
(используется непрерывность θ ↦ F^Q(θ)). **Значит F^C_M(θ_t) не стремится к F^Q(0) ни в каком смысле, и естественный борелевский D2 (lim_t sup_P F_P(th) и любой его вариант с порядком пределов) не может равняться F^Q.** Это запрет в смысле следа, что сильнее матричного.

## 5. Что доказано, что нет

- Доказано (PROVED-hand): Теорема N для ЛЮБОГО конечного POVM (включая нулевые в точке 0, которые при t ≠ 0 становятся регулярными или остаются нулевыми — обработка в лемме 1 и 2 одинакова); Следствие N₁ для любого борелевского POVM без предположений о порядке пределов и без обмена предела и интеграла.
- Предпосылки: семья F_U (аналитичность N_v(θ) и L_a(θ); постоянный спектр ρ_θ); направление h фиксировано (можно любое); разделитель R* с γ > 0 (сертификат O3).
- Не используется: равномерный Łojasiewicz по t; D2-соглашение для нулевых исходов (не нужно, так как рассуждение в точке θ_t); монотонность по разбиениям; обмен пределов.
- Константы C₀, θ₀ экзистенциальны (Łojasiewicz при t=0); L — из аналитичности (конечная на компакте).
- Нестрогие места: «N_v(θ) аналитична по θ» для SLD — через решение уравнения Ляпунова с постоянным спектром (стандартный факт, стоит проверить явно); точная ссылка Bochnak–Coste–Roy не сверена.
