## 4. Q0-I: инвариантность к параметризации

`[INFERRED]`, вывод на бумаге. Пусть θ = Gφ с обратимой вещественной G (|S| × |S|). Тогда L′_k = Σ_i G_ik L_i, то есть A′_k = Σ_i G_ik A_i.

1. Y′_S(x) = {y : A′_k†y ∈ ℝx ∀k} = Y_S(x): вещественные линейные комбинации векторов из ℝx лежат в ℝx, а G обратима. Значит, 𝒴_S и конус cone(𝒴_S) не меняются.
2. F′^Q = GᵀF^Q G и F′^C = GᵀF^C G для любого POVM, поэтому F′^C = F′^Q ⇔ F^C = F^Q.

Следствие: достижимость — свойство вещественного подпространства W_S = span_ℝ{A_i : i ∈ S} ⊂ ℂ^{20×2}, а не выбранного базиса. Механизм контраста S₊/S₋ надо искать как свойство двух вещественных подпространств ℂ^{20×2}, порождённых 12 блоками каждое и содержащих 8 общих блоков (S₊ ∩ S₋ = {4..11}), а не отдельных блоков.

## 5. Вопрос 2: буквальное (10) против ослабленного условия

`[INFERRED]`, редукция без вычислений.

**Обозначения.** a_i := A_i†y ∈ ℂ^{r₊} — образ вектора ядра y под i-м блоком. y ∈ Y_S(x) означает a_i = λ_i(y)·x с вещественными λ_i для всех i ∈ S. Чистый вектор — y с a_i = 0 для всех i ∈ S.

**Два чтения условия (10)** для куска ранга один E = yy†:
- **H1** (буквально, все упорядоченные пары): для каждой пары (l, m) ∈ S² найдётся вещественное c_lm с a_l = c_lm·a_m.
- **H2** (вещественный ранг ≤ 1): все a_i лежат на одной вещественной прямой ℝv, то есть a_i = λ_i v с вещественными λ_i, нули разрешены.
H1 ⇒ H2. Обратное нарушается ровно в случае нулевого образа: a_m = 0 при a_l ≠ 0 проходит H2, но не проходит пару (l, m) в H1.

Для направления x пусть Z(x) = {i ∈ S : λ_i ≡ 0 на Y_S(x)}. Буквальное множество 𝒴_S^lit — векторы y, для которых при всех упорядоченных парах (l, m) найдётся вещественное c с A_l†y = c·A_m†y. В каждом волокне:
- Z(x) = ∅: 𝒴_S^lit ∩ Y_S(x) — дополнение к конечному числу гиперплоскостей, плотно. Любую форму с невырожденной матрицей Грама на Y_S(x) можно собрать из буквальных векторов (как в лемме A).
- Z(x) ≠ ∅ и Z(x) ≠ S (смешанное волокно): в 𝒴_S^lit ∩ Y_S(x) остаются только чистые векторы.

Отсюда буквальная ядерная часть 2′ может нарушаться при выполненном ослабленном условии только в двух случаях: (а) любое разложение I_{r₀} существенно использует смешанные волокна; (б) любое разложение существенно использует вырожденные (неполного ранга) блоки на волокнах без нулей. Для S₊ ни (а), ни (б) не нужны (Addendum 01 §A).

**Наблюдение для поиска контрпримера.** Если λ_i ≡ 0 на *всех* волокнах, все допустимые векторы лежат в собственном подпространстве, и I_{r₀} в конус не попадает. Поэтому контрпример требует, чтобы ограничение обнулялось на одних направлениях x и не обнулялось на других.

### 5.1. При r₊ = 1 расхождения нет

`[INFERRED]`, доказательство. При r₊ = 1 условие A_i†y ∈ ℝx зависит от x только через фазу, и Y(x) = e^{iφ}Y₀: все волокна — фазовые копии одного вещественного подпространства, а yy† от фазы не зависит. Поэтому ослабленный конус равен {B G B† : G ⪰ 0 вещественная на Y₀}. Пусть множество допустимых G (с B G B† = I_{r₀}) непусто, и G* — точка его относительной внутренности; её образ R(G*) содержит образы всех допустимых G. Если какое-то λ_i обращается в ноль на R(G*), то вместе с Im(a_i†y) = 0 на Y₀ это даёт a_i†y = 0 для всех кусков, и I_{r₀} лежит в матрицах с носителем в a_i^⊥ — противоречие, если A_i ≠ 0. Значит, все λ_i ненулевые на R(G*), G* положительно определена на своём образе, и по лемме A существует разложение из буквальных векторов. Итог: при r₊ = 1 и ненулевых A_i буквальная и ослабленная формы ядерного условия совпадают.

### 5.2. При r₊ = 2 расхождение есть: явная модель

Базис (s₁, s₂, k₁, k₂), ρ₀ = diag(1/3, 2/3, 0, 0), два параметра: A₁† = [[1, 0], [0, 0]] (k₁ → s₁) и A₂† = [[0, 0], [0, 1]] (k₂ → s₂). Семейство F_U.

На бумаге `[INFERRED]`:
- Волокна смешанные: при x ∥ s₁ допустимы y = (y₁, 0) с λ₁ ≠ 0, λ₂ = 0; при x ∥ s₂ допустимы y = (0, y₂) с λ₁ = 0, λ₂ ≠ 0. Чистых ненулевых векторов нет.
- Ослабленный конус содержит I₂ = k₁k₁† + k₂k₂†, поэтому граница насыщаема (D1, T4).
- Буквальное (10): для пары (1, 2) нужно A₁†y = c·A₂†y, то есть y₁ = 0; для пары (2, 1) нужно y₂ = 0. Ненулевых векторов нет, и любой POVM на ядре нарушает (10). Ядерная часть буквального 2′ не выполняется ни для какого POVM.

Пример — ровно случай нулевого образа: у k₁ образ a₂ = 0, у k₂ образ a₁ = 0. При чтении H2 условие выполнено.

**Ограничения и что не утверждается.**
- Нет оснований утверждать, что в теореме имелось в виду H1. Если подразумевается H2, это замечание о формулировке, а не ошибка теоремы.
- В конвенции многомерного предела нулевые исходы с N_E ≠ 0 вклада не имеют (предел зависит от направления: в примере F^C₂₂ = 0 вдоль оси). Различие H1 и H2 там ничего не разделяет.
- Опубликованный текст поправки не прочитан (§1): если в нём стоит форма H2, вопрос как поправка к литературе закрыт. Пример прост, и его новизна не установлена.
- Минимальность: по r₊ пример минимален (при r₊ = 1 расхождения нет, §5.1). При r₀ = 1 та же конструкция не работает (с блоками k → s₁, k → s₂ допустим только y = 0, проверено на бумаге), но общая минимальность по r₀ не доказана.
