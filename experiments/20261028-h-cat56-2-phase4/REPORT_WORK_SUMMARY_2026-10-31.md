# H-CAT56-2: отчёт о проделанной работе (2026-10-31)

Внутренний отчёт. Не рецензирован внешне: все аудиты — агенты той же модели с изолированным контекстом (слабая–средняя независимость). Коммитов, push, публикаций и внешних отправок не было. Исторические сертификаты A0, R, registry/graph.yaml не менялись.

## 1. Что было задано

Контраст двух наборов параметров SLD-QCRB для одноэкземплярных POVM: S+ = {0..11} (существование насыщающего POVM) и S− = {4..15} (невозможность). Модель: d = 22 = 2 + 20, rank ρ = 2, ρ = Q ⊕ 0, Q = diag(1/3,2/3) (нормировка инстанса diag(1,2), Tr = 3). Инстанс seed 701082: A_a = −2i·B_a, B_a ∈ Z[i]^{20×2}, 16 блоков.

## 2. Результаты

### 2.1 S+ — существование насыщающего POVM (положительный результат)

**Утверждение.** На сетке Ξ из 280 направлений существует конечный POVM из 1764 регулярных исходов (нулевых нет), ΣE = I₂₂, насыщающий CFIM = QFIM для всех 12 параметров S+.

**Доказательство (логика).**
- Лемма 2: регулярный элемент насыщает CFIM-границу ⇔ A_iᴴy = ξ_i·α, ξ_i ∈ ℝ (по тексту YPZJ arXiv:1806.07337, thm:reg; проверено по LaTeX). Для любого Q ≻ 0.
- Лемма 3: 484 вещественные координаты задают изоморфизм Herm(22) ↔ ℝ⁴⁸⁴ (4 + 80 + 400, включая перекрёстный support–kernel блок). Значит ΣE = I ⇔ A·M = b.
- Лемма D: M = ω·Σ_k ĉ_kĉ_kᵀ с ĉ_{k,N}=1 и N векторами (отражение Хаусхолдера, M = CCᵀ). Числа исходов: Σ_j N_j = 182·7 + 98·5 = 1764.

**Входы (точные равенства и положительность).**
- `exact_cert.py` (рациональная арифметика, полный прогон ~3.2 ч): все 484 строки A·M* = b выполняются точно над ℚ (`rows_violated_exactly: 0`); все 280 блоков M_j* положительно определены точно (ведущие миноры по Сильвестру, LDLᵀ над ℚ).
- Проверено независимо: принадлежность Y_S(x_j) (1484 вектора × 12 условий, точная арифметика, 0 нарушений); линеаризация A из определения лифта совпадает с сохранённой A (расхождение 3.3·10⁻¹⁶); декодирование блоков по спецификации FORMAT.md совпадает с загрузчиком; SLD и QFIM модели проверены численно (уравнение SLD точно, QFIM точно); лемма D — 200 случайных матриц, ошибка 10⁻¹⁵.
- Адверсариальный float-пробег (агент): ΣE − I ~ 2·10⁻¹¹; |CFIM − QFIM| ~ 1.5·10⁻¹⁰ на S+; на параметрах вне S+ (12–15) расхождение ~2.6·10⁴ — тест способен провалиться.

**Статус.** PROVED-hand (логика) при точных входах. Воспроизводимость сертификата частичная: сам прогон `exact_cert.py` не перезапускался, входы захешированы (SHA в `stage_e_v1/logs/SHA256SUMS_inputs_stageE_v5_2026-10-31.txt`). Независимая целочисленная перепроверка `verify_exact_integer_v3.py` **в процессе** (см. §5).

### 2.2 S− — запрет насыщения (отрицательный результат, несколько классов)

**(а) D1 (нулевые исходы вносят 0).** Не существует POVM с CFIM_D1 = F^Q_{S−}. Статус: PROVED-hand + VERIFIED-interval. Разделитель: tr R* − 20 s* ≥ 0.0304 > 0, где s* — максимум yᴴR*y по 𝒴¹_{S−}; сертифицировано интервальной арифметикой arb (192 бита) на 3 955 841 листе, 7912 чанках, 0 отказов (журнал проверен независимым скриптом, AUDIT_PASS). Важно: D1 — не литературная конвенция; YPZJ трактует нулевые исходы предельной процедурой (D2). D1 приведён как отдельный, более слабый результат и не заменяет D2.

**(б) Конечные POVM, D2 (направленный предел), семья F_U, одно направление h — Теорема Q.** Для любого конечного POVM tr(F^Q − F_D2(h)) ≥ c₀ = (γ/(40‖R*‖C_Ł))^{1/θ} > 0. Константы C_Ł, θ — экзистенциальные (неравенство Łojasiewicz для полуалгебраической функции λ₂(N_y) на сфере). Доказательство: лемма о спектральном дефекте (λ₂(N_D) ≤ tr δ по Вейлю), Коши–Шварц для F ⪯ N, Гёльдер; обмена предела и интеграла нет. Аудит агента по 10 пунктам — CONFIRMED.

**(в) Борелевские POVM, естественный D2 — Теорема N и следствие N₁.** Для фиксированного направления h и малых s: tr(F^Q(θ_s) − F_E(θ_s)) ≥ c > 0 для любого конечного POVM. Следствие: для любого борелевского POVM след классической информации Фишера sup-по-разбиениям при θ_s не превышает tr F^Q(θ_s) − c, поэтому естественный предел lim_{s→0} sup_P F_P(θ_s) не равен F^Q даже по следу. Ключевой шаг — не переставлять пределы: разделитель фиксирован при s = 0, а при s ≠ 0 возникает аддитивная ошибка порядка |s|^{θ₀} (Липшиц по s + Łojasiewicz при s = 0). Аудит агента — CONFIRMED. Статус: PROVED-hand в смысле следа.

**(г) Постоянство ранга.** dim_ℝ Y_S(x) = 4 для всех направлений x ∈ CP¹. Доказано через сертифицированные arb ячейки: Φ(u) = Φ₀(I + Φ₀⁺Φ(Δ)), κ < 1 ⇒ rank 36 в каждой ячейке. Покрытие прямоугольника [0,π]×[0,2π] листами проверено. Статус: PROVED-hand + arb.

### 2.3 Отрицательные и ограничивающие результаты

- **Nurdin-метод (составная матрица c_lm) не работает для S−.** Для полного набора 16 параметров kernel-POVM невозможны (ранг 399 = dim Herm₀(20)). Для S− число образующих 4·C(12,2) = 264 < 399, то есть предпосылка метода не выполняется. Это строгое арифметическое препятствие, а не ошибка в вычислении.
- **Кандидат s14_povm_prefix12 (ранее предложенный POVM S+) опровергнут.** Невязка полноты 8.6·10⁻¹⁰ ненулевая; 3336 из 3360 пар (k,i) не удовлетворяют условию Y_S точно; коррекцией весов не исправляется. Опровергнут именно кандидат; S+ в целом это не отменяло, и точный сертификат построен заново.
- **Ограничения S−:** результаты для семьи F_U и одного направления h; для общих C¹-семей D2 не выведен; эквивалентность sup-по-разбиениям интегральной форме CFIM не доказана (для меры, зависящей от θ, это требует отдельного анализа).
- **Ограничения S+:** существование на конечной сетке Ξ; непрерывные направления не утверждаются (для положительного результата не нужны).

## 3. Исправления ошибок по ходу работы

- Неверное прочтение «±1 для всех координат» (v4): ограничение относится только к последней (support) координате; теорема переписана (v5, v6).
- Утверждение «D1 — соглашение литературы» было неверным: YPZJ использует предельную процедуру (D2); исправлено.
- mod-p остатки и Decimal-проверки не являются доказательством над ℚ; в доказательствах не используются.
- Проверка S+ по fmpq-дробям упиралась в gcd на огромных дробях (27 мин без результата); переписана в целых (`verify_exact_integer_v3`).
- Лемма 5 (счётный случай) требовала явного соглашения для изолированных нулей регулярного исхода; добавлено (F_k := 0 при p_k = 0).
- Блоки инстанса A_a и блоки генератора G_a были перегружены одним символом; разведены.
- Ошибка в ссылках: D2_CONE_TRANSFER_v3 лежит в корне phase4, а не в d2_v3/; исправлено.
- Константа C₁ в лемме о разделении была записана противоречиво; исправлена.
- Численная «проверка хвоста» g5 на самом деле проверяет ингредиенты на конечном усечении; переименовано.

## 10. Итог

- **Достаточно ли для статьи:** для препринта с явными предпосылками — да (S+ существование на сетке, S− количественный запрет D2 в F_U, естественный борелевский запрет в смысле следа). Для утверждений «невозможно для всех POVM» и «оптимально» — нет, без внешней проверки и закрытия пунктов 2–3 из §5.
