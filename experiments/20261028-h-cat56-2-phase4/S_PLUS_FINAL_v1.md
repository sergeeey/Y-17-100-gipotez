## 2. Теорема S+ (точная формулировка)

Пусть Ξ = {x_j}_{j=1}^{280} ⊂ C² \ {0} и вещественные базисы B_{j,1..m_j} ⊂ C²⁰ пространств Y_S(x_j) := {y : A_iᴴy ∈ R·x_j ∀ i ∈ S+}, m_j ∈ {6, 4}. Пусть для каждого j вещественная симметричная M_j ∈ S^{m_j+1} удовлетворяет:
(T1) M_j ≻ 0;
(T2) точные равенства A·M = b, где A — 484×6566 матрица координат Σ M_j[a,b] v_{j,a}v_{j,b}ᴴ (лемма 3 в v6) и b = координаты I₂₂.

Тогда существует конечный набор E_{j,k} = ω_j u_{j,k}u_{j,k}ᴴ, k = 1..N_j (N_j = m_j+1), u_{j,k} = (x_j; Σ_a (ĉ_{j,k})_a B_{j,a}), ω_j > 0, ĉ_{j,k} ∈ R^{N_j} с (ĉ_{j,k})_{N_j} = 1, такой что:
1. Σ_{j,k} E_{j,k} = I₂₂;
2. каждый E_{j,k} регулярен (Tr ρE > 0), нулевых исходов нет;
3. каждый E_{j,k} насыщает CFIM-границу по всем 12 параметрам (YPZJ thm:reg + лемма 2 v6);
4. Σ_{j,k} (CFIM-вклады) = QFIM как матрицы 12×12, т.е. CFIM = QFIM;
5. общее число исходов Σ_j N_j = 182·7 + 98·5 = 1764.

Доказательство: лемма D (разложение M_j = ω_j Σ_k ĉĉᵀ с последней координатой 1, N_j пикселей; проверка в `code/check_decomposition_v5.py`), лемма 2 (условие насыщения ⇔ A_iᴴy ∈ R·α), лемма 3 (полнота ⇔ A·M = b). Пункт 4 — из поэлементного насыщения и ΣE = I. Полное доказательство — в v6 §3–§4.
