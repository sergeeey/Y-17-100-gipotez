## 4. Полюс в лемме о ядре (P2)

Пусть x = (x₀, x₁) ≠ 0, a_c^{(i)} := conj(A_i[:,c]). Для y ∈ C²⁰ условие A_iᴴy = λ_i x с λ_i ∈ R эквивалентно (PHASE3 §3):
- g₁^{(i)}·y = 0 (комплексное, два вещественных условия), где g₁ = x₀a₁ − x₁a₀;
- Im(g₃^{(i)}·y) = 0 (одно вещественное), где g₃ = conj(x₀)a₀ + conj(x₁)a₁.

Итого 3 строки на i, 36 строк на 12 индексов.

- Если x₀ ≠ 0: λ_i := (a₀·y)/x₀; из g₁·y = 0 получаем a₁·y = λ_i x₁; Im(g₃·y) = 0 даёт Im(λ_i|x|²) = 0, т.е. λ_i ∈ R. [PROVED-hand]
- **Полюс x₀ = 0 (ранее не разобран):** тогда x₁ ≠ 0, g₁·y = −x₁(a₀·y) = 0 ⇒ a₀·y = 0 = λ_i·x₀ при λ_i := (a₁·y)/x₁. Условие Im(g₃·y) = Im(conj(x₁)·(a₁·y)) = Im(λ_i|x₁|²) = 0 даёт λ_i ∈ R. Обратное включение очевидно. Симметричное рассуждение с перестановкой индексов. [PROVED-hand, закрыто здесь]
- Фазовая эквивалентность: Y_S(e^{iα}x) = e^{iα}Y_S(x), y†Ry инвариантна. Поэтому достаточно x₀ ≥ 0, т.е. параметризация Блоха x = (cos θ/2, sin θ/2 e^{iφ}), θ ∈ [0,π], φ ∈ [0,2π). [PROVED-hand]

## 5. Лемма ячейки (P3)

Центр u₀ = (cos θ_c/2, 0, sin θ_c/2 cos φ_c, sin θ_c/2 sin φ_c) ∈ S³, полуширины h_θ, h_φ; du := ½h_θ + sin(θ_hi/2)h_φ (+10⁻¹² в коде). Φ₀ := Φ(u₀), A_j := Φ₀⁺Φ_j, κ := du(Σ‖A_j‖²)^{1/2}, Z — ортонормированный базис K := ker Φ₀, κ_K := du(Σ‖A_jZ‖²)^{1/2}, ρ := κ_K/(1−κ), B := max(λ_K,0) + 2‖MZ‖ρ + ‖M‖ρ², λ_K := λ_max(ZᵀMZ), M — вещественная форма R.

- **L1 (радиус).** |∂_θu| = ½ и |∂_φu| = sin(θ/2) (прямой расчёт). Путь «сначала θ, потом φ» даёт |u − u₀| ≤ ½h_θ + sin(θ_hi/2)h_φ = du для всех точек ячейки.
- **L2 (шар на сфере).** Для любого единичного u с |u − u₀| ≤ du и любого единичного y ∈ ker Φ(u): Φ₀y = −Φ(Δ)y, Δ := u − u₀. Лемма верна для всех таких u, не только для u из ячейки.
- **L3 (разложение).** y = z + w, z ∈ K, w ∈ row(Φ₀). Φ₀w = −Φ(Δ)y, поэтому w = −Φ₀⁺Φ(Δ)y. По Коши–Шварцу ‖Φ₀⁺Φ(Δ)v‖ ≤ du(Σ‖A_j‖²)^{1/2}‖v‖ = κ‖v‖ и для v = Zc: ≤ κ_K|c|. Отсюда |w| ≤ κ_K|z| + κ|w|, т.е. |w| ≤ ρ|z| при κ < 1. Ранг Φ₀ полный (σ₃₆(Φ₀) > 0) нужен для Φ₀⁺, а не в самой точке u. Вырожденные точки u (ядро прыгает) не требуют отдельного рассмотрения.
- **L4 (форма).** |z|²+|w|² = 1, |c| = |z| ≤ 1. yᵀMy = zᵀMz + 2zᵀMw + wᵀMw ≤ max(λ_K,0) + 2‖MZ‖ρ + ‖M‖ρ² = B.

Вывод: sup_{y∈ker Φ(u), |y|=1} yᵀMy ≤ B_ℓ для всех u с |u − u₀_ℓ| ≤ du_ℓ. [PROVED-hand]

## 6. Разделение (P5)

Пусть I₂₀ = Σ_j c_j y_j y_jᴴ с c_j ≥ 0, |y_j| = 1. Тогда Σc_j = tr I₂₀ = 20 и
tr R = Σ_j c_j y_jᴴ R y_j ≤ (Σ_j c_j)·sup_{𝒴¹} y†Ry = 20·sup.
Значит, если sup < tr R/20, то I₂₀ ∉ 𝒞_S. [PROVED-hand]

Эта же импликация с обратным знаком даёт PHASE3 §8(i): tr R > 0 и y†Ry ≤ 0 на 𝒴_S ⇒ несатурируемость.
