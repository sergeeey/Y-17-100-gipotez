# Независимая реконструкция доказательства Теоремы N (2026-10-31)

Цель: пройти каждый существенный переход заново, опираясь на THEOREM_NATURAL_D2_NOGO_v7.md §1–2 и THEOREM_NATURAL_D2_NOGO_v8.md §0, и отметить, где статус PROVED-hand, CONDITIONAL, FALSIFIED или UNKNOWN. Согласие агентов здесь не считается доказательством; каждый шаг проверен по тексту ниже.

Обозначения: ρ_θ — семейство матриц плотности на ℂ²², ρ₀ = Q ⊕ 0, Q = diag(q₁, q₂), q = (1/3, 2/3). Разбиение ℂ²² = supp ⊕ ker: индекс s для двух первых координат, k для двадцати остальных. L_a(θ) — SLD: ∂_aρ = (ρL_a + L_aρ)/2. N_v(θ)_{ab} = Re(vᴴL_aρ_θL_bv) для единичного v ∈ ℂ²². F_E, F^Q, δ_k — как в v8 §1. R̂ = 0₂ ⊕ R*, P_y = 0₂ ⊕ I₂₀, 𝒴 — замыкание {y : rank Re Gram(A_aᴴy)_{a} ≤ 1}, 𝒱₀ = ℂ² × 𝒴.

## Условия, которые использует доказательство

| Условие | Текст | Где используется |
|---|---|---|
| C0 | ρ_θ дифференцируема в окрестности 0, ρ₀ = Q⊕0 | SLD, спектральная щель |
| C2 | θ ↦ ∂ρ_θ непрерывна в θ = 0 | шаг 4 (непрерывность L), шаг 5 |
| C3 | (∂_aρ₀)_{ss} = 0, эквивалентно (L_a(0))_{ss} = 0 | шаг 6 (продуктовая структура 𝒱₀) |

Постоянный ранг не используется ни в одном шаге оценки. Он нужен только для предельной формы N₁ (см. шаг 10).

## Шаг 1. SLD существует при каждом θ. PROVED-hand.

Для u ∈ ker ρ_θ функция φ ↦ uᴴρ_φu ≥ 0 достигает минимума 0 в точке θ, поэтому её производная равна нулю: uᴴ(∂ρ_θ)u = 0. Значит (∂ρ_θ)_{kk} = 0, и уравнение ∂ρ = (ρL + Lρ)/2 разрешимо. Блок (L)_{kk} свободен и в дальнейшем не входит.

## Шаг 2. N_v зависит только от «видимой» части L. PROVED-hand.

Положим w_a := ρ^{1/2}L_a v. Тогда w_aᴴw_b = vᴴL_aρL_bv, и N_v = Re Gram(w_a). Так как ρ^{1/2} = diag(g(ρ_s), 0) в блочной форме с supp и ker, вектор w_a имеет только supp-компоненты: (w_a)_s = ρ_s^{1/2}(L_a v)_s = ρ_s^{1/2}(L_{ss}x + L_{sk}y). Блок L_{kk} в w_a не входит вообще, поэтому N_v не зависит от выбора SLD на ядре. Для F_U это совпадает с C2: L_{sk} = A_aᴴ.

## Шаг 3. Проектор Рисса. PROVED-hand.

Спектр ρ₀ равен {q₁, q₂, 0 (×20)}. По неравенству Вейля для |θ| ≤ r: |λ_i(ρ_θ) − λ_i(ρ₀)| ≤ ‖ρ_θ − ρ₀‖ → 0. Значит при малом θ ровно два собственных значения лежат внутри окружности Γ вокруг {q₁, q₂}, а остальные лежат в [0, ε].

P(θ) := (2πi)⁻¹∮_Γ (z − ρ_θ)⁻¹ dz — ортогональный проектор (ρ_θ эрмитова), непрерывный по θ. Обозначим ρ_P := ρ_θ|_{ranP} (спектр ≥ m := q₁ − ε > 0) и ρ_R := ρ_θ|_{ran(1−P)} (спектр ⊂ [0, ε]).

## Шаг 4. L непрерывна на ran P в нуле. PROVED-hand, использует C2.

Так как ρ коммутирует с P, проекции уравнения SLD дают:
- P(∂ρ)P = (ρ_P·PLP + PLP·ρ_P)/2, то есть ρ_P X + X ρ_P = 2P∂ρP;
- P(∂ρ)(1−P) = (ρ_P·X + X·ρ_R)/2, где X := PL(1−P).

Оператор X ↦ ρ_P X + X ρ_R при ρ_P ≥ m > 0 и ρ_R ≥ 0 обратим с нормой ≤ 1/m (стандартная оценка для эрмитовых операторов с неотрицательным спектром). Значит PLP и PL(1−P) однозначно определены и непрерывно зависят от ∂ρ(θ), P(θ), ρ(θ). По C2 ∂ρ(θ) → ∂ρ(0), так что PL(θ) → PL(0).

При θ = 0 имеем ρ_R = 0, P(0) = проектор на supp, и уравнение для блока PL(1−P) принимает вид Q X = 2∂ρ_{sk}, то есть X = 2Q⁻¹(∂ρ)_{sk}. Для F_U (∂ρ)_{sk} = QA_aᴴ/2, откуда X = A_aᴴ, что согласуется с конвенцией C2.

## Шаг 5. Одностороннее неравенство f_θ ≥ f₀ − ω(|θ|). PROVED-hand, использует C2, без постоянного ранга.

Положим M_v(θ) := Re Gram(P(θ)w_a(θ)). Так как w_a = P w_a + (1−P)w_a, для эрмитова Gram имеем Gram(w) = Gram(Pw) + Gram((1−P)w), и вторая часть положительно полуопределена. После Re получаем N_v(θ) ⪰ M_v(θ) как вещественные симметричные 12×12 матрицы.

Из Шагов 3–4 P w_a(θ) = ρ^{1/2}P L_a(θ)v → ρ₀^{1/2}P₀L_a(0)v равномерно по |v| = 1. Значит M_v(θ) → M_v(0) равномерно.

При θ = 0 имеем M_v(0) = N_v(0), так как ρ₀^{1/2} обнуляет ker.

По монотонности λ₂ относительно порядка ⪰ и 1-липшицевости λ₂ в операторной норме:
f_θ(v) := λ₂(N_v(θ)) ≥ λ₂(M_v(θ)) ≥ λ₂(M_v(0)) − ‖M_v(θ) − M_v(0)‖ = f₀(v) − ω(|θ|),
с ω(r) := sup_{|θ|≤r, |v|=1} ‖M_v(θ) − M_v(0)‖ → 0 при r → 0.

Вывод: f₀ ≤ f_θ + ω(|θ|), и именно это направление нужно в Шаге 8. Постоянный ранг здесь не используется. Если убрать C2, ω(r) не стремится к нулю, и шаг не проходит. Контрпример в v8 §0 показывает, что без C2 общее утверждение Теоремы N ложно.

## Шаг 6. Łojasiewicz для f₀. PROVED-hand (ссылка на уровень раздела BCR §2.6).

N_v(0) — вещественно-полиномиальная функция v (квадратичная форма по Re v, Im v с вещественными коэффициентами из L(0)). Значит f₀ = λ₂(N_v(0)) полуалгебраична на компактной алгебраической сфере S, для любых фиксированных L(0). Аналитичность семьи не нужна.

Нуль f₀ — это {v : rank N_v(0) ≤ 1}. По C3 N_v(0) зависит только от y (см. шаг 7), так что нуль = ℂ² × 𝒴 ∩ S. Łojasiewicz даёт
dist(v, 𝒱₀) ≤ C₀ f₀(v)^{θ₀} на S
для некоторых C₀ > 0 и θ₀ > 0. Показатель можно понизить до θ₀ ≤ 1 (на ограниченной f₀ это ослабляет неравенство). θ₀ ≤ 1 нужно для субаддитивности в Шаге 8.

## Шаг 7. Продуктовая структура 𝒱₀ использует C3. PROVED-hand.

Если (L(0))_{ss} = 0, то (L v)_s = L_{sk}y, и w_a = ρ^{1/2}L_a v = Q^{1/2}L_{sk}(a) y, то есть N_v(0) зависит только от y. Ненулевой блок (L(0))_{ss} = M_a давал бы слагаемые Q^{1/2}M_a x, зависящие от x, и 𝒱₀ не была бы продуктом ℂ² × 𝒴.

Проверка согласованности 𝒴 с YPZJ-насыщением для F_U: rank_ℝ Gram(Q^{1/2}A_aᴴy) ≤ 1 ⇔ все векторы Q^{1/2}A_aᴴy ∈ ℂ² лежат на одной вещественной прямой ⇔ A_aᴴy = ξ_a x с вещественными ξ_a. Это ровно условие насыщения из YPZJ thm:reg (после замены x := Q^{-1/2}w). Значит 𝒴 = ∪_x Y_S(x), то есть то же множество, которое покрывает O3.

Для общей C¹-семьи 𝒴 строится из блоков ∂ρ₀_{sk}, а не из A. O3 к ней не применим.

## Шаг 8. Разделение и оценка Теоремы N. PROVED-hand, с одним условием.

Лемма 5 (v8 §1): для единичного v = (x; y), y^H(R* − s*)y ≤ C₁ dist(y, 𝒴). Она выполняется, если yᴴR*y ≤ s* на 𝒴. Нормировка (аудит Codex): 𝒴 — замкнутый конус, поэтому q(y) := yᴴ(R* − s*)y ≤ 0 на 𝒴 (однородность). Для ‖y‖ ≤ 1 возьмём ближайшую точку z ∈ 𝒴 (она существует, 𝒴 замкнуто; выпуклость не нужна), ‖z‖ ≤ ‖y‖ + d с d = dist(y,𝒴) ≤ 1. Тогда q(y) ≤ q(y) − q(z) ≤ ‖R* − s*I‖(‖y‖ + ‖z‖)·d ≤ 3‖R* − s*I‖·d, то есть C₁ := 3‖R* − s*I‖ ≤ 4‖R*‖ + 2|s*| (прежняя константа остаётся верной). Для F_U это следует из O3 (VERIFIED-interval, γ ≥ 0.0304). Для общей семьи это отдельное условие: существование разделителя R* с tr R* − 20 s* = γ > 0 и sup_{𝒴} yᴴR*y ≤ s*. Без него Лемма 5 не доказана.

Лемма 6 (цепочка, проверена по шагам):
(a) Для элемента E_k = Σ_j e_{kj}v_{kj}v_{kj}ᴴ: λ₂(N_{E_k}) ≤ trδ_k (Вейль, F_k ранга ≤ 1), и e_{kj}f_s(v_{kj}) ≤ λ₂(N_{E_k}) (монотонность).
(b) Σ_k Σ_j e_{kj}(R̂ − s*P_y)-форма = tr R* − 20s* = γ (полнота ΣE = I, Σ tr P_yE = 20).
(c) γ ≤ C₁ Σ_k Σ_j e_{kj} dist(v_{kj}, 𝒱₀) ≤ C₁C₀ Σ e_{kj} f₀(v_{kj})^{θ₀} ≤ C₁C₀ Σ e_{kj}(f_s(v_{kj}) + ω)^{θ₀}.
(d) Субаддитивность (θ₀ ≤ 1): (f+ω)^{θ₀} ≤ f^{θ₀} + ω^{θ₀}.
(e) e f^{θ₀} = e^{1−θ₀}(e f)^{θ₀} ≤ e^{1−θ₀}(trδ_k)^{θ₀}. Суммы: Σ_j e_{kj}^{1−θ₀} ≤ 22^{θ₀}(tr E_k)^{1−θ₀} (вогнутость, ≤ 22 слагаемых). Гёльдер по k: Σ_k (trE_k)^{1−θ₀}(trδ_k)^{θ₀} ≤ 22^{1−θ₀}(trΔ)^{θ₀}, где Σ trE_k = 22.
Итог: γ ≤ 22C₁C₀[(trΔ)^{θ₀} + ω(|s|)^{θ₀}]. Это совпадает с v7 Лемма 6 при ω(r) ≤ L·r (тогда ω^{θ₀} ≤ max(1,L^{θ₀})|s|^{θ₀}).

Теорема N. Положим C₂ := 22C₁C₀ и выберем s₁ > 0 так, что s₁ ≤ t₀ и ω(s₁)^{θ₀} ≤ γ/(2C₂) (такое s₁ существует, потому что ω(r) → 0 при r → 0 по шагу 5). Для |s| ≤ s₁ из оценки (c) получаем γ ≤ C₂(trΔ)^{θ₀} + γ/2, то есть C₂(trΔ)^{θ₀} ≥ γ/2 и trΔ ≥ c := (γ/(2C₂))^{1/θ₀}. Для F_U ω(r) ≤ L·r, поэтому s₁ := min(t₀, (γ/(2C₂L^{θ₀}))^{1/θ₀}); c от L не зависит. Заметка: в v7 C₂ содержал L; здесь L вынесен в s₁, так что c = (γ/(2C₂))^{1/θ₀} не содержит L.
- Равномерность по POVM: используются только ΣE_k = I, Σ trE_k = 22, Σ tr(R̂E_k) = tr R*, Σ tr(P_yE_k) = 20.
- Равномерность по h: ω и C₀, C₁, θ₀ определены как sup по сфере направлений и по ball |θ| ≤ t₀.

Вывод: Теорема N доказана для F_U (C2, C3 и O3 выполнены) и для любой C¹-семьи, которая удовлетворяет C0, C2, C3 и имеет разделитель R* с γ > 0. Для общей семьи последнее условие — гипотеза, не следствие.

## Шаг 9. Борелевский переход (N₁, след). PROVED-hand.

Для конечного разбиения P борелевского POVM M получаем полный конечный POVM, и Теорема N даёт tr F_P(θ) ≤ tr F^Q(θ) − c. Сеть монотонна (неравенство Титу), ограничена сверху F^Q, значит sup существует по Лёвнеру, и sup следа ≤ tr F^Q(θ) − c. Это верно при каждом фиксированном θ, без предельного перехода.

## Шаг 10. Предельная форма N₁ и связь с непрерывностью F^Q. FALSIFIED для общих C¹-семей, PROVED при постоянном ранге 2.

Предельная форма (lim_{s→0} tr F^C_M(sh) ≤ tr F^Q(0) − c) требует lim_{s→0} tr F^Q(sh) = tr F^Q(0). Этого не следует из C0, C2, C3. Аналитическое объяснение контрпримера в toy_rank_jump (см. ниже).

При постоянном ранге 2 проектор поддержки непрерывен, L непрерывна на supp, и F^Q(θ) = Re tr(ρL L) непрерывна в нуле. Значит предельная форма верна.

## Шаг 11. Предложение 7 (борелевская сеть = интеграл). PROVED-hand.

μ := tr M не зависит от θ. P_θ(B) = tr(ρ_θM(B)) ≤ μ(B), m_θ = tr(ρ_θW). На {m_θ = 0} градиент ∇m_θ = 0 по той же минимизационной аргументации, что в шаге 1 (m_φ ≥ 0 с минимумом 0 в θ). Коши–Шварц даёт I_int ⪯ F^Q; условные ожидания — ортогональные проекции, их направленное объединение плотно в L²(P_θ) (аппроксимация борелевских множеств конечными алгебрами). Значит sup по разбиениям = I_int поквадратично, а значит матрично.

## Шаг 12. Направленная квадратичная форма (Предложение 8). FALSIFIED для общих семей, PROVED для F_U.

POVM {I₂⊕0, 0⊕e_ke_kᴴ}: при постоянном ранге 2 hᵀF_E(sh)h → hᵀF^Q(0)h (вклад E₀ равен O(s²), каждый нулевой исход даёт hᵀN_kh). При скачке ранга предел смещается на 4(trτ)|h|²·hhᵀ (см. ниже), поэтому утверждение ложно для общих семей.

## Аналитическое объяснение скачка ранга (toy_rank_jump)

Семья ρ_θ = U_θ((1−r²)ρ₀ + r²τ)U_θᴴ, τ = diag(0,0,0.2,0.3,0.5), r = |θ|. При θ ≠ 0 ранг равен 5 (2 + 3). В ядерном блоке малые собственные значения w_i = s²|h|²τ_i. Производная ∂_aρ на диагонали ядра даёт D_ii = 2sh_aτ_i + O(s²). Тогда L_ii = D_ii/w_i = 2h_a/(s|h|²) (порядок 1/s), и вклад w_i·L_aii·L_bii = 4h_ah_bτ_i/|h|² остаётся конечным. Недиагональные L_ij и смешанные блоки дают O(s²) или O(s) → 0.

Итог: F^Q(sh) → F^Q(0) + 4 (trτ) hhᵀ/|h|² при |h| = 1 (ошибка O(s)). Для следа: tr F^Q(sh) − tr F^Q(0) → 4 trτ = 4.0. Численно: trFQ(s)−trFQ(0) = 3.9976 при s = 0.003 и 3.9994 для hᵀ-формы. Аналитическое значение 4 совпадает с численным до 3 знаков.

Аналитический шаг: ∂_aρ(θ) содержит 2θ_a(τ−ρ₀) и вклад U-поворота порядка s. Диагональный ядерный блок даёт вклад 2sh_aτ_i, отсюда L_ii = 2h_a/(s|h|²). Недиагональные части ядра не дают вклада в O(1), так как [X,ρ] не имеет ядерного блока в первом порядке.

## Вторая критическая проверка (2026-10-31, независимый проход по тексту)

Цель: попытаться опровергнуть равномерную оценку через проектор Рисса и переход к борелевской CFIM. Результаты:
