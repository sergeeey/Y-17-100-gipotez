## 2. S− — запрет D2 для POVM

**Гипотезы H1–H5.** Семья F_U (ρ_θ = U_θρU_θᴴ, U_θ = exp(Σθ_aX_a)), θ₀ = 0, Q ≻ 0, POVM не зависит от θ и полон, направление h ∈ R^S, D2-соглашение (F_k := 0 при p_k ≡ 0 на луче, F_k := (Nh)(Nh)ᵀ/(hᵀNh) при hᵀNh > 0).

**Теорема Q (конечный POVM, количественно).** Для любого конечного POVM tr(F^Q_S − F_D2(h)) ≥ c₀ := (γ/(40‖R*‖C_Ł))^{1/θ} > 0, где R* — разделитель с γ := tr R* − 20 s* ≥ 0.0304 > 0 (сертификат O3, s* ≤ s_target), C_Ł, θ — константы неравенства Łojasiewicz (экзистенциальные).
- Доказательство: лемма D2a (F_k ⪯ N_{D_k}, rank F_k ≤ 1), лемма D2b (λ₂(N_{D_k}) ≤ tr δ_k, Weyl), лемма G (rank N_y ≤ 1 ⇔ y ∈ 𝒴_S), лемма Ł (f = λ₂(N_y) полуалгебраична на сфере), лемма E, Гёльдер. Нет обмена предела и интеграла. Аудит агента (`THEOREM_NOGO_S_MINUS_v3.md`, аудит по 10 пунктам): **CONFIRMED** для каждого шага.
- Статус: **PROVED-hand.**

**Следствие Q₁ (борелевский, в смысле определения §7).** Для borel POVM с F^C := sup_n lim_t F_{P_n}(th) (вложенная порождающая последовательность конечных разбиений) выполнено F^C ≤ F^Q − c₀ (след). В частности, F^C ≠ F^Q. Статус: **PROVED-hand в этом смысле.**

**Естественный борелевский D2 (lim_t sup_n F_{P_n}(th)) — OPEN.** Аудит: sup_n lim_t ≤ liminf_t sup_n; запрет для §7 не переносится автоматически. Для естественного определения нужна оценка, равномерная по t (константы Łojasiewicz зависят от θ_t). Это точный барьер.

**Постоянство ранга.** Предложение R: rank Φ(u) = 36 на каждой ячейке O3 (κ < 1, det G > 0; Φ(u) = Φ₀(I + Φ₀⁺Φ(Δ)), arb-сертификат). Ячейки покрывают [0,π]×[0,2π] (точная сверка дерева O2). Постоянство доказано на CP¹ (направления). **PROVED-hand + arb-сертификат.**

**D1.** Теорема C: нет POVM с CFIM_D1 = F^Q — PROVED-hand + VERIFIED-interval (разделитель, журнал O3 AUDIT_PASS). D1 слабее D2 и не заменяет его.

**Nurdin c_lm.** Для полного набора 16 параметров: невозможность kernel-POVM (ранг 399); для S−: метод не применим (4·C(12,2) = 264 < 399). Вывод арифметический.

**Ограничения S−:** семья F_U (для общей C¹-семьи F_k может зависеть от второго порядка); одно направление h; определение CFIM (sup по разбиениям, §7); константы Łojasiewicz экзистенциальны; контрольный эксперимент (минимизация tr Δ по POVM, ожидается ≥ c₀ для S− и ≈ 0 для S+) не выполнен.
