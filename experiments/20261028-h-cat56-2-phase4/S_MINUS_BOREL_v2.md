# S−: борелевские POVM — редукция к робастной лемме и её статус (v2, 2026-10-31)

Заменяет разделы B–D `S_MINUS_BOREL_AND_NURDIN_v1.md` (раздел C про Nurdin там остаётся в силе, см. v1 §C). Цель: строгая редукция борелевского случая к конечной робастной лемме, проверка её предпосылок и точное оставшееся обязательство.

## 1. Определение CFIM для несчётных исходов (выбор)

Для POVM M на стандартном борелевском X и θ: классическая информация Фишера
F^C_M(θ) := sup_P F_P(θ), где sup по конечным борелевским разбиениям P = {B_i}, F_P(θ) — классическая FI распределения (tr(ρ_θ M(B_i)))_i.

Обоснование выбора. (а) Для абсолютно непрерывных семейств sup по разбиениям совпадает с интегральной формой ∫(∂f)²/f dμ (Dmitriev–Levit); (б) в D2 доминирующая мера должна быть одна на траектории θ_t, а в нулевых точках θ₀ абсолютной непрерывности нет, поэтому интегральная форма не определена без дополнительного выбора меры, тогда как sup по разбиениям определён всегда. Эквивалентность двух определений в D2 не проверена (это тот самый пункт, который в `D2_G5_TAIL_v1.md` §5 принят через [INFERRED]).

**D2 для борелевского POVM (определение):** F^C_M,D2(h) := sup_P lim_{t→0} F_P(th), где для конечного P предел — по конечному случаю (существует, `D2_CONE_TRANSFER_v3.md`).

## 2. Редукция (строго)

**Лемма B1 (монотонность).** Если P' измельчает P, то F_P(th) ⪯ F_{P'}(th) при каждом t с p>0 (обработка данных для классической FI, матричная форма); значит lim_t F_P(th) ⪯ lim_t F_{P'}(th) (пределы существуют, см. конечный случай). Следовательно, семейство {F_{P,D2}(h)} направлено вверх по Лёвнеру.

**Лемма B2 (счётная аппроксимация).** В стандартном борелевском пространстве существует последовательность вложенных конечных разбиений P_1 ≤ P_2 ≤ … , порождающих σ-алгебру. По мартингальной сходимости (или по монотонной сходимости классической FI) F_{P_n}(θ) ↑ F^C_M(θ) при каждом θ (для θ с абсолютной непрерывностью на траектории; аккуратно — см. §4). Тогда sup_n F_{P_n,D2}(h) = F^C_M,D2(h).

**Следствие (редукция).** Если F^C_M,D2(h) = F^Q_S, то для любого ε > 0 существует конечное разбиение P_ε с ‖F^Q_S − F_{P_ε,D2}(h)‖ ≤ ε (монотонная сходимость в конечной размерности). Значит борелевский случай следует из:

> **Лемма R (робастная).** Существуют C, ε₀ > 0, такие что для любого КОНЕЧНОГО POVM с ‖F^Q_S − F_{D2}(h)‖ ≤ ε ≤ ε₀ выполнено tr R* ≤ 20 s* + C√ε, где R*, s* — разделитель S− (tr R* − 20 s* = 0.0304).

При C√ε < 0.0304 это даёт противоречие. Поэтому: **борелевская теорема A (при определении §1) ⇔ лемма R (с константами, не зависящими от POVM).**

## 3. Статус леммы R

**Регулярные элементы — набросок закрыт.** Для регулярного элемента (p_k(0) > 0) дефект δ_k := N_k − F_k ⪰ 0 (F_k = F_k(0)), Σ_k δ_k = Δ := F^Q − F_D2, ‖Δ‖ ≤ ε.
- Лемма 1: xᵀδ_k x = Re tr(R_k M_x QM_xᴴ) + (T₁−T₂)_k(x) с обоими слагаемыми ≥ 0. Суммируя по k при x = e_a: Σ_k Re tr(R_k A_a QA_aᴴ) ≤ Δ_aa ≤ ε, и так как Σ_a A_aQA_aᴴ ⪰ q_min·λ_min(Σ_a A_aA_aᴴ) I с λ_min > 0 (A-стек полного ранга 20 для S−), получаем Σ_k tr R_k ≤ C_1 ε (линейно по ε).
- Проверка численным сканированием (`code/robust_obstacle_scan.py`, `logs/robust_obstacle_scan.json`): dim_ℝ Y_S(c) = 4 для всех 8608 выборок c ∈ S³ (включая вещественные направления); κ(c) = 1/σ_min(Π_{V_c^⊥}T|_{ker^⊥}) ≤ 84 на выборке. Константа κ равномерна, так как dim Y_S постоянна и κ непрерывна на компакте S³. Строгое обоснование «dim = 4 всюду» — ранг Φ(u) = 36 на каждой ячейке O3 (сертификат (a) det G > 0 в arb), то есть это уже закрыто O3 v2.
- Отсюда (Коши–Шварц по k: Σ_k √(a_k b_k) ≤ √(Σa_k)√(Σb_k) с a_k = tr(R_k) ≤ 20 и b_k = tr δ_k) получаем Σ_k tr(R* Z_kᴴZ_k) ≤ s*·Σ_k tr(Z_kᴴZ_k) + C√ε и Σ_k tr(R* R_k) ≤ C_2 ε, что дает лемму R для регулярной части.

**Нулевые элементы (p_k(0) = 0) — не закрыто.** Для нулевого элемента D_k = R_k, N_k = Σ_j r_j N_{y_j}, F_lim_k = (Nh)(Nh)ᵀ/(hᵀNh) — ранг 1. Дефект δ_k = N_k − rank-1 ⪰ 0, Σ_null δ_k ⪯ Δ. Нужна количественная версия леммы 4: если N_k ≈ rank-1 с ошибкой в следе ≤ tr δ_k, то каждое y_j с r_j > 0 близко к 𝒴_S в норме, с оценкой, линейной по tr δ_k. Формально: P⊥ N_{y_j} P⊥ ⪯ P⊥ δ_k P⊥ (P⊥ — проектор ⊥ Nh), и из этого нужно вывести dist(y_j, 𝒴_S) ≤ C·√(tr δ_k) с равномерной C (компактность и постоянство dim, как для κ). Это аналитическая лемма, не проверенная.

**Статус леммы R:** регулярная часть — PROVED-hand при O3 (аналитика + компактность); нулевая часть — OPEN (нужна количественная лемма 4 с равномерной константой; в ней сборка оценок сходится по той же схеме Коши–Шварца).

## 4. Оговорки

1. **Определение §1** принято по соображениям §1(б). Если владелец выберет интегральное определение, нужна эквивалентность с sup по разбиениям (Dmitriev–Levit для семейства с меняющейся доминирующей мерой) — не доказана.
2. **Измеримость.** Для sup по разбиениям измеримость не нужна (sup по счётному направленному семейству).
3. **Mартингальная сходимость (B2)** для классической FI: монотонная сходимость по вложенным разбиениям, но предел F_{P_n}(θ) → F^C(θ) требует абсолютной непрерывности p_θ относительно σ-алгебры, порождённой P_n, для θ на траектории; в D2 это проверяется на θ = th только в регулярных точках. Для θ = 0 это условие может не выполняться для нулевых исходов. Поэтому B2 строго верно только для sup-определения (которое мы и приняли), а не для предела по σ-алгебре.
4. Вся борелевская часть относится к D2 с семьёй F_U и одним направлением h.

## 5. Точное препятствие и минимальный эксперимент

**Препятствие:** лемма R для нулевых элементов (количественная версия леммы 4 с равномерной константой).

**Минимальный эксперимент, способный изменить результат:** численная проверка κ-подобной константы для лемм 4-нулевого типа: для случайных y ∈ C²⁰ и N_y = Gram(Q^{1/2}A_aᴴy) оценить отношение dist(y, 𝒴_S)/√(tr P⊥N_yP⊥) на компакте (сканирование по S³ и по y). Если отношение ограничено (как κ) — лемма R для нулевых элементов правдоподобна; если неограничено — борелевская редукция работает только для регулярных POVM, и класс «все борелевские POVM» остаётся открытым в более узком смысле.
