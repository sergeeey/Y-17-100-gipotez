# S−: запрет для естественного борелевского D2 — версия v7 (2026-10-31)

Заменяет v6 после второго аудита кванторов (агент a70e279a…). Исправления: (1) s₁ = min(t₀, …); (2) равномерность по направлению h; (3) закрыт пункт «сеть разбиений против интегральной формы» для θ-независимой меры μ = tr M; (4) добавлено явное замечание о поисходном предельном переходе.

## 0. Предпосылки

Модель и обозначения — как в v6 §0 (ρ_θ = U_θρ₀U_θᴴ, Q = diag(1/3,2/3), S = {4..15}, G_a = A_a/2, конвенция C2). Направление h ∈ S¹ (|h| = 1), θ_s = s·h, |s| ≤ t₀. Разделитель R* ∈ Herm(20) с γ := tr R* − 20 s* > 0 (O3: γ ≥ 0.0304).

## 1. Элементарные леммы (как в v6, без изменений)

Лемма 1 (Коши–Шварц): F_k(θ) ⪯ N_{E_k}(θ), rank F_k ≤ 1. Лемма 2 (спектральный дефект): λ₂(N_{E_k}) ≤ tr δ_k, Σ_kδ_k = F^Q − F_E. Лемма 3 (Łojasiewicz при s = 0): dist(v,𝒱₀) ≤ C₀f_0(v)^{θ₀}, θ₀ ∈ (0,1]. Лемма 4 (Липшиц по s): |f_s − f_0| ≤ L|s|, где L := sup_{|h|=1, |s|≤t₀, |v|=1} ‖∂_sN_v(sh)‖ < ∞ (равномерно по h, так как сфера направлений компактна и N аналитичен). Лемма 5 (разделение): vᴴR̂v − s*|P_yv|² ≤ C₁dist(v,𝒱₀), C₁ = 4‖R*‖ + 2|s*|.

## 2. Главная оценка и теорема N (с исправленным s₁)

**Лемма 6.** Для любого конечного полного POVM {E_k} (любое число исходов, любые ранги): tr R* − 20s* ≤ C₂[(trΔ(sh))^{θ₀} + |s|^{θ₀}], C₂ = 22C₁C₀max(1,L^{θ₀}). Доказательство — как v6 §3 (субаддитивность, Гёльдер, суммы Σtr E_k = 22, Σtr(R̂E_k) = trR*, Σtr(P_yE_k) = 20).

**Теорема N.** Положим s₁ := min(t₀, (γ/(2C₂))^{1/θ₀}). Тогда для любого конечного полного POVM, любого |h| = 1 и любого |s| ≤ s₁:
tr(F^Q(sh) − F_E(sh)) ≥ c, c := (γ/(2C₂))^{1/θ₀}.
Квантор: ∃ c, s₁ ∀POVM ∀h ∀|s|≤s₁. Константы зависят только от (A, Q, S), R*, C₀, θ₀, L, t₀ — не от POVM и не от h.

*Доказательство.* Из леммы 6 при C₂|s|^{θ₀} ≤ γ/2 (это верно при |s| ≤ s₁ по определению s₁): C₂(trΔ)^{θ₀} ≥ γ/2 ⇒ trΔ ≥ (γ/(2C₂))^{1/θ₀} = c. Условие s₁ ≤ t₀ обеспечивает применимость леммы 6. ∎

## 3. Порядок пределов и сеть разбиений (N₁)

**Следствие N₁.** Для борелевского POVM M и фиксированного θ_s определим F^C_M(θ_s) := lim по направленной сети конечных разбиений P (сеть монотонна по измельчению: огрубление уменьшает классическую информацию, функция (g,p) ↦ ggᵀ/p совместно выпукла и однородна, исходы с p = 0 дают ∇p = 0). Каждое конечное разбиение P даёт полный конечный POVM {M(B)}_{B∈P}, поэтому trF_P(θ_s) ≤ trF^Q(θ_s) − c по теореме N (с той же c). След непрерывен, нестрогое неравенство переходит к пределу сети; значит trF^C_M(θ_s) ≤ trF^Q(θ_s) − c для |s| ≤ s₁. Далее s → 0 (F^Q непрерывна): любая предельная точка lim_{s→0} trF^C_M(θ_s) ≤ trF^Q(0) − c. Обмена пределов нет.

## 4. Сеть разбиений против интегральной формы (закрыто для θ-независимой меры)

**Предложение 7.** Пусть μ(B) := tr M(B) — конечная мера, не зависящая от θ. Тогда P_θ(B) := tr(ρ_θM(B)) ≤ ‖ρ_θ‖·μ(B) = μ(B), то есть P_θ ≪ μ; M(dx) = W(x)μ(dx) с W(x) ⪰ 0, trW(x) = 1 μ-п.в. Плотность m_θ(x) := tr(ρ_θW(x)). Тогда:
(а) ∂_am_θ(x) = tr(∂_aρ_θ W(x)) и |∂_am_θ(x)| ≤ ‖∂_aρ_θ‖ (поэтому дифференцирование под знаком интеграла законно — доминируемая сходимость);
(б) интегральная классическая информация I_int(θ) := ∫_{m>0} ∇m∇mᵀ/m dμ ⪯ F^Q(θ) (Коши–Шварц внутри ячеек);
(в) для любого конечного разбиения P: F_P(θ) ⪯ I_int(θ), и sup по сети разбиений даёт I_int(θ) (в следе; скор ℓ_x = x·∇m/m, xᵀF_Px = ‖E[ℓ_x | σ(P)]‖²_{L²(P_θ)}, и для возрастающей последовательности порождённых σ-алгебр условное ожидание сходится к ℓ_x в L² (мартингальная сходимость), значит sup = ‖ℓ_x‖² = xᵀI_int x).
Следствие: для θ-независимой меры μ = tr M интегральная и сетевая классические информации совпадают, и Следствие N₁ применимо к интегральному определению.

Замечания: (i) интегранд ∇m/m — логарифмическая производная — не зависит от выбора доминирующей меры μ' ≪ μ при θ-независимом μ; (ii) для θ-зависимой меры интегральная формула в общем случае некорректна, и мы её не используем.

*Статус предложения 7:* PROVED-hand (проверено по шагам аудитом, пункт 3 отчёта). Ссылки на Dmitriev–Levit / Gill–Levit не верифицированы (UNVERIFIED-CITATION); утверждение доказано здесь непосредственно, без ссылки.

## 5. Поисходный предел (Fatou) — явно

Для D2-варианта, где предел берётся поисходно, Σ_k lim_t и ∫ lim_t могут не совпадать. Для конечных POVM совпадают (конечная сумма пределов). Для счётных и борелевских — по Фату: liminf ∫ ≥ ∫ liminf при неотрицательной подынтегральной функции и фиксированной μ; это даёт неравенство в нужном направлении для оценки сверху (мы оцениваем сверху след). **Наш основной результат (N₁) не использует поисходный предел:** оценка проводится в точке θ_s для каждого s и только потом переходит к пределу.
