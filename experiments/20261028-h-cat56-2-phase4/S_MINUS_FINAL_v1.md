# S− = {4..15}: статус отрицательного результата (final v1, 2026-10-31)

Сводит стадию C (`STAGE_C_FINAL_PROOF.md`), `d2_v3/D2_CONE_TRANSFER_v3.md`, O3 v2 (`o3_v2/`) и новую лемму о хвостах (счётные POVM, §4). Нормативная конвенция — D2 (направленный предел), как просит владелец; D1 приведён отдельно и не подменяет D2.

## 1. Постановка

- Модель: как в S+ (ρ = diag(Q,0), Q = diag(1/3,2/3), L_a = [[0,A_aᴴ],[A_a,0]], a ∈ S = {4..15}, 0-based).
- Y_S(x) := {y ∈ C²⁰ : A_aᴴy ∈ R·x ∀ a ∈ S}; 𝒴_S := ⋃_{x≠0} Y_S(x) ∪ Y_S(0), где Y_S(0) = {y : A_aᴴy = 0}.
- 𝒞_S := cone{yyᴴ : y ∈ 𝒴_S}; I₂₀ — блок тождества.
- Семья для D2: F_U, ρ_θ = U_θ ρ U_θᴴ, U_θ = exp(Σθ_a X_a), X_a = [[0,−B_aᴴ],[B_a,0]], B_a = A_a/2 (первый порядок совпадает с L_a; `CONVENTION_RESOLUTION.md` §1).
- D2: для направления h ∈ R^S, F_D2(h) := lim_{t→0} F^C(θ₀ + th) (матричный предел 12×12), где вклад исхода с p ≡ 0 на луче равен 0 (соглашение 0/0, D2_CONE_TRANSFER_v3 §3a).

## 2. Утверждения

**Теорема C (D1, отрицательная, сертифицирована).** Не существует POVM M на C²² с CFIM_D1(θ₀) = F^Q_S как матрицы 12×12, где D1 — нулевые исходы вносят 0. Доказательство: §3 (редукция P1, P2, P3, P5) + численная сертификация P6 (O3 v2). **Статус: PROVED-hand + VERIFIED-interval**, с условиями: O1 (редукция проверена агентом той же модели семейства — слабая независимость); O2 закрыт (точный тайлинг); O3 закрыт (журнал согласован, `o3_v2/metrics/o3_journal_audit_2026-10-31.json`: 7912 чанков, 3 955 841 лист, 0 отказов, AUDIT_PASS).

**Теорема A (D2, конечные и счётные POVM, семья F_U, одно направление h).** Пусть M = {E_k} — конечный или счётный POVM на C²², F_D2(h) = F^Q_S (матричное равенство 12×12) для некоторого h ∈ R^S. Тогда I₂₀ ∈ 𝒞_S. Поскольку 𝒞_S ∌ I₂₀ (сертифицировано для S, §3 P6), такой POVM не существует. **Статус: PROVED-hand для конечного случая (`D2_CONE_TRANSFER_v3` §§1–5); счётный случай закрыт в этом документе (§4); независимый аудит полного текста не выполнен (G4 — PARTIAL).**

**Борелевский CFIM (несчётные исходы).** **OPEN.** Для него нужна количественная (робастная) версия Теоремы A: из приближённого насыщения ‖F_D2 − F^Q‖ ≤ ε вывести, что I₂₀ лежит в ε-окрестности 𝒞_S, и сравнить с зазором tr R − 20s = 0.0304 (§3 P6). Эта версия не доказана.

## 4. Счётные POVM: закрытие G5 (новое в этом документе)

**Лемма 5 (хвостовая).** Пусть M = {E_k}_{k∈N} — POVM. Положим N_k(θ) := Re tr(E_k L_a(θ)ρ(θ)L_b(θ))_{a,b∈S}, F_k(θ) := ∂p_k ∂p_kᵀ/p_k (при p_k(θ) > 0), F_k(θ) := 0 при p_k ≡ 0 на луче.
(i) N_k(θ) ⪰ 0, и F_k(θ) ⪯ N_k(θ). Доказательство: для x ∈ R^S, ∂_x p_k = Re tr(E_k L_x ρ) (L_x := Σ x_a L_a), и по Коши–Шварцу (Re tr(E L_x ρ))² ≤ tr(ρE)·tr(ρL_xEL_x), откуда (∂_xp)²/p ≤ xᵀN x.
(ii) Σ_k N_k(θ) = F^Q(θ) при всех θ (полнота Σ E_k = I, сходимость по следу).
(iii) Хвост: T_K(θ) := Σ_{k>K} N_k(θ) = F^Q(θ) − Σ_{k≤K} N_k(θ) непрерывен по θ, и ‖T_K(θ_0)‖ → 0 при K → ∞ (сходимость ряда PSD-матриц с конечной суммой следов). Значит limsup_{t→0} ‖T_K(th)‖ = ‖T_K(0)‖ → 0.
(iv) Обмен пределом: 0 ⪯ Σ_{k>K} F_k(th) ⪯ T_K(th), поэтому lim_{t→0} Σ_k F_k(th) = Σ_k F_lim_k(h) для каждого k, где F_lim_k(h) существует (регулярные — по непрерывности; нулевые — лемма 3b).

**Следствие (счётная Теорема A).** Если F_D2(h) = F^Q(θ₀), то Σ_k (N_k(0) − F_lim_k(h)) = 0 с PSD-слагаемыми, поэтому каждое слагаемое 0. Дальше — как в конечном случае (лемма 2 и 3). Значит I₂₀ ∈ 𝒞_S, что противоречит §3 P6. **Счётный случай: закрыт аналитически (PROVED-hand); численная проверка tail-оценки — g5_countable_check.log (G2, G4 PASS).**

**Барьер G5 из `D2_CONE_TRANSFER_v3` §6 снят**: тугость выводится из F_k ⪯ N_k и полноты Σ_k N_k(θ) = F^Q(θ) с непрерывностью, а не требует отдельного довода.

## 5. Оговорки и границы

1. **Семья F_U.** Теорема A для семьи ρ_θ = U_θρU_θᴴ с X_a = [[0,−B_aᴴ],[B_a,0]]. Для общей C¹-семьи с тем же L_a не выведена (E_AUDIT T4 (ii)).
2. **Одно направление h.** Насыщение по одному h достаточно; «по всем направлениям» — частный случай. Это сильнее, чем насыщение по всем h.
3. **D2 в смысле владельца.** Соглашение «0/0 = 0 при p ≡ 0 на луче» — часть определения D2 здесь (v3 §3a). Другая трактовка нулевых исходов (например, предел по другой кривой) может дать другой класс насыщаемости; это вне Теоремы A.
4. **Борелевский CFIM** — открыт (§2).
5. **Нормировка.** Q = diag(1/3,2/3) (Tr 1). Сертификат инвариантен по масштабу ρ только в смысле пропорциональности; нормировка Σp = 1 используется в классической части.
6. **Номенклатура.** Теорема C (D1) и Теорема A (D2) — разные утверждения, не вложены.
