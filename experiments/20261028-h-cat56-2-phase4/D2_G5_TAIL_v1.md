Дата: 2026-10-30. Дополняет `D2_CONE_TRANSFER_v3.md` §6 (там G5 был открыт, барьер — равномерная тугость хвостов). Версия v3 не изменялась.

Статус: **аналитически закрыто для счётных и борелевских POVM в семье F_U при d < ∞, при условии верности Лемм 1–3 из v3. Не аудировано (G4 открыт). Не PROVED.**

Скрипт: `d2_v3/code/g5_countable_check.py`, лог: `d2_v3/metrics/g5_countable_check.log`.

## 0. Что меняется относительно v3 §6

v3 §6 утверждал, что для G5 нужна **равномерная тугость** `lim_K limsup_t ‖Σ_{k>K} F_k(θ_t)‖ = 0`, и считал её недоказанным барьером. Это условие **не нужно**. Достаточно теоремы о мажорированной сходимости рядов (лемма Прата, §2): поточечная сходимость слагаемых плюс сходимость мажорирующих сумм.

Исправленный барьер: вместо тугости требуется `Σ_k N_k(θ_t) → Σ_k N_k(0)`, и это следует из непрерывности `F^Q` и тождества `Σ_k N_k = F^Q`.

---

## 1. Лемма A (поэлементная мажоранта, полное доказательство)

Пусть `ρ` — состояние, `L` — SLD по направлению (то есть `∂ρ = ½(ρL + Lρ)`, `L = Lᴴ`), `E ⪰ 0` — элемент POVM, `p = tr(Eρ)`, `∂p = tr(E∂ρ)`. Тогда

`(∂p)² / p ≤ tr(E L ρ L)`, при `p > 0`.

*Доказательство.* Из `∂ρ = ½(ρL + Lρ)` и эрмитовости E, ρ, L: `Re tr(E∂ρ) = Re tr(ELρ)` (поскольку `conj tr(EρL) = tr(LρE) = tr(ELρ)`). Положим `a := E^{1/2}ρ^{1/2}`, `b := E^{1/2}Lρ^{1/2}`. Тогда `tr(aᴴb) = tr(ρ^{1/2}E Lρ^{1/2}) = tr(ELρ)`, `‖a‖²_HS = tr(Eρ) = p`, `‖b‖²_HS = tr(ρ^{1/2}LELρ^{1/2}) = tr(E LρL)`. Коши–Шварц: `(∂p)² ≤ p · tr(ELρL)`. ∎

Матричная версия: для любого `x ∈ ℝ^S` с `L_x = Σ x_a L_a` имеем `(x·∂p)²/p ≤ tr(E L_x ρ L_x) = xᵀN x`. Значит `F_k(θ) ⪯ N_k(θ)` (матрицы), где `N_k(θ)_ab = Re tr(E_k L_a ρ L_b)`.

Лемма A не использует конечномерности и верна поточечно для каждого исхода.

---

## 2. Лемма B (тождество и непрерывность) и лемма Прата

**B1.** Для счётного POVM `Σ_k E_k = I` сходится по следу (все `E_k ⪰ 0`, `Σ tr E_k = d < ∞`). Поэтому `Σ_k N_k(θ) = Re tr(L_a ρ L_b) = F^Q(θ)_ab` для каждого θ.

**B2.** `F^Q(θ)` непрерывна вдоль семьи F_U. Ранг и спектр `ρ_θ` постоянны: ненулевые собственные значения `{1/3, 2/3}` отделены от нуля, а спектральный проектор на носитель равен `U_θ P_0 U_θᴴ` и гладко зависит от θ. Формула `F^Q_ab = Σ_{λ_i+λ_j>0} 2 Re[(∂_aρ)_{ij}(∂_bρ)_{ji}]/(λ_i+λ_j)` непрерывна, ядро–ядро слагаемые обращаются в ноль (проверено численно, лог: `max|D_kk| = 0`).

**Постоянный ранг и выбор SLD (добавлено 2026-10-30, по handoff).** Ранг `ρ_θ` на семье F_U равен 2 (ненулевые собственные значения `1/3` и `2/3`). Непрерывный выбор SLD: `L_a(θ) = U_θ L̃_a(θ) U_θᴴ`, где `U_θ` — непрерывный унитар семьи. Тождество `∂ρ = ½(ρL + Lρ)` для этого выбора в данной правке не перепроверено: [UNKNOWN до проверки].

**Лемма прата (лемма о мажорированной сходимости для рядов).** Пусть `0 ⪯ f_k(t) ⪯ g_k(t)`, `f_k(t) → f_k`, `g_k(t) → g_k` при каждом k, и `Σ_k g_k(t) → Σ_k g_k < ∞`. Тогда `Σ_k f_k(t) → Σ_k f_k`.

*Доказательство.* Нижняя оценка: Фату для `f`, `liminf Σ f_k(t) ≥ Σ f_k`. Верхняя: Фату для `g − f ≥ 0`: `liminf Σ(g_k(t) − f_k(t)) ≥ Σ(g_k − f_k)`; так как `Σ g_k(t) → Σ g_k`, получаем `limsup Σ f_k(t) ≤ Σ f_k`. ∎

Равномерный хвост **не нужен**: сходимость мажорант уже даёт сходимость сумм.

## 3. Счётный POVM: теорема

**Теорема G5(c).** Пусть `{E_k}_{k∈ℕ}` — счётный POVM на ℂ²², семья F_U (§0 v3), `h ∈ ℝ^S`. Тогда

`lim_{t→0} Σ_k F_k(th) = Σ_k F_k^lim(h)`, где `F_k^lim = F_k(0)` для регулярных k (`p_k(0) > 0`), а для нулевых k `F_k^lim = (N_k h)(N_k h)ᵀ/(hᵀN_k h)` (или 0, если `hᵀN_kh = 0`). Здесь `N_k := N_k(0)`.

*Доказательство.*
- Мажоранта: `F_k(θ_t) ⪯ N_k(θ_t)` (Лемма A), `Σ_k N_k(θ_t) = F^Q(θ_t) → F^Q(0) = Σ_k N_k(0)` (Лемма B).
- Поточечная сходимость слагаемых: для регулярного k — непрерывность `F_k` при `p_k(0) > 0`; для нулевого k — предел (3b) из v3 (`p_k(th) = ¼t²hᵀN_kh + O(t³)`, `∇p_k = (t/2)N_kh + O(t²)`), численно подтверждён (лог, G3).
- Лемма Прата (матрицы — покомпонентно через квадратичные формы `xᵀ(·)x`, по лемме A для каждого x). ∎

**Насыщение по счётному POVM.** Пусть `lim_t Σ_k F_k(θ_t) = F^Q(0)`. По теореме: `Σ_k (N_k(0) − F_k^lim) = F^Q(0) − Σ_k F_k^lim = 0`. Слагаемые `N_k(0) − F_k^lim ⪰ 0` (Лемма A при t→0), ряд сходится ⇒ **каждое слагаемое равно 0**. Это поэлементное насыщение из v3 §4, теперь для счётного набора.

## 4. Конусная необходимость без замыкания конуса

Для счётного POVM каждый `D_k` (блок E₂₂) насыщен, значит по Леммам 2–3 v3 лежит в `cone_fin{yyᴴ : y ∈ 𝒴_S}` (конечная комбинация). Сумма `Σ_k D_k = I₂₀` сходится по следу.

Сепаратор R (P5, P6 v3): `σ := sup_{y ∈ 𝒴_S, ‖y‖=1} yᴴRy < tr R / 20`. Для каждого k, `D_k = Σ_j c_{kj} y_{kj} y_{kj}ᴴ`, `yᴴ R y ≤ σ‖y‖²`, поэтому `tr(R D_k) ≤ σ tr D_k`. Суммируя (ряды положительны и сходятся):

`tr R = tr(R I₂₀) = Σ_k tr(R D_k) ≤ σ Σ_k tr D_k = 20 σ < tr R`.

Противоречие. Значит `I₂₀` не насыщается счётным POVM. Замыкание конуса **не требуется**: оценка работает на каждом `D_k` отдельно.

## 5. Борелевский POVM

Пусть `E(·)` — POVM на борелевской σ-алгебре пространства Ω (стандартное борелевское). Положим `m(B) := tr E(B)`, конечная мера с `m(Ω) = d`. По Радону–Никодиму `E(B) = ∫_B e(ω) dm(ω)`, где `e(ω) ⪰ 0` и `tr e(ω) = 1` для m-почти всех ω (поскольку `tr E(B) = m(B)`).

Классическая информация Фишера семейства `f_θ(ω) := tr(e(ω)ρ_θ)` относительно m: `F^C(θ) = ∫ (∂f_θ)²/f_θ dm` (по f > 0). Это стандартное представление FI для семейства, абсолютно непрерывного относительно m; совпадение с супремумом по конечным разбиениям [INFERRED, стандартный факт, не выведен здесь полностью].

- Мажоранта (Лемма A поточечно по ω): `F_ω(θ) ⪯ g_θ(ω) := N_ω(θ) = tr(e(ω) L_a ρ_θ L_b)`, `∫ g_θ dm = F^Q(θ)` (потому что `∫ e dm = I`).
- Поточечная сходимость: `g_{θ_t}(ω) → g_0(ω)` для m-почти всех ω (непрерывность `L_t`, `ρ_t`, e(ω) фиксирован), `∫ g_{θ_t} dm = F^Q(θ_t) → F^Q(0) = ∫ g_0 dm`.
- Лемма Прата для интегралов (та же аргументация) даёт `∫ F_ω(θ_t) dm → ∫ F_ω^lim dm`.

Насыщение: `∫ (g_0 − F_ω^lim) dm = 0`, подынтегральная функция ⪰ 0 ⇒ **почти всюду** `F_ω^lim = g_0(ω)`, т.е. поэлементное насыщение m-почти всюду. По §4 для почти всех ω блок `e₂₂(ω)` лежит в конусе, и

`I₂₀ = ∫ e₂₂(ω) dm(ω)`, `tr(R I₂₀) = ∫ tr(R e₂₂(ω)) dm ≤ σ ∫ tr e₂₂ dm = 20σ < tr R`.

Противоречие такое же. Борелевский случай тоже закрыт, при тех же условиях (d < ∞, семья F_U, Леммы 1–3 v3).

## 8. Статус

- Сведение G5 (счётные POVM в F_U, d < ∞): аналитически доказано по §1–3 (Лемма A, Лемма Прата, непрерывность F^Q). Из него следует поэлементное насыщение каждого исхода. Численная поддержка — §6, только для конечного усечения.
- Сведение G5 (борелевские POVM): аналитически по §5, с [INFERRED] в одном стандартном шаге (представление FI через интеграл).
- **Финальное противоречие «I₂₀ ∉ cone» не доказано.** Оно зависит от верхней оценки σ < tr R/20 для сепаратора (§7 п. 4), которой нет. Поэтому утверждение следует читать как условную импликацию: D2-насыщение счётным или борелевским POVM ⇒ I₂₀ ∈ cone{yyᴴ : y ∈ 𝒴_S}. Это та же условная форма, что у Теоремы A.
- Общий статус переноса D2: **CONDITIONAL**, не PROVED. Блокеры: (а) верхняя оценка σ для S = {4..15}; (б) независимый аудит v3 (G4).
