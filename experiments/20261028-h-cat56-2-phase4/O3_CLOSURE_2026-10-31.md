# O3 v2 — закрытие: округления, оценки, покрытие, происхождение журналов (2026-10-31)

Объект: верхняя граница B_up(cell) < s для всех ячеек направлений x ∈ S³ (Bloch-параметризация) при S− = {4..15}, и разделитель tr R − 20 s > 0.

## 1. Что именно доказывается

Для каждой ячейки Λ (направления x с |u − u₀| ≤ du) и каждого y ∈ ker Φ(u), |y| = 1: yᴴRy ≤ B_up(Λ) ≤ s. Из этого по разделению (`STAGE_C_FINAL_PROOF.md` §6) tr R ≤ 20 sup ≤ 20 s, что противоречит tr R − 20 s > 0. Итоговая величина: tr R − 20 s = 0.030405245308261095 (arb, 192 бита).

## 2. Аналитические оценки (cell lemma L1–L4)

- L1: |u − u₀| ≤ du для всех u в ячейке (путь «θ, потом φ»; формула du = ½h_θ + sin(θ_hi/2)·h_φ + 10⁻¹² — верхняя граница в arb).
- L2: для u с |u − u₀| ≤ du и единичного y ∈ ker Φ(u): ‖Φ₀ y‖ = ‖Φ(Δ)y‖ ≤ du·(Σ‖A_j‖²)^{1/2}.
- L3: разложение y = z + w, z ∈ K = ker Φ₀, w ∈ row Φ₀; |w| ≤ ρ|z| при κ < 1 (ρ = κ_K/(1−κ)).
- L4: yᵀMy ≤ max(λ_K, 0) + 2‖MZ‖ρ + ‖M‖ρ² = B.
Статус: **PROVED-hand** (перевыведено в `STAGE_C_FINAL_PROOF.md` §5; агент-аудит O1 — частично, слабая независимость). Математика проста; коэффициенты — явные.

## 3. Округления

- Вычисления в arb (ball arithmetic), prec 192 бита. Все операции — с сохранением включения (inclusion isotonicity): exact значение лежит внутри шара.
- Входы: R (float64, точные двоичные рациональные числа), границы ячеек (float), константа 10⁻¹² (верхняя граница). Преобразование R: симметризация в arb, (R + Rᴴ)/2, — ошибка 5·10⁻¹⁷ в исходной матрице переносится на tr R на 10⁻¹⁶, что много меньше зазора 0.0304.
- Границы: λ_max верхняя (Gershgorin на V⁻¹BV, V — любой преобразователь из float eigh; корректность не зависит от точности V, так как Gershgorin — для спектра C = V⁻¹BV, а C вычисляется в arb).
- s_target = 0.9·tr R/20: вычислена из float-значений ((arb(float)) — точное значение в binary, без округления при переходе.
- **Минимальный запас** в прогоне 8.4·10⁻⁹ — это ширина шара, в котором arb гарантирует включение; порядок ошибки округления при 192 битах около 10⁻⁵⁸. То есть запас 8.4·10⁻⁹ — не эвристика, а строго положительный интервальный результат.
