## 1. Постановка и гипотезы

- Модель: ρ = diag(Q,0), Q = diag(1/3,2/3) ≻ 0, L_a = [[0,A_aᴴ],[A_a,0]], a ∈ S = {4..15} (0-based), A_a = −2iB_a (конвенция инстанса).
- Y_S(x) := {y ∈ C²⁰ : A_aᴴy ∈ R·x ∀a ∈ S} для x ≠ 0; Y_S(0) := {y : A_aᴴy = 0 ∀a}; 𝒴_S := ∪_x Y_S(x) (включая Y_S(0)); 𝒞_S := cone{yyᴴ : y ∈ 𝒴_S}.
- Семья F_U: ρ_θ = U_θρU_θᴴ, U_θ = exp(Σ_a θ_a X_a), X_a = [[0,−B_aᴴ],[B_a,0]], B_a = A_a/2. Точка θ₀ = 0, L_a(0) = L_a (первый порядок).
- **Гипотезы теоремы A (все явно):** (H1) семья F_U, θ₀ = 0; (H2) Q ≻ 0; (H3) E_k не зависят от θ и POVM полон, ΣE_k = I₂₂; (H4) θ-координаты вне S фиксированы нулём; (H5) направление h ∈ R^S.
- **Соглашение D2 (явное).** Для исхода E_k и h: если p_k(θ) > 0 при θ = th, то F_k(th) := ∂p_k ∂p_kᵀ/p_k. Если p_k(th) = 0, то F_k(th) := 0. Это соглашение задаёт F_k(th) на всех t, включая изолированные t_k, где регулярный исход обращается в ноль. Предел F_lim_k(h) := lim_{t→0} F_k(th) (существует: для регулярного k — по непрерывности; для нулевого k — лемма 3b). Матричный предел F_D2(h) := Σ_k F_lim_k(h) (определяется по лемме 5). Любая другая трактовка нулевых исходов, дающая PSD-значения ⪯ N_k(0), приводит к тому же выводу (см. §5).

## 2. Утверждения

**Теорема C (D1, отрицательная, сертифицирована).** Нет POVM с CFIM_D1(θ₀) = F^Q_S. Статус: PROVED-hand + VERIFIED-interval (O3 v2; журнал AUDIT_PASS).

**Теорема A (D2, конечные и счётные POVM).** При (H1)–(H5): если F_D2(h) = F^Q_S(θ₀) как матрицы 12×12, то I₂₀ ∈ 𝒞_S. Поскольку I₂₀ ∉ 𝒞_S (разделитель R, tr R − 20s = 0.0304 > 0, сертификат O3 v2), такого POVM не существует.

Статус: **CONDITIONAL → PROVED-hand для конечного случая** (независимая перепроверка агентом, см. `D2_CONE_TRANSFER_v3.md` §§1–5); **счётный случай: PROVED-hand с соглашением §1** (лемма 5, §4). Аудит — weak-medium независимость (агент той же модели без истории вывода); полный независимый аудит человеком или моделью другого семейства не выполнен.

## 3. Цепочка (конечный случай)

Используются `D2_CONE_TRANSFER_v3.md` (корень phase4):
- Лемма 1 (блочная): x^T(N_E − F_E)x = Re tr(RM_xQM_xᴴ) + (T₁−T₂), оба слагаемых ≥ 0.
- Лемма 2 (регулярные исходы): при матричном насыщении BA_a = μ_aP, RA_a = 0, D_E ∈ 𝒞_S.
- Лемма 3 (нулевые исходы): (3a) точная нулевая норма ⇒ p ≡ 0 на луче; (3b) предел (Nh)(Nh)ᵀ/(hᵀNh) ⪯ N_E; (3d) rank ≤ 1 ⇔ y ∈ 𝒴_S.
- Лемма 4 (вещественная матрица Грама): rank N^S(yyᴴ) ≤ 1 ⇔ y ∈ 𝒴_S.
- Поэлементное насыщение: Σ_k(N_k(0) − F_lim_k(h)) = 0 с PSD-слагаемыми ⇒ каждое слагаемое 0.

**Шаг в конус (явно).** Для каждого k: D_k := (E_k)₂₂ ∈ 𝒞_S (лемма 2 или 3). Для разделителя R (эрмитова 20×20) по определению sup_{𝒴¹} yᴴRy ≤ s, где 𝒴¹ — единичные векторы из 𝒴_S. Тогда tr(R D_k) ≤ s·tr(D_k) для каждого k (линейность следа и определение конуса). Суммируя по k (сходимость: Σ_k D_k = I₂₀, Σ_k tr D_k = 20): tr R = Σ_k tr(R D_k) ≤ 20s. Противоречие с tr R − 20s > 0. Этот шаг не требует замкнутости конуса и не зависит от числа исходов.

## 4. Счётный случай (лемма 5) — с явным соглашением

**Лемма 5.** Пусть {E_k}_{k∈N} — POVM. Положим N_k(θ) := Re tr(E_k L_a(θ)ρ(θ)L_b(θ)), F_k(θ) по соглашению §1.
(i) N_k(θ) ⪰ 0; F_k(θ) ⪯ N_k(θ) для всех θ (Коши–Шварц: (Re tr(E L_xρ))² ≤ tr(ρE)·tr(ρ L_x E L_x), с учётом p = 0 ⇒ F = 0).
(ii) Σ_k N_k(θ) = F^Q(θ) при всех θ (полнота, сходимость по следу).
(iii) Хвост T_K(θ) := Σ_{k>K} N_k(θ) непрерывен по θ при фиксированном K; ‖T_K(0)‖ → 0 при K→∞. Поэтому limsup_{t→0} ‖T_K(th)‖ = ‖T_K(0)‖.
(iv) 0 ⪯ Σ_{k>K}F_k(th) ⪯ T_K(th). Для каждого фиксированного k функция t ↦ F_k(th) сходится к F_lim_k(h) (при изолированных нулях p_k(th) значения F_k = 0 не мешают пределу, так как для малых |t| вне конечного множества нулей p_k > 0 при p_k(0) > 0; для нулевых k — лемма 3b). Тогда lim_{t→0} Σ_k F_k(th) = Σ_k F_lim_k(h).

**Следствие.** Если F_D2(h) = F^Q(0), то Σ_k(N_k(0) − F_lim_k(h)) = 0 с PSD-слагаемыми ⇒ N_k(0) = F_lim_k(h) для всех k; далее — как в конечном случае.

**Замечание о пробеле v1.** В v1 не было соглашения о нулях регулярных исходов в отдельных точках луча. Оно введено в §1: F_k(th) := 0 при p_k(th) = 0. Это не меняет вывода, так как оценка (i) сохраняется.
