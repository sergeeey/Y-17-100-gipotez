# O3 v2 — предпроверка ядра и проектора (стадия C, S−)

Дата: 2026-10-29. Код: `code/interval_cells_v2.py`, `code/preflight_v2.py`. Хеши: `SHA256SUMS_o3v2.txt`.
Отличие от v1: (i) симметризация R выполняется в arb (точная эрмитова часть), а не в float;
(ii) сертификат ядра (a)–(d) обязателен для каждой ячейки; (iii) множитель 1/(1−δ) для неортонормальности базиса.

## 1. Точность входов [VERIFIED]

- Φ_j (4 матрицы 36×40): целые значения, max |Φ| = 156 < 2⁵³, точно представимы в float64.
  Проверено: `np.all(P == np.round(P))` = True.
- R: файл `s14_R_…nx250.npz` **не эрмитов точно**: max|R − R^H| = 5.2·10⁻¹⁷ (298 ненулевых разностей).
  Предыдущее утверждение «R проверена np.array_equal» в сводке стадии C **неверно для этого файла**;
  исправлено: строится точная эрмитова часть H = (R + R^H)/2 в arb по формулам
  Re H_ij = (Re R_ij + Re R_ji)/2, Im H_ij = (Im R_ij − Im R_ji)/2; M = [[Re H, −Im H], [Im H, Re H]].
- Центр u0 = (cos(θc/2), 0, sin(θc/2)cos φc, sin(θc/2)sin φc) вычисляется в arb из шаровых границ ячейки.
- Вход ячейки (рёбра) — точные double.

## 2. Включение (inclusion isotonicity) [DOCS: стандартное свойство ball arithmetic]

Каждая операция arb возвращает шар, содержащий результат для любых точных входов из входных шаров.
Поэтому Φ0-шар ∋ точное Φ(u0), G-шар ∋ точное Φ0Φ0ᵀ, и т.д. Аргументы ниже относятся к точным объектам.

## 3. Обратимость (a) и размерность ядра [INFERRED из (a) + VERIFIED по каждой ячейке]

- Если det-шар G имеет нижнюю границу > 0, то точная G невырождена, следовательно точная Φ0 имеет полный строчный ранг 36.
- Тогда dim ker Φ0 = 40 − 36 = 4 (точно).
- Проверка (a) выполняется **для каждой ячейки** в `kernel_certificate`. Аналитического доказательства невырожденности
  для всех ячеек здесь нет: это сертификат ячейки, и ячейка без сертификата не используется.
- Негативный тест N4 (строка 35 := строка 34): `det_lower = −1.27·10⁻¹²`, `inv` падает `ZeroDivisionError: matrix is singular`. Отвергнуто.

## 4. Проектор P (покрытие точного проектора) [INFERRED + VERIFIED (d)]

- Точный Pinv = Φ0ᵀ(Φ0Φ0ᵀ)⁻¹ (Moore–Penrose при полном строчном ранге) лежит в Pinv-шаре, так как G⁻¹ — арбовское обращение с включением.
- Точный P = I − Pinv·Φ0 = ортогональный проектор на ker Φ0 (единственный). Он лежит в шаре P.
- Проверка (d): Φ0·P содержит 0 во всех элементах. Для точного проектора это тождество, для шара — необходимое условие согласованности.

## 5. Базис K (гарантированная принадлежность и независимость) [INFERRED + VERIFIED (b),(c)]

- Старт: Zf из float-SVD Φ0f. Float-SVD влияет только на стартовые векторы; Z1 = P·Zf — точный ортогональный образ стартовых векторов на ядре.
- Грам–Шмидт в arb: шар Z0 содержит точный результат Грама–Шмидта от точных представителей. Значит шар Z0 содержит точный
  ортонормальный базис Z* ядра Φ0 (при линейной независимости, что и проверяет (c)).
- (b) Φ0·Z0 ∋ 0: столбцы Z0 лежат в ядре.
- (c) Гершгорин: сумма |(Z0ᵀZ0 − I)_ij| по строкам < 1 ⇒ столбцы независимы; вместе с (a) это базис ядра.
- Дополнительно (belt-and-braces): δ = верхняя граница ‖Z0ᵀZ0 − I‖₂ (Гершгорин). Z0 = Z*T, T = Z*ᵀZ0, TᵀT = I + E,
  ‖T⁻¹‖² ≤ 1/(1−δ). Все величины (λ_K, ‖MZ‖, κ_K) оценены из Z0 и при переходе к Z* умножаются не более чем на 1/(1−δ),
  поэтому сертифицируемая граница B_cert = B_code/(1−δ). δ ≈ 10⁻⁴² на проверенных ячейках, поправка численно пренебрежима,
  но теперь формально учтена.

## 6. Что проверяют шаровые оценки λ_K и ‖MZ‖ [DOCS + INFERRED]

- λ_max симметричной точной матрицы B ≤ max_i (C_ii + Σ_{j≠i}|C_ij|) для C = V⁻¹BV (Гершгорин; V — приближённые собственные векторы,
  V⁻¹ — арбовское обращение, включение сохраняется). Верхняя граница берётся от шаровых верхних концов.
- λ_K использует правило верхней границы (исправление от предыдущего этапа): lamK = max(λ_up, 0).
