# S−: количественный запрет D2 для конечных и борелевских POVM (v3, 2026-10-31)

Заменяет разделы B–D `S_MINUS_BOREL_v2.md` и устраняет зависимость от точного насыщения по элементам. Цель: одна лемма, которая дает запрет для любого конечного POVM количественно, и её следствие для борелевских POVM без обмена предела и интеграла.

## 0. Модель и гипотезы (явно)

- Вся структура из `S_MINUS_FINAL_v2.md` §1: d = 22, ρ = Q ⊕ 0, Q ≻ 0 (Q = diag(1/3,2/3)), S = {4..15} (0-based), A_a ∈ C^{20×2}, A_a = −2iB_a (конвенция инстанса C2).
- Семья F_U: ρ_θ = U_θ ρ U_θᴴ, U_θ = exp(Σθ_aX_a), X_a = [[0,−B_aᴴ],[B_a,0]], B_a = A_a/2. θ₀ = 0. Направление h ∈ R^S.
- D2-предел для конечного POVM E = {E_k} (с D_k := (E_k)_{22}): F_k(th) := ∂p_k ∂p_kᵀ/p_k при p_k(th) > 0, F_k(th) := 0 при p_k(th) = 0; F_k := lim_{t→0} F_k(th) (существует, см. §2); F_D2(h) := Σ_k F_k.
- Разделитель: R* ∈ Herm(20), s* := sup{yᴴR*y : y ∈ 𝒴¹_S}, где 𝒴¹_S := {y ∈ C²⁰, |y| = 1, ∃x: A_aᴴy ∈ R·x ∀a ∈ S} (включая вырожденный случай). Для S− имеем γ := tr R* − 20 s* > 0 (γ = 0.0304 в O3, `O3_CLOSURE_2026-10-31.md`).

## 1. Элементные величины

Для PSD D ∈ Herm₊(20) положим N_D := (Re tr(D A_a Q A_bᴴ))_{a,b∈S} ∈ S^{12}. Тогда:
- N_D ⪰ 0; N_{D+D'} = N_D + N_{D'}; N_{I₂₀} = F^Q_S (полнота, Σ_k N_{D_k} = F^Q при Σ_k D_k = I₂₀).
- Для вектора y: N_y := N_{yyᴴ} — Gram-матрица вещественных скалярных произведений векторов g_a = Q^{1/2}A_aᴴy ∈ C²: (N_y)_{ab} = Re⟨g_a, g_b⟩ (проверено выше: N_y ⪰ 0).
- **Лемма G (ранг).** rank N_y ≤ 1 ⇔ y ∈ 𝒴_S. Доказательство: rank N_y = dim_R span_R{g_a}; ранг ≤1 ⇔ g_a = λ_a z с λ_a ∈ R ⇔ A_aᴴy = λ_a Q^{−1/2}z ⇔ y ∈ Y_S(Q^{−1/2}z) (или y ∈ Y_S(0)). Это Lemma 4 из `D2_CONE_TRANSFER_v3.md` §13.

## 2. Элементы D2 (структура дефекта)

**Лемма D2a.** Для каждого k: F_k ⪯ N_{D_k} и rank F_k ≤ 1.
- Регулярный k (p_k(0) > 0): F_k(0) = ∂p∂pᵀ/p — rank 1; неравенство F_k ⪯ N_{D_k} — Коши–Шварц (`S_MINUS_FINAL_v2.md` §4 (i), аудит агента — подтверждено, пункт 2).
- Нулевой k (p_k(0) = 0): F_k = (Nh)(Nh)ᵀ/(hᵀNh) при hᵀNh > 0 (ранг 1, ⪯ N по Коши–Шварцу для PSD N), F_k = 0 при hᵀNh = 0 (ранг 0). Формула — `D2_CONE_TRANSFER_v3.md` §3b, 3a; проверено численно (`S5`).
Положим δ_k := N_{D_k} − F_k ⪰ 0 и Δ := Σ_k δ_k = F^Q_S − F_D2(h) ⪰ 0.

**Лемма D2b (спектральный дефект).** λ₂(N_{D_k}) ≤ tr δ_k.
*Доказательство.* N_{D_k} = F_k + δ_k, rank F_k ≤ 1, δ_k ⪰ 0. По неравенству Вейля λ₂(A+B) ≤ λ₂(A) + λ₁(B) с λ₂(F_k) = 0 и λ₁(δ_k) ≤ tr δ_k. ∎

## 3. Функция Łojasiewicz

Пусть Σ := {y ∈ C²⁰ : |y| = 1} ≅ S⁴⁰ (компакт). Определим f(y) := λ₂(N_y) (второе собственное значение, вещественная 12×12 матрица с полиномиальными по (Re y, Im y) элементами). Тогда:
- f непрерывна и полуалгебраична на Σ (собственные значения симметричной полиномиальной матрицы полуалгебраичны);
- f ≥ 0; Z := {f = 0} = 𝒴¹_S (по лемме G и |y| = 1); Z ≠ ∅ (Y_S(x) имеет вещественную размерность ≥ 4 и содержит ненулевые векторы).

**Лемма Ł (неравенство Łойасевича).** Существуют C_Ł > 0 и θ ∈ (0, 1] такие, что dist(y, 𝒴¹_S) ≤ C_Ł · f(y)^θ для всех y ∈ Σ. (Łojasiewicz 1959; Bochnak–Coste–Roy, «Real Algebraic Geometry», следствие о полуалгебраических функциях на компактах.) Константы C_Ł, θ зависят только от (A_a, Q, S) и не от POVM.
Статус: **PROVED** (стандартная теорема; проверка применимости — полуалгебричность f и компактность Σ). Константы не вычислены явно.

## 4. Элементная оценка

**Лемма E.** Для любого PSD D с спектральным разложением D = Σ_j d_j y_j y_jᴴ (|y_j| = 1, d_j > 0, J ≤ 20 слагаемых) и любого Hermitian R*:
tr(R*D) − s* tr D ≤ 2‖R*‖ Σ_j d_j dist(y_j, 𝒴¹_S).
*Доказательство.* Для единичного y и ближайшего z ∈ 𝒴¹ (|y − z| = dist): yᴴR*y − zᴴR*z = (y−z)ᴴR*y + zᴴR*(y−z) ≤ 2‖R*‖·dist, а zᴴR*z ≤ s*. Суммируя с весами d_j (Σ d_j = tr D): tr(R*D) = Σ_j d_j y_jᴴR*y_j ≤ s* Σ_j d_j + 2‖R*‖ Σ_j d_j dist_j. ∎

## 5. Главная количественная оценка

**Теорема Q (конечный POVM).** Пусть E = {E_k}_{k=1}^K — конечный POVM на C²², семья F_U, направление h. Пусть γ := tr R* − 20 s* > 0. Тогда
tr(F^Q_S − F_D2(h)) ≥ (γ / (40 ‖R*‖ C_Ł))^{1/θ}.
В частности, F_D2(h) ≠ F^Q_S (точное насыщение невозможно), и граница не зависит от POVM.

*Доказательство.* Используем Σ_k D_k = I₂₀ и tr R* = Σ_k tr(R*D_k). Для каждого k возьмём спектральное разложение D_k = Σ_j d_{kj} y_{kj}y_{kj}ᴴ.
(1) По лемме D2b и N_{D_k} = Σ_j d_{kj} N_{y_{kj}}: d_{kj} N_{y_{kj}} ⪯ N_{D_k}, значит d_{kj} f(y_{kj}) ≤ λ₂(N_{D_k}) ≤ tr δ_k. Следовательно f(y_{kj}) ≤ tr δ_k / d_{kj}.
(2) По лемме Ł: dist(y_{kj}, 𝒴¹) ≤ C_Ł (tr δ_k / d_{kj})^θ.
(3) По лемме E: tr(R*D_k) − s* tr D_k ≤ 2‖R*‖ C_Ł Σ_j d_{kj}^{1−θ} (tr δ_k)^θ ≤ 2‖R*‖C_Ł J_k^θ (tr D_k)^{1−θ}(tr δ_k)^θ, где J_k ≤ 20.
(4) Суммируя по k, tr R* − 20 s* = Σ_k [tr(R*D_k) − s* tr D_k] ≤ 2‖R*‖C_Ł 20^θ Σ_k a_k^θ b_k^{1−θ}, где a_k = tr δ_k, b_k = tr D_k. По неравенству Гёльдера Σ_k a_k^θ b_k^{1−θ} ≤ (Σa_k)^θ (Σb_k)^{1−θ} = (tr Δ)^θ · 20^{1−θ}. Итог: γ ≤ 40‖R*‖C_Ł (tr Δ)^θ.
Отсюда tr Δ ≥ (γ/(40‖R*‖C_Ł))^{1/θ}. ∎

**Замечания.**
- Нет обмена предела и интеграла: используются только конечные суммы, неравенство Коши–Шварца по элементам и Гёльдер по конечной сумме.
- Нет предположения о насыщении по элементам. Теорема Q количественно сильнее прежнего точного запрета: даже приближённое насыщение недостижимо на определённую величину.
- Проверка знака: для S+ разделителя с γ > 0 не существует (там есть явный POVM), то есть лемма не даёт ложного запрета. Это контрольный тест совместимости.
- Константы C_Ł, θ неявные (Łojasiewicz). Явная оценка возможна через κ-анализ (см. §6), но не нужна для качественного запрета.

## 6. Постоянство ранга на CP¹ (ответ на п. 2 задачи)

Направления x ∈ C² с точностью до комплексного и вещественного масштаба — точка CP¹ ≅ S² (θ, φ), а Y_S(e^{iα}cx) = e^{iα}Y_S(x) (c > 0) — размерность и ранг инвариантны, поэтому достаточно CP¹.

**Предложение R (постоянный ранг).** Для каждой ячейки Λ из O3 (|u − u₀| ≤ du, Φ₀ = Φ(u₀), G = Φ₀Φ₀ᵀ): если det G > 0 и κ < 1, то rank Φ(u) = 36 для всех u ∈ Λ.
*Доказательство.* Φ₀ полного строкового ранга 36 (det G > 0), поэтому Φ₀Φ₀⁺ = I₃₆. Разложим Φ(u) = Φ₀ + Φ(Δ), Δ = u − u₀. Тогда Φ(Δ) = Φ₀Φ₀⁺Φ(Δ), так что Φ(u) = Φ₀ M, M := I₄₀ + Φ₀⁺Φ(Δ). По L2/Коши–Шварцу ‖Φ₀⁺Φ(Δ)‖ ≤ du (Σ_j ‖Φ₀⁺Φ_j‖²)^{1/2} = κ < 1, значит M обратима и rank Φ(u) = rank Φ₀ = 36. ∎

**Следствие.** Для каждой ячейки κ < 1 и det G > 0 сертифицированы arb (O3, `interval_cells_v2.py`, `cell_bound` возвращает OK только при этих условиях). Ячейки покрывают [0,π]×[0,2π] полностью: сумма площадей 19.7392088 = 2π² (`metrics/leaves_coverage_2026-10-31.json`, разрыв θ: 0, φ: 0). Значит dim_R Y_S(x) = 4 для всех x ∈ CP¹ — **PROVED** (с опорой на arb-сертификат журнала O3).

**Равномерная оценка.** σ₃₆(Φ(u)) = σ₃₆(Φ₀M) ≥ σ₃₆(Φ₀)·σ_min(M) ≥ σ₃₆(Φ₀)(1 − κ). Минимум по ячейкам даёт равномерную нижнюю границу ненулевой сингулярной величины Φ(u) по CP¹; численная оценка σ₃₆ — VERIFIED-NUMERIC (нужна arb-нижняя граница, если её требовать строгой).

## 7. Борелевские POVM

**Определение (принятое).** Для борелевского POVM M на стандартном борелевском X: F^C_M,D2(h) := sup_n F_{P_n,D2}(h), где (P_n) — вложенная последовательность конечных разбиений, порождающая борелевскую σ-алгебру, а F_{P,D2}(h) := Σ_{B∈P} F_{M(B),D2}(h) (D2-предел классической FI конечного POVM {M(B)}_{B∈P}).

Два факта:
- (i) Монотонность: P_n ≤ P_{n+1} ⇒ F_{P_n,D2} ⪯ F_{P_{n+1},D2} (обработка данных для классической FI вдоль каждого направления x, затем предел t→0). Значит последовательность возрастает по Лёвнеру и ограничена F^Q (по D2-лемме для конечного POVM, F_{P,D2} ⪯ F^Q — следствие Лемма D2a и Σ N = F^Q).
- (ii) Не требуется эквивалентность с интегральной формой ∫(∂f)²/f dμ: определение задано через конечные разбиения (как в Gill–Levit для классической информации Фишера; эквивалентность sup по разбиениям и предела по порождающей последовательности — стандартный факт, точная ссылка не проверена).

**Следствие (борелевский запрет).** Для любого борелевского POVM M с F^C_M,D2(h) = F^Q_S в семье F_U: tr(F^Q − F_{P_n,D2}) → 0. По теореме Q (применённой к конечному POVM {M(B)}_{B∈P_n}) tr(F^Q − F_{P_n,D2}) ≥ c_0 := (γ/(40‖R*‖C_Ł))^{1/θ} > 0 для всех n. Противоречие. ∎

Итого: **для борелевских (и, в частности, счётных и конечных) POVM в семье F_U при одном направлении h и определении §7 насыщение CFIM = QFIM в D2 невозможно**; более того, отклонение tr(F^Q − F_D2) ≥ c_0 > 0 равномерно.

## 8. Границы применимости

1. Семья F_U (используется в формуле предела для нулевых исходов, §2, лемма D2a; для общей C¹-семьи F_k может зависеть от второго порядка).
2. Одно направление h (тот же вывод для любого фиксированного h).
3. Определение CFIM §7 (sup по разбиениям); эквивалентность интегральной форме при D2 — не доказана (границы применимости).
4. Соглашение D2 для нулевых исходов (F_k := 0 при p_k ≡ 0 на луче; F_k := (Nh)(Nh)ᵀ/(hNh) при hNh > 0) — то же, что `S_MINUS_FINAL_v2.md` §1.
5. Модельная конвенция C2 (A_a = −2iB_a, Q = diag(1/3,2/3)).
6. Теорема Q не применима к S+ (разделителя с γ > 0 нет; POVM существует).
