# Стадия E v1 — поиск точного POVM для S+ = {0..11}, промежуточный отчёт, 2026-10-30

Статус: S+ НЕ доказана и НЕ опровергнута. Точный POVM не найден. Отчёт фиксирует результаты первой серии методов.

## Постановка (SDP на сетке направлений)
Элементы v = (x_j; B_j c), x_j — направления на CP¹, B_j — вещественный базис Y_S+(x_j) (`code/ys_space.py`),
c ∈ R^m, веса через моменты M_j = [[Q_j, s_j],[s_jᵀ, t_j]] ⪰ 0. Условие Σ w v v† = I₂₂ линейно по (Q_j, s_j, t_j):
(a) Σ_j t_j x_j x_j† = I₂; (b) Σ_j x_j (B_j s_j)† = 0; (c) Σ_j B_j Q_j B_j† = I₂₀. Код: `code/sdp_feas.py`.
Hermitian-равенства берутся только в верхнем треугольнике (иначе дубли, Clarabel падает). Решатель: SCS, eps 1e-9.

## Контрольные тесты (`code/controls.py`)
- Положительный: цели порождены случайными допустимыми моментами → **optimal** (допустимо). Пайплайн работает.
- Отрицательный S− = {4..15}, цель I₂₀: **infeasible**. Согласуется с теоремой C стадии C (I₂₀ ∉ cone для S−).

## Структурный факт (точная вещественная окружность)
Для x = (cos a, sin a) при семи тестовых a: ранг 34, ядро Y_S+(x) размерности 6; сингулярное значение на границе
ранга ≈ 1e-15 против ≥ 0.1 для удерживаемого. Это численное свидетельство точного разрыва ранга, НЕ сертификат.
Для комплексных направлений общая размерность 4 (200 случайных направлений).

## Что установлено и что НЕ установлено
- Установлено: пайплайн SDP корректен на контрольных тестах; точный разрыв ранга на вещественной окружности
  (численно, зазор 1e-1 против 1e-15); S+ недопустима на сетках 200 (сфера), 48 и 96 (окружность).
- НЕ установлено: недопустимость для континуума. Конечные сетки дают только верхнюю оценку допустимости:
  недопустимость на сетке не исключает допустимость на непрерывном множестве направлений.
- НЕ установлено: статусы SCS «infeasible» не проверены сертификатом двойственности.
- НЕ сделано: точный POVM; интервальный сертификат существования; cutting-plane по направлениям с двойственным
  сертификатом; алгебраическая конструкция на особых точках.
