## 0. Постановка

- d = 22 = 2 + 20; ℋ = ℋ₊ ⊕ ℋ₀, ℋ₊ = C², ℋ₀ = C²⁰.
- Состояние ρ = Q ⊕ 0, Q — нормированное состояние на ℋ₊ с положительным спектром. В инстансе Tr = 3 у diag(1,2); нормированный вариант Q = diag(1/3, 2/3). На существование POVM и на насыщение Q не влияет (лемма 2, §2); влияет только на численное значение QFIM.
- Блоки A_i ∈ C^{20×2}, i ∈ S+ = {0..11}, A_i = −2i·B_i с B_i ∈ Z[i]^{20×2} (конвенция инстанса, `TECHNICAL_NOTE_A0_EN_v1.2.md` §1). SLD-блоки L_i = [[0, A_iᴴ],[A_i, 0]], L_{i,00} не входит ни в одну величину.
- Сетка Ξ = {x_j}_{j=1}^{280} ⊂ C² \ {0}; для каждого j — вещественный базис B_{j,1..m_j} ⊂ C²⁰ пространства Y_S(x_j) = {y ∈ C²⁰ : A_iᴴ y ∈ R·x_j ∀ i ∈ S+}; m_j ∈ {6, 4} (182 и 98 направлений; сумма 1484).
- Вектор моментов: для блока j обозначим v_{j,a} := (0 ; B_{j,a}) ∈ C²² при a = 1..m_j и v_{j,n} := (x_j ; 0), где n := m_j + 1 — индекс x-части.

## 1. SLD (лемма 1)

ρ = diag(Q,0), X_i := [[0, −A_iᴴ/2],[A_i/2, 0]] (антиэрмитова, e^{X_i} унитарна), ∂_i ρ = Xρ − ρX = [[0, QA_iᴴ/2],[A_iQ/2, 0]]. Для L = [[0,Bᴴ],[B,0]] имеем (ρL+Lρ)/2 = [[0, QBᴴ/2],[BQ/2, 0]]; равенство ∂ρ = (ρL+Lρ)/2 даёт B = A. Значит SLD-блоки L_{i,+0} = A_iᴴ, L_{i,0+} = A_i. QFIM: F_ij = Re Tr(ρ L_iL_j) = Re Tr(Q A_iᴴ A_j).

**Что проверено и что — конвенция.** Вычисление выше проверяет, что L_i является SLD для семейства ρ(θ) = e^{X(θ)} ρ e^{−X(θ)}. Соответствие «инстанс ↔ физическая модель» (A = −2iB и это семейство) — конвенция пакета, см. §5.

## 2. Насыщение для одного элемента (лемма 2)

Пусть Π = d·uuᴴ, u = (α; y), d > 0.
- Tr(ρΠ) = d·Σ_n p_n|α_n|² > 0 ⇔ α ≠ 0 (p_n — собственные значения Q). **Элемент регулярен.**
- Теорема YPZJ (arXiv:1806.07337, §4.1, Thm. «thm:reg», проверено по LaTeX): Π насыщает матричную границу CFIM ⇔ Π L_i ψ_n = ξ_i Π ψ_n для всех n из спектра ρ с вещественным ξ_i (не зависящим от n).
- Для ψ_n = (e_n; 0): uᴴψ_n = conj(α_n), uᴴL_iψ_n = conj((A_iᴴy)_n). Значит условие ⇔ (A_iᴴy)_n = ξ_i α_n для n = 1, 2 с одним вещественным ξ_i.

**Лемма 2.** Регулярный элемент u = (α; y), α ≠ 0, насыщает границу ⇔ A_iᴴ y = ξ_i α для всех i ∈ S+ с ξ_i ∈ R. Условие не зависит от собственных значений p_n.

Для α = x_j и y ∈ Y_S(x_j) условие выполнено по определению Y_S (ξ_i = λ_i, вещественное). Для α = x_j с y = Σ_a c_a B_{j,a}, c ∈ R^{m_j}, — тоже (вещественная линейная оболочка Y_S, см. §3).

## 3. Лифт: точная эквивалентность 484 строк полноте POVM (лемма 3)

**Лемма 3.** Отображение H ↦ (координаты H) из Herm(22) в R^484 — R-линейный изоморфизм, где координаты:
- E1 (блок H₊₊, 2×2): Re H₁₁, Re H₁₂, Re H₂₂, Im H₁₂ — 4 числа (H₁₁, H₂₂ — диагональ, H₁₂ — внедиагональ);
- E2 (блок H₊₀, 2×20, комплексный): Re и Im всех 40 элементов — 80 чисел;
- E3 (блок H₀₀, 20×20 эрмитов): Re H_{rs} при r ≤ s (210 чисел) и Im H_{rs} при r < s (190 чисел) — 400 чисел.
Итого 4 + 80 + 400 = 484 = 22² = dim_R Herm(22). Эрмитовость восстанавливает нижний треугольник, поэтому координаты задают изоморфизм.

**Следствие.** Пусть для элемента E = d·uuᴴ с u = Σ_a c_a v_a (вещественные c_a) имеем E = Σ_{a,b} (d c_a c_b) v_a v_bᴴ. Тогда сумма по элементам Σ E = Σ_{j} Σ_{a,b} M_j[a,b] v_{j,a} v_{j,b}ᴴ с M_j := Σ_p d_{j,p} c_{j,p} c_{j,p}ᵀ — вещественная симметричная матрица. Координаты этой суммы — линейная функция M = (M_j[a,b])_{a≤b} и задаются матрицей A (484 × 6566). **Σ E = I₂₂ ⇔ A·M = b**, где b — координаты I₂₂: b_{E1} = (1, 0, 1, 0), b_{E2} = 0, b_{E3} = (1 на диагонали, 0 иначе).

**Блоки.**
- Support-блок H₊₊ = Σ_j t_j x_j x_jᴴ (t_j = M_j[n,n]): это E1.
- Перекрёстный блок H₊₀ = Σ_j Σ_a s_{j,a} x_j B_{j,a}ᴴ (s_{j,a} = M_j[a,n]): это E2; условие H₊₀ = 0 — условие «вектор x_j ⊗ y» ортогонален I.
- Kernel-блок H₀₀ = Σ_j Σ_{a,b} Q_j[a,b] B_{j,a}B_{j,b}ᴴ: это E3.

Проверено: `code/audit_lift_rows.py` (прямое построение A из определения v_a, сравнение с сохранённой A: max разн. 3.3·10⁻¹⁶; b совпадает точно). Это вычисление в float; точная версия A — тот же код на рациональных входах, см. §5.

## 4. Разложение PD-матрицы (лемма D) и теорема

**Лемма D.** Пусть M ∈ S^n, M ≻ 0. Существуют n вещественных векторов ĉ_1..ĉ_n ∈ R^n с последней координатой (ĉ_k)_n = 1 и d > 0 такие, что M = d·Σ_k ĉ_k ĉ_kᵀ.

*Доказательство.* Пусть C — вещественная матрица с M = CCᵀ (например, разложение Холецкого), C обратима. Положим w := Cᵀe_n (последняя строка C, транспонированная), w ≠ 0. Пусть u := w/‖w‖, h := (1,…,1)ᵀ/√n. Если u ≠ h, положим v := u − h и O := I − 2vvᵀ/‖v‖² (отражение Хаусхолдера; O симметрична, ортогональна, Ou = h). Если u = h, O := I. Тогда C' := CO удовлетворяет C'C'ᵀ = COOᵀCᵀ = M. Столбец c'_k = C o_k (o_k = Oe_k) имеет последнюю координату e_nᵀCo_k = wᵀo_k = ‖w‖·uᵀOe_k = ‖w‖·(Ou)_k = ‖w‖·h_k = ‖w‖/√n =: s, для всех k (использовали симметричность O). Значит c'_k = s·ĉ_k с (ĉ_k)_n = 1. Тогда M = Σ_k c'_k c'_kᵀ = s²·Σ_k ĉ_kĉ_kᵀ, d := s² = ‖w‖²/n. ∎

**Проверка.** `code/check_decomposition_v5.py`: 200 случайных PD-матриц размера 2..7, относительная ошибка реконструкции ≤ 10⁻¹⁵; пример diag(1,2): d = 1, ĉ_1 = (−1/√2, 1), ĉ_2 = (1/√2, 1), сумма d·ĉĉᵀ = diag(1,2). Видно, что диагональ (1,2) не нарушает условия: ограничение (ĉ_k)_n = 1 — только на последнюю координату.

**Теорема 3 (конечный POVM на Ξ).** Пусть для каждого j имеется M_j ≻ 0 вещественная симметричная (n_j × n_j, n_j = m_j+1), удовлетворяющая A·M = b. Тогда существует конечный набор E_{j,k} = d_j·u_{j,k}u_{j,k}ᴴ, k = 1..n_j, с
u_{j,k} := (x_j ; Σ_{a=1}^{m_j} (ĉ_{j,k})_a B_{j,a}),
где (ĉ_{j,k}), d_j — из леммы D для M_j, и выполнено:
(i) Σ_{j,k} E_{j,k} = I₂₂ (точно в R, по лемме 3);
(ii) каждый E_{j,k} регулярен: Tr(ρE) = d_j·Σ_n p_n|x_{j,n}|² > 0;
(iii) каждый E_{j,k} насыщает границу CFIM (лемма 2; условие выполнено, так как y ∈ Y_S(x_j) с вещественными коэффициентами);
(iv) Σ_{k} E_{j,k} по блоку даёт вклад M_j, поэтому CFIM = QFIM как квадратичная форма на R^{12}: по теореме YPZJ сумма матричных границ по элементам равна Σ_k Re Tr(ρ L_i E_k L_j) = Re Tr(ρL_iL_j) = F_ij, и равенство получается элементно;
(v) общее число исходов: **N_out = Σ_j n_j = 182·7 + 98·5 = 1764**.

*Доказательство.* (i) — из леммы 3 и A·M = b. (ii) — x_j ≠ 0 и d_j > 0. (iii) — лемма 2. (iv) — YPZJ в матричной форме: для каждого элемента матричная граница Re Tr(ρL_iΠL_j) (симметризованная по i,j) достигается, и сумма этих границ по k равна Re Tr(ρ L_i L_j), потому что Σ_k Π_k = I₂₂ по (i). ∎

**Замечание о нормировке.** Теорема 3 не использует значения p_n — только вещественность ξ и ненулевой α. Поэтому (i)–(iv) верны при любом нормированном Q с положительным спектром (в том числе Q = diag(1/3,2/3)). Для нормировки важно лишь Tr ρ = 1 при вычислении p_k.

**Нулевые исходы.** Их нет: при α = x_j (ненулевом по всем направлениям) все p_k > 0. Поэтому конвенции D1 и D2 совпадают и не требуют выбора; слабая D1 не используется.

## 5. Что опирается на что (компактный сертификат)

- **Точные равенства A·M* = b над Q.** Источник — `exact_cert.py` (рациональная арифметика, fmpq; `logs/exact_cert_result.json`: `rows_violated_exactly: 0`, `independent_rows: 175`). Это единственное точное доказательство равенств над Q. Компактная перепроверка по трём простым модулям (`logs/verify_cert_compact.log`: нулевой остаток mod p для трёх простых) — **не** точное равенство над Q: без доказанной границы рациональной реконструкции остаток по модулю не доказывает нулевой остаток над Q. Используется только как отпечаток.
- **Положительность M* ≻ 0.** Источник — тот же `exact_cert.py`, блок «exact LDL^T over Q»: ведущие опорные элементы Гаусса для каждого M_j* положительны (Sylvester). Точная проверка над Q; минимальный опорный элемент ≈ 1.09·10⁻³ (float-печать). Decimal-проверка (prec 200) НЕ используется как доказательство: она не контролирует округление и не завершилась.
- **Конвенция.** A = −2iB и нормированное состояние — конвенция пакета (§0, §1), не выведена здесь из первоисточника.
