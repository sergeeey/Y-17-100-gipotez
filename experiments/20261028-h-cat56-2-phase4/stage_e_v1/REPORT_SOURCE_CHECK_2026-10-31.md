## 1. Условие насыщения для регулярных элементов (YPZJ, arXiv 1806.07337, v3, §4.1, Thm "thm:reg")

**VERIFIED-source.** Верно: элемент Π_k регулярен, если Tr(ρΠ_k) ≠ 0; тогда CFIM-граница насыщена в точке λ ⟺
Π_k L_iλ |ψ_nλ⟩ = ξ_i^k Π_k |ψ_nλ⟩ для всех i, k, n, где ξ_i^k вещественны и не зависят от n. Здесь n пробегает спектр ρ с p_n > 0.

**Специализация на наш случай (INFERRED из VERIFIED):**
ρ = diag(1/3, 2/3) ⊕ 0 (ℋ_+ = C², ℋ_0 = C²⁰), ψ_n = (e_n; 0) для n = 1,2.
L_i = [[0, A_iᴴ],[A_i, 0]]. Пусть элемент Π = |u⟩⟨u| с u = (c_m x; y), y = Bc ∈ C²⁰, c_m ≠ 0.
Тогда L_i ψ_n = (0; A_i e_n), ⟨u|L_i ψ_n⟩ = yᴴ A_i e_n = conj((A_iᴴ y)_n),
⟨u|ψ_n⟩ = conj(c_m x_n).
Условие ⟨u|L_iψ_n⟩ = ξ_i ⟨u|ψ_n⟩ (ξ_i вещественно) ⟺ (A_iᴴ y)_n = ξ_i c_m x_n ⟺ A_iᴴ y = λ_i x с вещественным λ_i = ξ_i c_m (после деления на c_m ≠ 0, с учётом вещественности c_m).
Это совпадает с проверкой Y_S(x) в `code/ys_space.py` (условие «Im(xᴴu)=0 и u ∥ x») и с аудитом `code/audit_ys_exact.py`.

**Статус:** условие для **регулярных** элементов (c_m ≠ 0) подтверждено по первоисточнику. Для элементов с c_m = 0 это условие не применяется — нужен null-критерий (см. §2). **[OPEN]**: в текущей конструкции не проверено, есть ли LDL-элементы с c_m = 0.

## 2. Nurdin, arXiv 2402.11567 (v5) — Theorem 2 и исправление

**VERIFIED-source (v5, раздел 6, Corrigendum).**
- Исходное Condition 2 в Theorem 2 признано недостаточным: система PDE может иметь унитарное решение, не отвечающее насыщению QCRB нулевыми элементами.
- Исправление: Condition 2′ с вещественными диагональными D_l, унитарной U_θ и **вещественными константами c^k_lm** для нулевых элементов, Theorem 3 (`thm:main-corrected`) с условиями 1, 2′, 3 (коммутаторы L_{θ_l,+0}), 4 (вещественные пропорциональности столбцов с унитарной W_θ).
- Null-условие (сохранено в v5, формула (10)): E_k L_{θ_l} P_+ = c^k_lm E_k L_{θ_m} P_+ — это и есть «составная матрица попарных ограничений с коэффициентами c_lm» из постановки. Оно связывает нулевые элементы с вещественными c_lm.
- В corrigendum приведён пример L-CSS (номер примера не сверен), на котором условие 2′ выполняется с D=0.

**Ошибка ссылки, VERIFIED:** во введении v5 написано «sufficient … (Theorem 6)». Номер Theorem 6 в тексте не найден (поиск по `label{thm:` вернул 0 совпадений в основном тексте); корректная теорема — Theorem 3 в приложении. Ссылка «Theorem 6» висит.

**Публикация исправления, VERIFIED (метаданные):** Corrections к «Saturability…», IEEE Control Systems Letters, doi 10.1109/lcsys.2024.3451468. Оригинал: doi 10.1109/lcsys.2024.3382330.

**Для S+ (важно):** наш конструктивный сертификат проверяет только регулярную часть (условие YPZJ для c_m ≠ 0 и сумму Σ w u uᴴ = I₂₂). Null-часть — условие Nurdin 2′/c_lm — **не проверена**. Значит, насыщение QCRB для построенного POVM **не доказано**, даже если сумма точно равна I.

## 3. Yang–Imai–Pezzè, arXiv 2601.21801 (v1, 2026-01-29)

**VERIFIED-abstract.** Насыщение QCRB ⟺ одновременная «холлоуизация» набора следовых операторов. Оптимальные ранговые-1 векторы POVM лежат в ортогональном дополнении 𝒱_⊥ (в Herm(d)) к Hermitian-span 𝒱, определяемому состоянием. PCC не всегда достаточно. Информационно полные POVM бесполезны (контринтуитивное утверждение).

**Что это даёт для проверки:** критерий E ∈ 𝒱_⊥ — линейный и независимый от нашей формулировки. Его можно проверить на нашем POVM (u uᴴ должно лежать в 𝒱_⊥ для всех элементов). **Не сделано**; это естественный следующий шаг и независимая проверка насыщения, если POVM будет построен.
