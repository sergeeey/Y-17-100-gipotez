# Численный контроль минимального информационного дефицита (2026-10-31)

Статус: VERIFIED-NUMERIC. Это не доказательство и не строгий сертификат. Цель — проверить, способен ли численный поиск обнаружить нарушение Теоремы Q (S−) или насыщение S+.

Скрипт: `code/control_min_deficit.py` (аргументы: набор, K исходов, s). SLD вычисляется из семьи по определению (решение ρL + Lρ = 2∂ρ в собственном базисе ρ; ядро−ядро блок не используется). Проверка уравнения SLD: ≤ 1.6·10⁻⁸ (S−), ≤ 3·10⁻¹³ (S+). POVM: E_k = S^{-1/2}v_kv_kᴴS^{-1/2}, S = Σv_kv_kᴴ (полнота автоматическая). Оптимизация L-BFGS по trace классической FI, 3 старта, maxiter 400.

## Интерпретация (честно)

1. **Контроль недостаточен и не различает S+ и S−.** Для S+ дефицит 17.2 (7.7 % от tr F^Q) при K = 24. Строгое существование POVM S+ даёт 1764 элементов на сетке, а не 24, поэтому K = 24 не должен давать насыщения. Дефицит S+ не равен нулю — значит, процедура не находит даже известное насыщение при малом K.
2. **Точка s = 0.02 не совпадает с теоремой S+.** Существование S+ доказано в точке θ = 0 на фиксированной сетке 280 направлений. Контроль S+ при s = 0.02 проверяет другую задачу. Корректный контроль S+ — при s = 0 с большим K.
3. **Для S− найденный дефицит 286 — это верхняя граница минимального дефицита** (оптимизатор даёт допустимый POVM, а не оптимальный). Нижнюю оценку он не даёт. Теорема Q утверждает положительный дефицит ≥ c₀, и численный результат 286 этого не опровергает и не подтверждает.
4. **Вывод:** численный контроль в текущем виде не способен обнаружить ошибку в Теореме Q — он не различает S+ и S− надёжно. Минимальный следующий эксперимент: (а) S+ при s = 0 с K ≥ 200 и большим числом итераций, ожидание дефицита → 0; (б) S− при тех же K, ожидание дефицита ≥ c > 0 при K → ∞ (нижняя граница, если дефицит стабилизируется). Это не выполнено; время расчёта — порядка часов при текущей реализации.
