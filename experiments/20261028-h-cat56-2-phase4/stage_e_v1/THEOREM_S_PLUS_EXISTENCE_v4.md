# S+ = {0..11}: теорема существования конечного насыщающего POVM без явного многогигабайтного разложения (v4, 2026-10-31)

Статус: **PROVED на конечной сетке Ξ из 280 направлений** при условиях C1–C4 ниже. Непрерывный случай не утверждается (не нужен для положительного результата). S− здесь не рассматривается.

## 0. Обозначения и условия

- d = 22 = 2 + 20, ℋ = ℋ₊ ⊕ ℋ₀, ℋ₊ = C², ℋ₀ = C²⁰. Блок-порядок: сначала ℋ₊.
- Состояние ρ = Q ⊕ 0, Q = diag(1/3, 2/3) (нормировка instance-состояния diag(1,2) с Tr=3; см. C2).
- Блоки A_i ∈ C^{20×2}, i ∈ S+ = {0..11}; из файла инстанса: A_i = −2i·B_i, B_i = Re + i·Im (Gaussian-integer), см. `TECHNICAL_NOTE_A0_EN_v1.2.md` §1.
- SLD-блоки: L_i = [[0, A_iᴴ],[A_i, 0]] (ℋ₊-блок первым), L_{i,00} не входит ни в одну величину ниже.
- Сетка: направления x_j ∈ C² \ {0}, j = 1..280; базисы B_j = (B_{j,1..m_j}) ⊂ C^{20}, m_j ∈ {6, 4} (182 и 98 направлений), с вещественным пространством Y_S(x_j) = {y : A_iᴴ y ∈ R·x_j ∀ i ∈ S+}.

**C1 (вещественный конус).** Все коэффициенты c, моменты M_j и веса d вещественны; M_j — вещественные симметричные (m_j+1)×(m_j+1).
**C2 (состояние и SLD).** Состояние ρ(θ) = e^{X(θ)} (Q⊕0) e^{−X(θ)}, X(θ) = Σ_i θ_i X_i, X_i = [[0, −A_iᴴ/2],[A_i/2, 0]]. Проверка (§1) показывает, что L_i = [[0, A_iᴴ],[A_i, 0]] — SLD-оператор параметра i в θ=0. Согласование с инстансом (A = −2iB) — конвенция пакета, владелец должен подтвердить (см. §5).
**C3 (точный сертификат).** Существуют рациональные M_j* ≻ 0, удовлетворяющие точно 484 равенствам A·M* = b (`exact_cert.py`, `logs/exact_cert_result.json`; независимая проверка mod p и high-precision в `code/verify_cert_compact.py`, см. §4).
**C4 (нет нулевых исходов).** Все построенные элементы имеют Tr(ρΠ_p) > 0 (§3).

## 1. SLD (лемма 1)

Пусть ρ = diag(Q, 0), ∂_i ρ = [X_i, ρ] = [[0, QA_iᴴ/2],[A_iQ/2, 0]] (при θ=0; проверено вычислением блоков). Положим L = [[0, Bᴴ],[B, 0]]. Тогда (ρL + Lρ)/2 = [[0, QBᴴ/2],[BQ/2, 0]]. Равенство ∂ρ = (ρL+Lρ)/2 даёт QAᴴ/2 = QBᴴ/2 ⇒ B = A, т.е. блок L_{+0} = Aᴴ, L_{0+} = A. Блок ∂ρ_{++} = 0 и L_{00}-член автоматически согласованы (ρ_{00}=0). **Следствие (QFIM):** F_ij = Tr(∂_iρ L_j) = Re Tr(Q A_iᴴ A_j) = Re Tr(ρ L_i L_j), симметризовано по i,j.

## 2. Условие насыщения для одного элемента (лемма 2)

Пусть Π = d |u⟩⟨u| с u = (α; y), α ∈ C², y ∈ C²⁰, d > 0. Тогда
- Tr(ρΠ) = d Σ_n p_n |α_n|² > 0 ⇔ α ≠ 0 (p_n = (1/3, 2/3));
- для ψ_n = (e_n; 0): L_i ψ_n = (0; A_i e_n), uᴴ ψ_n = conj(α_n), uᴴ L_i ψ_n = yᴴ A_i e_n = conj((A_iᴴ y)_n).

По теореме YPZJ (arXiv:1806.07337, §4.1, Thm. «thm:reg»; проверено по LaTeX-тексту) элемент Π насыщает матричную границу CFIM тогда и только тогда, когда Π L_i ψ_n = ξ_i Π ψ_n для всех n из спектра ρ с ξ_i ∈ R. Это эквивалентно uᴴL_iψ_n = ξ_i uᴴψ_n, т.е. (A_iᴴy)_n = ξ_i α_n для n = 1, 2 с одним вещественным ξ_i. Итог:

**Лемма 2.** Регулярный элемент u = (α; y) (α ≠ 0) насыщает границу ⇔ A_iᴴ y = ξ_i α для всех i ∈ S+ с ξ_i ∈ R.

Для элемента с α = c x_j (c ∈ R∖{0}) и y ∈ Y_S(x_j) это выполнено: A_iᴴ y = λ_i x_j с λ_i ∈ R, ξ_i = λ_i/c ∈ R. Проверка точная: `code/audit_ys_exact.py` (1484 вектора × 12 условий, 0 нарушений, Fraction).

## 3. Лифт моментов и теорема существования

**Лемма 3 (покомпонентное представление).** Для v_a := (x_j·[a=m] ; B_{j,a}) ∈ C²² (a = 1..m+1, где индекс m+1 — x-часть) и вещественной симметричной M_j:
Σ_{a,b} M_j[a,b] v_a v_bᴴ ∈ Herm(22), и отображение M ↦ (координаты) — R-линейное и биективное на Herm(22) (dim_R Herm(22) = 484 = 4 + 80 + 400 ✓: E1 — 2×2 эрмитова часть; E2 — 2×20 комплексная; E3 — 20×20 эрмитова). Поэтому Σ_p E_p = I₂₂ ⇔ точные 484 равенства A·M = b, где M — вектор моментов, и **A — ровно координаты Σ M v vᴴ**.
Проверка (независимая, с нуля от определения лифта): `code/audit_lift_rows.py`: max|A_direct − A_float| = 3.3·10⁻¹⁶, b совпадает точно.

**Теорема 1 (разложение PD-блока).** Пусть M ∈ S^n_{++} (вещественная, положительно определённая), n ≥ 2. Тогда существуют P ≤ n(n+1)/2 − 1 векторов c_p ∈ R^n с (c_p)_n = ±1 и весов d_p > 0, таких что M = Σ_p d_p c_p c_pᵀ.

*Доказательство.* Пусть M_nn > 0 (PD), R := tr M / M_nn, M' := M/M_nn. Рассмотрим K_R := {X ∈ S^n : X ⪰ 0, X_nn = 1, tr X = R}. K_R компактно (след фиксирован, PSD) и выпукло; M' ∈ K_R. По конечномерной теореме Минковского K_R = conv(ext K_R). Крайняя точка X спектраэдра с k = 2 аффинными ограничениями имеет ранг r с r(r+1)/2 ≤ k (Pataki 1998; Barvinok 1995), т.е. r = 1. Значит ext K_R ⊂ {cc^T : c_n² = 1, |c|² = R}. Размерность аффинной оболочки K_R равна n(n+1)/2 − 2, поэтому по теореме Каратеодори M' = Σ_p λ_p c_p c_pᵀ с λ_p > 0 и P ≤ n(n+1)/2 − 1. Полагаем d_p := M_nn·λ_p. ∎

**Теорема 2 (конечный POVM на Ξ).** Пусть для каждого j блоки M_j* ≻ 0 вещественны и удовлетворяют A·M* = b (C3). Тогда для Ξ существует конечный набор элементов
E_{j,p} = d_{j,p} u_{j,p} u_{j,p}ᴴ, u_{j,p} = (c_{j,p,m}·x_j ; Σ_a c_{j,p,a} B_{j,a}), p = 1..P_j,
где (c_{j,p}) — из теоремы 1 для M_j*, такой что:
(i) Σ_{j,p} E_{j,p} = I₂₂ точно;
(ii) каждый E_{j,p} регулярен и насыщает границу CFIM (лемма 2);
(iii) P = Σ_j P_j ≤ 182·27 + 98·14 = 6286 исходов.

*Доказательство.* (i): u uᴴ = Σ_{a,b} c_a c_b v_a v_bᴴ, поэтому Σ_p d_p u_p u_pᴴ = Σ_{a,b} M_j*[a,b] v_a v_bᴴ (по j), и это равно I₂₂ по лемме 3 и C3. (ii): c_{j,p,m} = ±1 ≠ 0 ⇒ α = ±x_j ≠ 0; y = Σ_a c_a B_{j,a} — вещественная комбинация базиса Y_S(x_j), поэтому A_iᴴy ∈ R x_j, что по лемме 2 даёт насыщение. (iii): n = m+1 ∈ {7, 5}, n(n+1)/2 − 1 ∈ {27, 14}. ∎

**Алгоритм (без материализации точных коэффициентов).** Существование даёт теорема 1 (неконструктивно по Каратеодори); численно: в высокой точности (Decimal prec ≥ 200) найти разложение M_j*/M_nn через ограниченный LP или "ректификацию" Каратеодори по пулу кандидатов c_p = (±1-патчи) на сфере |c|² = R. Точность требуется только для вычисления весов; **точная проверка** сумм обходится C3 (равенства A·M* = b, проверяются mod p и по rational-сертификату), а не весами. Точные веса d_p — рациональные числа огромной высоты и не выписываются.

**Важно — здесь не нужна LDL.** Положительность M_j* уже установлена (C3). LDL давал явные d_p, но теорема 1 даёт существование без него.

## 5. Оговорки (честно)

1. **Конвенция инстанса** (A = −2iB) и состояние diag(1,2) — из пакета `20261027-h-cat56-2-submission-package-v1`; в `TECHNICAL_NOTE_A0_EN_v1.2.md` прямо сказано, что владелец должен подтвердить состояние. Это [UNKNOWN] до подтверждения.
2. **Nurdin (корригендум).** Здесь не используется: доказательство опирается только на YPZJ для каждого элемента. Поскольку все элементы регулярны, условия null-части (c_lm) не нужны. Это *не* проверка Nurdin.
3. **Смешанные support–kernel блоки.** Элементы u=(α;y) с α≠0, y≠0 — смешанные. Условие YPZJ поэлементное и не требует коммутативности SLD; это обходит проблему Conlon et al. (arXiv:2404.01520) для нашего конкретного случая.
4. **Вещественность.** Все c_p вещественны, y ∈ вещественной оболочке Y_S(x_j) (не комплексной). Комплексное пространство не используется.
5. **Нормировка.** x_j не единичны (ни одно из 280). Линейные условия однородны по масштабу; насыщение (лемма 2) инвариантно при вещественном масштабе α. Проверено exact.
6. **Непрерывный случай, S−** — вне этого документа.
