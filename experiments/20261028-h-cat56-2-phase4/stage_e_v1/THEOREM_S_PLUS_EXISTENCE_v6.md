## 0. Постановка и обозначения

- d_H := 22 = 2 + 20; ℋ = ℋ₊ ⊕ ℋ₀, ℋ₊ = C², ℋ₀ = C²⁰.
- Состояние ρ = Q ⊕ 0, Q ≻ 0 на ℋ₊ с Tr Q = 1. Для инстанса (diag(1,2), Tr = 3) нормированный вариант Q = diag(1/3, 2/3). В доказательстве Q произвольна (§2, §4).
- Блоки A_i ∈ C^{20×2}, i ∈ S+ = {0..11}, A_i = −2i·B_i, B_i ∈ Z[i]^{20×2} (конвенция инстанса, `TECHNICAL_NOTE_A0_EN_v1.2.md` §1). SLD-блоки L_i = [[0, A_iᴴ],[A_i, 0]]; L_{i,00} нигде не используется.
- Сетка Ξ = {x_j}_{j=1}^{280} ⊂ C² \ {0}. Для каждого j — вещественный базис B_{j,1..m_j} ⊂ C²⁰ пространства Y_S(x_j) = {y : A_iᴴy ∈ R·x_j ∀ i ∈ S+}. m_j ∈ {6, 4} (182 и 98 направлений).
- Размер блока N_j := m_j + 1; индекс N_j — x-часть. Векторы v_{j,a} := (0; B_{j,a}) для a ≤ m_j и v_{j,N_j} := (x_j; 0) ∈ C²².
- Блочная матрица моментов: M_j — вещественная симметричная N_j × N_j, с элементами M_j[a,b].

## 1. SLD и QFIM (лемма 1)

X_i := [[0, −A_iᴴ/2],[A_i/2, 0]] антиэрмитова; ρ(θ) = e^{X(θ)} ρ e^{−X(θ)}, ∂_iρ = X_iρ − ρX_i = [[0, QA_iᴴ/2],[A_iQ/2, 0]]. Для L = [[0, Bᴴ],[B, 0]]: (ρL+Lρ)/2 = [[0, QBᴴ/2],[BQ/2, 0]], и ∂ρ = (ρL+Lρ)/2 даёт B = A_i. Значит L_i — SLD параметра i в θ = 0. **QFIM:** F_ij = Re Tr(ρL_iL_j) = Re Tr(QA_iᴴA_j).

**Конвенция (C2).** Соответствие «инстанс ↔ модель» (A_i = −2iB_i, семейство ρ(θ) с этим X_i) — конвенция пакета, не выведена из первоисточника (§5).

## 2. Насыщение для одного элемента (лемма 2, произвольный Q ≻ 0)

Пусть Π = d·uuᴴ, u = (α; y), d > 0.

- Элемент регулярен, если Tr(ρΠ) ≠ 0; здесь Tr(ρΠ) = d·αᴴQα, и при Q ≻ 0 это > 0 ⇔ α ≠ 0.
- Теорема YPZJ (arXiv:1806.07337, §4.1, thm:reg): регулярный Π насыщает матричную границу CFIM ⇔ Π L_i ρ = ξ_i Π ρ для всех i с вещественными ξ_i (в доказательстве — равенство Π L_i ρ = ξ Π ρ; эквивалентно Π L_i ψ_r = ξ Π ψ_r для собственных векторов ψ_r ρ с p_r > 0, поскольку ρ ≻ 0 на ℋ₊).
- Условие Π L_i ρ = ξ Π ρ при Π = d uuᴴ сводится (d > 0) к uᴴL_iρ = ξ uᴴρ. Здесь L_iρ = [[0, 0],[A_iQ, 0]], поэтому uᴴL_iρ = (yᴴA_iQ, 0) и uᴴρ = (αᴴQ, 0). Сокращая Q (обратима на ℋ₊): yᴴA_i = ξ αᴴ, то есть **A_iᴴy = ξ̄ α = ξ α** (ξ вещественно).

**Лемма 2.** Регулярный элемент u = (α; y), α ≠ 0, насыщает CFIM-границу ⇔ A_iᴴy = ξ_i α для всех i ∈ S+ с вещественными ξ_i. Условие не зависит от Q (при Q ≻ 0). Для α = x_j и y ∈ Y_S(x_j) оно выполнено по определению Y_S.

## 3. Лифт и полнота (лемма 3)

**Лемма 3.** Отображение H ↦ координаты (R-линейный изоморфизм Herm(22) → R^484):
- E1 (H₊₊, 2×2): Re H₁₁, Re H₁₂, Re H₂₂, Im H₁₂ — 4 числа;
- E2 (H₊₀, 2×20 комплексный): Re и Im всех 40 элементов — 80 чисел;
- E3 (H₀₀, 20×20 эрмитов): Re H_{rs} при r ≤ s (210) и Im H_{rs} при r < s (190) — 400 чисел.
4 + 80 + 400 = 484 = 22² = dim_R Herm(22). Нижний треугольник восстанавливается эрмитовостью.

**Следствие.** Для элемента E = d·uuᴴ с u = Σ_a c_a v_{j,a} (вещественные c_a) имеем E = Σ_{a,b} d c_a c_b v_a v_bᴴ. Сумма по всем элементам равна Σ_j Σ_{a,b} M_j[a,b] v_{j,a}v_{j,b}ᴴ с M_j := Σ_p d_{j,p}c_{j,p}c_{j,p}ᵀ (вещественная симметричная). Координаты этой суммы — линейная функция вектора M = (M_j[a,b])_{a≤b} с матрицей A (484 × 6566). Итог: **Σ E = I₂₂ ⇔ A·M = b**, где b_{E1} = (1,0,1,0), b_{E2} = 0, b_{E3} = (единицы на диагонали, нули иначе).

**Блоки:**
- support-блок H₊₊ = Σ_j M_j[N_j,N_j] x_jx_jᴴ — это E1;
- перекрёстный блок H₊₀ = Σ_j Σ_{a} M_j[a,N_j] x_j B_{j,a}ᴴ — это E2; равенство H₊₀ = 0 входит в b;
- kernel-блок H₀₀ = Σ_j Σ_{a,b} M_j[a,b] B_{j,a}B_{j,b}ᴴ — это E3.

Проверка по определению (float): `code/audit_lift_rows.py`, max |A_direct − A_float| = 3.3·10⁻¹⁶.

## 4. Разложение PD-матрицы и теорема

**Лемма D.** Пусть M ∈ S^N, M ≻ 0, N ≥ 1. Существуют N вещественных векторов ĉ_1..ĉ_N ∈ R^N с (ĉ_k)_N = 1 и ω > 0 такие, что M = ω·Σ_k ĉ_kĉ_kᵀ.

*Доказательство.* Пусть C — вещественная обратимая матрица с M = CCᵀ (например, Холецкий). Пусть g := Cᵀe_N ≠ 0 (последняя строка C, транспонированная). Пусть u := g/‖g‖, h := (1,…,1)ᵀ/√N. Если u ≠ h, пусть v := u − h и O := I − 2vvᵀ/‖v‖² (отражение Хаусхолдера; O симметрична, ортогональна, Ou = h); если u = h, O := I. Тогда C' := CO, C'C'ᵀ = M. Для k-го столбца c'_k = C o_k (o_k = Oe_k): (c'_k)_N = eNᵀ C o_k = gᵀo_k = ‖g‖·uᵀOe_k = ‖g‖·(Ou)_k = ‖g‖/√N =: s > 0 для всех k. Значит c'_k = s·ĉ_k с (ĉ_k)_N = 1, и M = s²·Σ_k ĉ_kĉ_kᵀ; ω := s² = ‖g‖²/N = M_NN/N. ∎

*Численная проверка* (`code/check_decomposition_v5.py`, 200 случайных PD-матриц размера 2–7): относительная ошибка реконструкции ≤ 10⁻¹⁵. Пример diag(1,2): ω = 1, ĉ_1 = (−1/√2, 1), ĉ_2 = (1/√2, 1). Ограничение «последняя координата = 1» не накладывает условий на первую координату; diag(1,2) не противоречит лемме D.

**Теорема 3 (конечный POVM на Ξ).** Пусть для каждого j блок M_j ≻ 0 вещественный симметричный и A·M = b (точно). Положим, для каждого j, (ĉ_{j,k})_{k=1}^{N_j}, ω_j из леммы D и
u_{j,k} := (x_j ; Σ_{a=1}^{m_j} (ĉ_{j,k})_a B_{j,a}), E_{j,k} := ω_j · u_{j,k}u_{j,k}ᴴ.
Тогда:
(i) Σ_{j,k} E_{j,k} = I₂₂ (в R, по лемме 3 и A·M = b);
(ii) каждый E_{j,k} регулярен: Tr(ρE_{j,k}) = ω_j·x_jᴴQx_j > 0;
(iii) каждый E_{j,k} насыщает CFIM-границу (лемма 2; y = Σ_a (ĉ)_a B_{j,a} ∈ Y_S(x_j), так как Y_S(x_j) — вещественное подпространство);
(iv) Σ_{j,k} CFIM-вклады = QFIM на 12×12: по YPZJ матричная граница для каждого элемента равна Re Tr(ρL_iE L_j) (симметризовано), суммирование по элементам даёт Re Tr(ρL_iL_j) = F_ij, потому что Σ E = I₂₂ по (i); насыщение элементарное, поэтому CFIM = QFIM;
(v) число исходов N_out = Σ_j N_j = 182·7 + 98·5 = 1764.

*Доказательство* — из (i)–(iv) выше. (iv) использует только ΣE = I и поэлементное равенство; ненулевые p не нужны отдельно, так как (ii) даёт Tr(ρE) > 0.

## 5. Нормировка, D1/D2, точность

- **Нормировка.** Q входит только в (ii) и в значение QFIM/CFIM. Условие насыщения (лемма 2) и существование POVM от Q не зависят. Для diag(1,2) (Tr = 3) CFIM и QFIM умножаются на 3 (аудит, численно); Q = diag(1/3,2/3) — правильная нормировка для Tr ρ = 1.
- **D1/D2.** Нулевых исходов нет (ii), поэтому конвенция для нулевых исходов не применяется; D1 (нулевые исходы дают 0) и D2 (направленный предел) совпадают. Стандартная D2 не заменяется слабой D1.
- **Точность.** Лемма D использует вещественные Холецкий и отражение (иррациональные числа). Поэтому веса ω_j и векторы ĉ — вещественные алгебраические, а не рациональные. Для существования это достаточно; явный POVM рационально не выписан.
