# Prior Result Gate — «ошибки LLM как источник научных гипотез» (мишень №3)

Дата: 2026-09-19. Тип: предрегистрационная проверка, **не эксперимент**. Гипотезе H-номер **не присвоен**.
Основание проверки: вопрос «занято ли поле» (Prior Result Gate), после трёх случаев в лаборатории, где идея оказывалась
уже сделанной (H-CAT56-1 — REPEAT, Мост 10 — BRIDGE-TRIVIAL, `E[theta] >= sqrt(n)` — известная теорема).

## L0 и Zero-Signal Gate

**L0: предиктивный вопрос** (предсказывает ли отобранное подмножество ошибок модели связи, которые позже реализуются в литературе). Причинных утверждений нет.

| Поле | Значение |
|---|---|
| Сущность | пары понятий, порождённые LLM как «структурированные ошибки» (не совпадают с известной на дату отсечки литературой, но выводимы по цепочке), воспроизводимые между запусками |
| Проверяемое предсказание | доля таких пар, реализованных в литературе в окне после даты отсечки, выше, чем у (а) правильных ответов, (б) случайных пар с той же степенью узлов, (в) стандартного предсказателя связей по графу литературы |
| Измеримый исход | доля реализованных пар в окне и её разница с базовыми линиями, доверительный интервал |

Все три поля заполняются, гейт формально проходит. Но заполнимость поля не равна открытости вопроса.

## Разложение идеи и найденные предшественники

Ключевые слова поиска: гипотезы из галлюцинаций, литературная разведка, тест по времени, загрязнение датой отсечки, ошибки, общие для моделей.
Всё ниже найдено веб-поиском по сводкам выдачи; статьи целиком **не читались** — метка `[WEAK]`.

| Составная часть идеи | Уже сделано? | Опора (найдено поиском) |
|---|---|---|
| Проверка гипотез «по времени» (предсказать будущие совместные упоминания) | **Да, классика** | «time-sliced» оценка в литературной разведке (Swanson-ABC и последователи), обзор LBD на arXiv:2310.03766 |
| Предсказание будущих связей на графе понятий | **Да** | Krenn & Zeilinger, PNAS 2020; Science4Cast (более 143 000 статей ИИ, около 64 000 понятий-узлов); Nature Machine Intelligence 2023 |
| LLM генерирует гипотезы, оцениваемые по будущей литературе | **Да** | «Learning to Predict Future-Aligned Research Proposals» (arXiv:2603.27146, метрика Future Alignment Score); CUSP; «Interesting Scientific Idea Generation using KGs and LLMs» (arXiv:2405.17044) |
| Загрязнение датой отсечки при ретроспективных тестах | **Да, решена** | ProjectionBench (arXiv:2605.30284): живая процедура, статьи заведомо после отсечки обучения тестируемых моделей |
| Галлюцинации и креативность в генерации гипотез | **Да** | arXiv:2512.11509 (меры подавления галлюцинаций по-разному влияют на дивергентное мышление), arXiv:2505.14599 (правдивость гипотез) |
| Ошибки, общие для разных моделей | **Да, и это против нас** | ошибки моделей систематичны и коррелированы; две модели ошибаются одинаково около 60% случаев (работа ICML 2025 на более чем 350 моделях); согласие моделей слабо предсказывает правильность (Spearman rho 0,20–0,59, аудит июля 2026) |
| **Специфический контраст: «структурированные воспроизводимые ошибки» против «правильных ответов» по обогащению будущими связями** | **Прямых попаданий не найдено** в двух целевых поисках | `[WEAK]`: отсутствие в выдаче не доказывает отсутствие в литературе (у нас есть свой урок: MCP arXiv вернул «не найдено» для двух реальных статей) |

## Что из этого следует

1. Все ингредиенты плана опубликованы; новизной остаётся только один контраст (ошибки против правильных ответов). Это узкий остаток, а не «новая парадигма».
2. **Согласие моделей — не независимое свидетельство.** Плановый шаг «GPT, Claude и Gemini независимо воспроизводят одну связь» по литературе означает общие ошибочные приоры обучения, а не подтверждение. Его нужно заранее объявить не-доказательством.
3. **Загрязнение решается только двумя способами**: (а) модель с известной старой датой отсечки (слабая), (б) окно исхода строго после даты отсечки тестируемой модели (окно короткое). Запретить модели «знать» 2016–2026 текстовой инструкцией нельзя.
4. **Нулевая модель обязательна и она сильная**: стандартное предсказание связей по графу литературы уже даёт результаты в Science4Cast. Побить её сложнее, чем случайные пары.
5. **Оценка стоимости** `[INFERRED]`: план из текста (1000 вопросов, 100 запусков, 3 модели) = `1000 * 100 * 3 = 300 000` вызовов. Минимально осмысленная версия: около `100 * 20 * 2 = 4 000` вызовов.

## Вердикт гейта

**PARTIAL-PRIOR-ART / NARROW-RESIDUAL — H-номер не выдаётся.**

- Вероятный исход честного эксперимента: обогащения сверх базовой линии по графу нет. Это информативный отрицательный результат, а не открытие.
- Стоимость и инфраструктура (вызовы LLM, датированный корпус, граф литературы) велики относительно ожидаемого выигрыша.
- Поэтому по правилу проекта (ADR-121: новый цикл только при выполнении условий, «граф может родить ещё один H-номер» — не основание) **не регистрирую**.

## Условия пересмотра (что изменило бы вердикт)

Регистрировать, только если выполнены все три:
1. Прицельный поиск (Google Scholar/arXiv по терминам «hallucination», «confabulation», «temporal validation», «link prediction») прямого предшественника не находит.
2. Есть готовая датированная база (например, публичные данные Science4Cast) и слабая старая модель или окно после отсечки, при которых эксперимент укладывается в порядка 4 000 вызовов.
3. Заранее зафиксированы: нулевая модель по графу литературы, единица независимости (пара понятий, не запрос), критерий исхода, стоп-правило, и оговорка «согласие моделей — не свидетельство».

Если понадобится, минимальный кандидат-эксперимент: 100 вопросов по одной области, 20 запусков, две модели, окно исхода после отсечки, сравнение с предсказателем по графу.

## Что делать со всей затеей «Anomaly Hunter»
Не строить. Это инфраструктура без результата (тот же риск, что описан в ADR-121), и три из её восьми компонентов уже существуют как опубликованные системы.
