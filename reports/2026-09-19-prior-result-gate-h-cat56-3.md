# Prior Result Gate — кандидат H-CAT56-3 («минимальное число ранг-один элементов насыщающего POVM»)

Дата: 2026-09-19. Тип: предрегистрационная проверка, **не эксперимент**. H-номер **не присвоен**.
Порядок из плана: сначала литература, потом геометрия Theorem 2/3, потом дешёвый расчёт на известных насыщаемых состояниях.

## L0 и Zero-Signal Gate
L0: **описательный** вопрос существования (какое минимальное число элементов у насыщающего POVM для данного состояния).

| Поле | Значение |
|---|---|
| Сущность | насыщающий QCRB ранг-один POVM для обобщённого quasi-pure состояния (Yang, Eq. 12) |
| Проверяемое предсказание | минимальное число элементов `m` можно предсказать формулой (например `m = d`) |
| Измеримый исход | найденное решение с `sum |u><u| = I` и условиями гололизации на `m` элементах (существование подтверждается найденным решением) |

## Шаг 2. Что следует из геометрии (мой вывод, не из статьи)
- `d` ранг-один элементов с суммой `I` — это ортонормированный базис. Значит `m ≥ d` всегда (нужно натянуть `C^d`), и `m = d` тогда и только тогда, когда в `V⊥` лежит ортонормированный базис из ранг-один проекторов.
- Выше порога Theorem 3 `m = d` гарантировано теоремой; **ниже порога** ни доказательства, ни контрпримера нет. Значит вопрос формально открыт, но верхняя оценка размера известна, а нижняя тривиальна.

## Вердикт гейта: **TRIVIAL-IN-TESTED-REGIME / NOT-REGISTERED**
1. Нижняя оценка тривиальна (`m ≥ d`), верхние оценки размера опубликованы.
2. В проверенной области (`d ≤ 6`, 12 состояний на класс, 5 классов) минимум равен `d` везде, включая состояния ниже порога Theorem 3, то есть постановка «нужно ли больше `d`» там отвечена «нет».
3. H-номер не выдаётся: осталось бы показывать то, что уже видно в 36 из 36.

Ограничения: обходится область малых `d`, где поиск дёшев; для больших `d` поиск дорог, а неудача его ничего не доказывала бы. Успешность в 36/36 не доказывает теорему для `d ≤ 6`, это численное подтверждение с допуском 1e-9.

## Что осталось содержательного: случай «на границе» (кандидат, тоже не зарегистрирован)
Тест сертификации (`dim V⊥ < d` запрещает насыщение) молчит ровно тогда, когда `dim V⊥ ≥ d`. Самый жёсткий случай — **`dim V⊥ = d` точно**: тогда любое насыщающее измерение — это ортонормированный базис из ранг-один проекторов, натягивающий **весь** `V⊥`, и одна такая структура либо есть, либо нет. В нашем же контрпримере H-CAT56-2 такие состояния есть: `d = 21, r = 2, s = 16` даёт `dim V⊥ = 21` (проверено независимым кодом, 4 из 4), то есть ровно на границе, и сертификат молчит.

Вопрос: **насыщаема ли QCRB на границе `dim V⊥ = d` или там возникает второе препятствие?** Это острее исходного H-CAT56-3, потому что ответ «нет» дал бы **второй механизм контрпримера** для обобщённых quasi-pure состояний при `d = 21`, а не только при `d ≥ 22`. Стоимость: 882 неизвестных на `d = 21` (`2·d·d`), вычислительно тяжело; неудача поиска не будет сертификатом. Нужен собственный Prior Result Gate (граничный случай `n = d − 1`, конечное многообразие допустимых векторов, упомянут в Observation 2 и Theorem 2 статьи) и точный тест вместо поиска. Не запускаю, пока нет решения.
