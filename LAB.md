## 4. Инварианты лаборатории (нарушение = стоп)

1. **Гипотеза не существует, пока нет узла в `graph.yaml`** с `l0_type`, `kill_criterion`, `evidence`, `status`.
2. **L0 gate первым**: Descriptive / Predictive / Causal — до выбора tier FL. Causal → `estimand.md` с DAG.
3. **Kill-criterion до запуска**, три исхода: KILLED / CONFIRMED / LEAD. «Почти» не бывает.
4. **Новый NULL → ретроскан**: найти все узлы, до которых от него ведёт `depends_on`/`grounds`, и пересмотреть их статус *в той же сессии*. (Прецедент: PARKED-файл 12 дней ссылался на инвалидированный результат.)
5. **Верификация не переносится**: вердикт для артефакта A не действует для B из-за общего названия/автора (Gate 1, `artifact-provenance-gates`). H-7 GeoSpectra ≠ H-7 TAD.
6. **Evidence labels** на каждом числе: `VERIFIED-REAL` / `VERIFIED-SYNTHETIC` / `HYPOTHESIS` / `UNVERIFIED` / `CONFLICT`.
7. **Skeptic — с асимметрией контекста**: только `claim.md` + код, без истории рассуждений.
8. **Ничего наружу без Submission Gate** (`03-methodology-rules/Submission Gate Protocol (HARD RULE).md`).
9. **Каждый применённый инструмент → строка в LEDGER.** Без этого мета-цель «протестировать стек» — не данные, а впечатление.

**H-B2-1 выполнено 2026-09-06 (автономно во время отсутствия пользователя, ADR-014):** мост B2
(Chernoff↔Neural-ODE) формализован и проверен на 1D аналитически решаемом примере → **KILLED**.
Теорема формально применима, но её собственная количественная оценка скорости систематически на
1 порядок n слабее элементарного расчёта Тейлора. По пути пойман и исправлен собственный фабрикат
цитаты (см. `pearl_registry/INDEX.md`).

**I выполнено 2026-09-06 (автономно, ADR-015):** V3 (descriptive join) → LEAD. Самая резкая находка
ветки B3: Paul doSat (негативный контроль) даёт самый устойчивый «TDA-опережает» сигнал во всём
исследовании (4/4 методов), устойчивее 2 из 3 настоящих позитивов. Ноль нового вычисления.

**Следующие кандидаты:**
- **J.** V4' (heteroscedastic null) — низкий приоритет: V3 уже показал, что проблема не в конкретной

**K выполнено 2026-09-06 (автономно, `/loop`, ADR-017):** H-B2-1b (матричный случай, 2 собственных

**Ещё один шаг выполнен 2026-09-06 (автономно, `/loop`, ADR-018):** H-B2-1c (несимметричная матрица,
transient growth, territория теоремы Крейса) → CONFIRMED. M1/M2 честно измерены (≈2.56, не

ниже), но порядок точно сохраняется, граница выполняется во всех 16 случаях.

**Четвёртый шаг выполнен 2026-09-06 (автономно, `/loop`, ADR-019):** H-B2-1d (смешанный спектр —
одно растущее, одно затухающее собственное значение) → CONFIRMED, обоснован через `WebSearch`
(реальные ResNet имеют нестабильные направления; Neural ODE — «stiffness»), не произвольная
эскалация. M1=M2=1 доказано ТОЧНО (не численно) — самая чистая генерализация из четырёх. Побочно:
самопойманная ошибка в формуле границы H-B2-1c (M1² вместо M1) — исправлена, вердикт H-B2-1c не
изменился, эффективность честнее. **Четыре подряд успешные генерализации в одной сессии.**
**Пятый и финальный шаг серии выполнен 2026-09-06 (автономно, `/loop`, ADR-020):** H-B2-1e
(объединённый стресс-тест: несимметрия + смешанный знак вместе) → CONFIRMED. Эффекты РЕАЛЬНО
складываются (M1=3.806 > 2.563 у одной несимметрии), но не взрывным образом — граница держится во
всех 16 случаях, порядок точен. **Шестое подтверждение выполнено 2026-09-06 (автономно, `/loop`, ADR-021, без паузы на отчёт):**
H-B2-1f (N=8, широко разнесённый «жёсткий» спектр) → CONFIRMED. Контринтуитивная находка: M1 при
N=8 (2.665) МЕНЬШЕ, чем при N=2 (3.806) — размерность сама по себе не усилила compounding в этой
конструкции. **Седьмое подтверждение выполнено 2026-09-06 (автономно, `/loop`, ADR-022) — САМАЯ ВАЖНАЯ находка
серии:** H-B2-1g (та же 8D конструкция, связь ×5 сильнее) → CONFIRMED. M1 взлетел с 2.665 до 158.93
(~60×) — контринтуитивная находка H-B2-1f оказалась артефактом слабой связи. Граница ВСЁ РАВНО
держится и порядок ВСЁ РАВНО точен, но эффективность падает до ~1.5×10⁻⁷ — **формально верно,
практически бесполезно**. Ключевой вывод для всей серии: валидность границы и её практическая
полезность — разные оси; предыдущие «хорошие» числа эффективности (0.0002-0.37) были артефактом
протестированных параметров, не общим свойством метода. Любое будущее цитирование серии H-B2-1*
должно нести эту оговорку.

сравнение диаграмм устойчивости напрямую (явно названо как непройденный вариант в `H-B3-1g`'s
claim.md) — принципиально другая FAMILY метода, не очередной параметрический вариант.
